## 第一部分 题型1：FIRSTVT/LASTVT 与算符优先分析（第 1 题）

> **第 1 题**：已知文法 G[E]：
> E→E∨T | T，T→T∧F | F，F→¬F | (E) | a
> （其中 ∨、∧、¬、(、)、a 为终结符）。
> (1) 求各非终结符的 FIRSTVT、LASTVT；(2) 构造算符优先关系表；(3) 判断 G 是否算符优先文法，并说明理由。

**解 (0) 拓广文法**：$G'[Z]$：Z→#E#（引入界符 #，兼作栈底与输入结束标志）。

**解 (1) 集合计算**（规则 F1/F2/F3、L1/L2/L3 见 [[期末复习专题#1.1 知识点|题型1 知识点]]）

FIRSTVT：
- **Z**：Z→#E# 右部以终结符 # 开头，用 F1 得 # ⇒ **FIRSTVT(Z) = { # }**
- **F**：F→¬F、F→(E)、F→a 右部均以终结符开头，用 F1 得 ¬、(、a ⇒ **FIRSTVT(F) = { ¬, (, a }**
- **T**：T→T∧F 是 F2 形（右部以非终结符开头、紧跟终结符 ∧）得 ∧；T→F 用 F3 得 FIRSTVT(F) ⊆ FIRSTVT(T) ⇒ **FIRSTVT(T) = { ∧, ¬, (, a }**
- **E**：E→E∨T 用 F2 得 ∨；E→T 用 F3 得 FIRSTVT(T) ⊆ FIRSTVT(E) ⇒ **FIRSTVT(E) = { ∨, ∧, ¬, (, a }**

LASTVT：
- **Z**：Z→#E# 右部以终结符 # 结尾，用 L1 得 # ⇒ **LASTVT(Z) = { # }**
- **F**：F→a、F→(E) 右部以终结符结尾，用 L1 得 a、)；**F→¬F 右部以非终结符结尾、其前紧跟终结符 ¬，是 L2 形 ⇒ ¬ ∈ LASTVT(F)**（本题最易漏的一条！）⇒ **LASTVT(F) = { ¬, ), a }**
- **T**：T→T∧F 是 L2 形得 ∧；T→F 用 L3 得 LASTVT(F) ⊆ LASTVT(T) ⇒ **LASTVT(T) = { ∧, ¬, ), a }**
- **E**：E→E∨T 用 L2 得 ∨；E→T 用 L3 得 LASTVT(T) ⊆ LASTVT(E) ⇒ **LASTVT(E) = { ∨, ∧, ¬, ), a }**

**解 (2) 算符优先关系**（行 = 栈顶符号，列 = 输入头符号；`<` 低于、`≐` 同级、`>` 高于）

逐条产生式扫描：
- **F→(E)**：`( E` 形 ⇒ $( \lessdot FIRSTVT(E)$；`E )` 形 ⇒ $LASTVT(E) \gtrdot )$；`( E )` 两终结符隔一个非终结符 ⇒ $( \doteq )$。
- **F→¬F**：`¬ F` 形 ⇒ $ \neg \lessdot FIRSTVT(F)$。
- **T→T∧F**：`T ∧` 形 ⇒ $LASTVT(T) \gtrdot \wedge$；`∧ F` 形 ⇒ $\wedge \lessdot FIRSTVT(F)$。
- **E→E∨T**：`E ∨` 形 ⇒ $LASTVT(E) \gtrdot \vee$；`∨ T` 形 ⇒ $\vee \lessdot FIRSTVT(T)$。
- **Z→#E#**：`# E` 形 ⇒ $\# \lessdot FIRSTVT(E)$；`E #` 形 ⇒ $LASTVT(E) \gtrdot \#$；`# E #` 两终结符隔一个非终结符 ⇒ $\# \doteq \#$。

得关系表：

|      | ∨  | ∧  | ¬  | (  | )  | a  | #  |
| ---- | -- | -- | -- | -- | -- | -- | -- |
| **∨** | > | < | < | < | > | < | > |
| **∧** | > | > | < | < | > | < | > |
| **¬** | > | > | < | < | > | < | > |
| **(** | < | < | < | < | ≐ | < |   |
| **)** | > | > |    |    | > |   | > |
| **a** | > | > |    |    | > |   | > |
| **#** | < | < | < | < |   | < | ≐ |

**解 (3) 判定**：拓广后的 G' 无 ε 产生式、各产生式右部无相邻非终结符 ⇒ 是**算符文法**；表中每一对终结符（含 #）之间至多只有一种优先关系（如 ( 与 ) 之间只有 ≐，∨ 与 ( 之间只有 <，# 与 # 之间只有 ≐），无冲突 ⇒ **G[E] 是算符优先文法**。

> [!warning] 本题易错
> 1. **F→¬F 是 L2 形**（右部以非终结符结尾、其前紧跟终结符）⇒ ¬ ∈ LASTVT(F)。漏掉它，"¬" 行会少 3 个 `>`。¬ 同时在 FIRSTVT(F) 与 LASTVT(F) 里是正常的。
> 2. **"¬" 行既有 `<` 又有 `>` 不是冲突**：冲突指**同一格**出现两种以上关系；不同格不同关系互不影响。
> 3. 判定结论两句话：先"是算符文法"，再"每对终结符至多一种关系、无冲突"，最后"故是算符优先文法"。
> 4. **表格要带 # 行、# 列**：由 Z→#E# 得 $# \lessdot FIRSTVT(E)$、$LASTVT(E) \gtrdot \#$、$\# \doteq \#$。# 行只有 < 与 ≐，# 列只有 > 与 ≐，方向别写反。

## 第二部分 题型2：语言 → 文法，并判断文法类型（第 2–4 题）

> **第 2 题**：写一文法 G，使其语言为 $L=\{a^{2n} \mid n \ge 0\}$（偶数个 a 组成的串，含空串 ε），并判断文法类型。

**解**：

```
S → aA | ε
A → aS
```

- **正向**：S→ε 得 n=0；S→aA、A→aS 两步增加两个 a，反复使用得任意偶数个 a。
- **反向**：每轮必须"成对"使用 S→aA 与 A→aS（A 不可单独终止），故 a 的总数恒为偶数。
- **类型**：S→aA、A→aS 都是右线性（aB 形），S→ε 允许 ⇒ **3 型（正规文法）**；语言是正规语言。

> [!warning] 本题易错
> 若写 S→aaS | ε，语言对，但"aaS"不是右线性形式（右线性要求右部为 $A \to aB \mid a$）⇒ 该文法只是 **2 型**。判类型是判**文法**不是判语言！（见 [[期末复习专题#2.3 易错点|题型2 易错点 3]]。）

> **第 3 题**：写一文法 G，使其语言为 $L=\{a^n b^n c^m \mid n \ge 1,\ m \ge 0\}$，并判断文法类型。

**解**：

```
S → A B
A → a A b | a b
B → c B | ε
```

- A 生成 $a^n b^n$（n ≥ 1），B 生成 $c^m$（m ≥ 0，含空），拼接即得语言。
- **正向**：$A \Rightarrow a^n b^n$、$B \Rightarrow c^m$ ⇒ $a^n b^n c^m$；**反向**：任意合法串按结构唯一拆成"等数 a、b 段 + c 段"，分别由 A、B 推出。
- **边界**：m = 0 时 B⇒ε，如 ab、aabb ✓；n ≥ 1 保证至少一对 a、b ✓。
- **类型**：S→AB 右部含两个非终结符 ⇒ 非 3 型；左部为单个非终结符 ⇒ **2 型**。语言非正规（$a^n b^n$ 需要计数配对，DFA 做不到）。

> [!warning] 本题易错
> 不要写成 S→aSb | ab | C，C→cC | ε：此时 S⇒aSb⇒aCb 会推出 "acb"、"accb" 等 **c 夹在 a、b 之间**的非法串。c 段必须独立成块（用 S→AB 拼接），或显式限制 S→aSb 时内层 S 不得再用 C 产生式。

> **第 4 题**：写一文法 G，使其语言为 $L=\{a^n b^m \mid n > m \ge 0\}$，并判断文法类型。

**解**：

```
S → a S b | a S | a
```

- **结构读法**：S→a 是出口（1 个 a）；aS 每次加 1 个 a；aSb 每次加 1 个 a 和 1 个 b。设 aSb 用 j 次、aS 用 k 次，则串为 $a^{1+k+j} b^{j}$，即 $n = m + 1 + k > m$（m = j ≥ 0）。
- **正向**：推得的串都是 a 在前、b 在后且 n > m ≥ 0；**反向**：任给 n > m ≥ 0，取 j = m、k = n−m−1 ≥ 0，即可推出 $a^n b^m$。
- **边界**：m = 0 得 a、aa、aaa…（n ≥ 1）✓；最小"带 b"串是 aab（n=2, m=1）✓；"ab"（n=m=1）不在语言中，推不出 ✓。
- **类型**：S→aSb 右部非右线性 ⇒ **2 型**；语言非正规（需比较 n 与 m 的大小差，DFA 记不住）。

## 第三部分 题型3：文法 → 语言，并判断文法/语言类型（第 5–7 题）

> **第 5 题**：G[S]：S→aS | bA | ε，A→bA | ε。求 L(G)，并判断文法类型与语言类型。

**解**：S→aS 在串前加一个 a，S→bA 转入"加 b"阶段（至少 1 个 b），S→ε、A→ε 是出口。归纳可得：

$$L(G)=\{a^i b^j \mid i,\ j \ge 0\} = a^* b^*$$

（即任意个 a 后随任意个 b，含 ε，如 ε、a、b、aab、aabb、bb。）

- **文法类型**：每条右部都是 aB 或 a 形（S→aS、S→bA、A→bB 等右线性，ε 允许）⇒ **3 型（正规文法）**。
- **语言类型**：**正规语言**（正规式 $a^*b^*$，可画 DFA）。

> **第 6 题**：G[S]：S→aSb | bSa | SS | ε。求 L(G)，并判断文法类型与语言类型；G 是否二义文法？

**解**：aSb、bSa 成对放一个 a、一个 b，SS 拼接两段，ε 是出口：

$$L(G)=\{w \in \{a,b\}^* \mid w 中 a 与 b 的个数相等\}$$

- **正向**：对推导长度归纳——每条产生式都保持 a、b 数目相等且 a、b 可交错（如 ab、ba、aabb、abab、abba…）。
- **反向**：任取 a、b 等数的 w：若 w 有真前缀也是等数的，w = uv，由 S⇒SS⇒*uv；否则首字符与末字符必相异，w = aw'b 或 bw'a 且 w' 等数，由 S⇒aSb（或 bSa）⇒*w。归纳可得全部等数串，含 ε。
- **文法类型**：S→SS 右部含两个非终结符 ⇒ 非 3 型 ⇒ **2 型**。
- **语言类型**：**非正规**（等数要计数，正规语言泵引理可证不可行），是上下文无关语言。
- **二义性**：**是**。句子 abab 有两棵语法树：S⇒SS⇒(ab)(ab) 与 S⇒aSb⇒a(ba)b ⇒ 二义文法。

> **第 7 题**：G[S]：S→0S0 | 1S1 | 0 | 1。求 L(G)，并判断文法类型与语言类型。

**解**：0S0、1S1 在两头对称地加一对相同符号，0、1 是奇数长度回文的中心：

$$L(G)=\{w \in \{0,1\}^* \mid w = w^R \}$$

（即 0/1 上的**奇数长度回文串**：0、1、010、111、00100、01010…）

- **正向**：对推导长度归纳——对称包裹保持回文，长度每次 +2，出口长度 1 ⇒ 奇数长度回文。
- **反向**：任一奇数长度回文 w，中心一个字符用 0|1，去掉中心后 w = x x^R，从外向内逐对用 0S0/1S1 包裹即可。
- **文法类型**：0S0、1S1 右部非右线性 ⇒ **2 型**。
- **语言类型**：**非正规**（回文要"记住前半段"，DFA 无此能力），是上下文无关语言。

## 第四部分 题型4：推导与语法树——短语、直接短语、句柄、素短语、最左素短语（第 8 题）

> **第 8 题**：G[E]：E→E+T | E-T | T，T→T\*F | T/F | F，F→(E) | i。
> 对于句型 **E+T\*F-i**：(1) 给出最右推导；(2) 画出语法树；(3) 写出所有短语、直接短语和句柄；(4) 写出所有素短语和最左素短语。

**解 (1) 最右推导**（每步都替换当前**最右**非终结符）：

```
E        ⇒ E-T        (E→E-T)
         ⇒ E-F        (T→F)
         ⇒ E-i        (F→i)
         ⇒ E+T-i      (E→E+T)
         ⇒ E+T*F-i    (T→T*F)
```


**解 (2) 语法树**：

```
E
├── E
│   ├── E
│   ├── +
│   └── T
│       ├── T
│       ├── *
│       └── F
├── -
└── T
    └── F
        └── i
```

（根 E→E-T；左 E→E+T，其右 T→T\*F；根右 T→F→i。未展开的**叶型非终结符**：左下角的 E、T、F。）

**解 (3) 短语、直接短语、句柄**

**短语** = 语法树中任一子树的全部叶子从左到右组成的串：

- **E+T\*F-i**（根 E 的子树）
- **E+T\*F**（E→E+T 的子树）
- **T\*F**（T→T\*F 的子树）
- **i**（T→F→i 的子树）

**直接短语** = 高度为 1 的子树（产生式右部**原样**出现在句型中，一步推导所得）：

- **T\*F**（T→T\*F，T、\*、F 三符号都直接出现在句型中）
- **i**（F→i）

**句柄** = 最左直接短语 = **T\*F**（也恰好是 (1) 中最右推导**最后一步**所用产生式 T→T\*F 的右部，两法互验）。

**解 (4) 素短语、最左素短语**

**素短语** = 本身是短语、**至少含一个终结符**、且内部**不含更小短语**的串。把 (3) 的四个短语逐个检查：

- **i**：含终结符，内部无更小短语 ⇒ **素短语** ✓
- **T\*F**：含终结符 \*，内部只有叶型非终结符 T、F（都不是短语）⇒ **素短语** ✓
- **E+T\*F**：内部含更小短语 T\*F ⇒ 不是素短语 ✗
- **E+T\*F-i**：内部含更小短语 ⇒ 不是素短语 ✗

⇒ **素短语：T\*F、i**；**最左素短语 = T\*F**（最左边出现的素短语）。

> [!tip] 句柄 vs 最左素短语
> 本句型中句柄 = 最左素短语 = T\*F，属巧合；二者一般不同——**句柄**是最左直接短语（可以是单个非终结符，不含终结符也可，如专题习题中的 H→G 的 "H"），**素短语**必须**至少含一个终结符**。规范归约每步归约**句柄**；**算符优先分析**每步归约**最左素短语**（见 [[期末复习专题#1.3 易错点|题型1 易错点 5]]）。

> [!warning] 本题易错
> 1. **"E+T" 不是短语**：它虽然是产生式 E→E+T 的右部、也原样出现在句型开头，但该子树的两个子结点 E、T 都**继续展开了**，这棵子树实际推出的串是"E+T\*F"。子树的"叶子串"才是短语——"E+T"只是一步产生式的形状，不是任何子树的叶子串。
> 2. **未展开的叶型非终结符（句型中的 E、T、F）不是短语**，它们只是子树叶子串的组成部分（对比 [[期末复习专题#4.7 教材课后习题（附详细解答）|题型4 习题2.10 修订警告]]）。
> 3. 句柄只有一个：**最左**直接短语；规范归约第一步就是把 T\*F 归约为 T。

## 第五部分 题型5：消除左递归（第 9–11 题：1 直接 + 2 间接）

> **第 9 题（直接左递归）**：G[E]：E→E+T | E-T | T，T→T\*F | T/F | F，F→(E) | i。消除文法的左递归。

**解**：E、T 各含直接左递归（F 无递归，保持不变）。按公式 $A \to A\alpha_1 \mid A\alpha_2 \mid \beta \Rightarrow A \to \beta A',\ A' \to \alpha_1 A' \mid \alpha_2 A' \mid \varepsilon$：

- E→E+T | E-T | T：α₁="+T"、α₂="-T"、β="T" ⇒ $E \to TE'$，$E' \to +TE' \mid -TE' \mid \varepsilon$
- T→T\*F | T/F | F：α₁="\*F"、α₂="/F"、β="F" ⇒ $T \to FT'$，$T' \to \*FT' \mid /FT' \mid \varepsilon$

结果：

```
E  → T E'
E' → + T E' | - T E' | ε
T  → F T'
T' → * F T' | / F T' | ε
F  → ( E ) | i
```

**验证等价**：原 E 可推得 T₁±T₂±…±Tₙ（n ≥ 1 个 T 由 +、- 连接）；新文法 E→TE' 与 E'→±TE' 恰好生成同样的"1 个 T + 若干个 ±T"结构，E'⇒ε 对应"只有一个 T"。T 同理（F 后接若干 \*F、/F）。原语言无空串，新文法中 E'、T' 的 ε 仅供停止递归、不会产生额外终结串 ⇒ **语言等价**。

> [!tip] 多条 α、β 要一一对应
> 若 $A \to A\alpha_1 \mid A\alpha_2 \mid \beta_1 \mid \beta_2$，则 $A \to \beta_1 A' \mid \beta_2 A'$，$A' \to \alpha_1 A' \mid \alpha_2 A' \mid \varepsilon$。例如 G[S]：S→Sa | Sbc | b | c ⇒ **S→bS' | cS'，S'→aS' | bcS' | ε**（β 有几条就写几条，别漏 ε，见 [[期末复习专题#5.3 易错点|题型5 易错点]]）。

> **第 10 题（间接左递归·两非终结元）**：G[S]：S→Aa | b，A→Sb | c。消除左递归。

**解**：$S \Rightarrow Aa \Rightarrow Sba$，S（与 A）**间接左递归**。按非终结符顺序 (S, A) 依次"把**前面**的产生式代入后面者，再消直接左递归"：

1. S 的右部不以 S 开头（无直接左递归），且无前序非终结符可代入 ⇒ S→Aa | b 不变。
2. A 的右部含前序非终结符 S：代入 S→Aa | b 得 A→(Aa|b)b | c，即 **A→Aab | bb | c**（已化为直接左递归）。
3. 消直接左递归：α="ab"、β₁="bb"、β₂="c" ⇒ $A \to bbA' \mid cA'$，$A' \to abA' \mid \varepsilon$。

结果：

```
S  → A a | b
A  → b b A' | c A'
A' → a b A' | ε
```

**验证等价**：代入消元——原 A = Sb|c = (Aa|b)b|c = Aab|bb|c ⇒ $A=(bb \mid c)(ab)^*$，$S=Aa \mid b$；新文法给出的 A、S 正是同一方程。核对小串：b ✓（S→b）、ca ✓（A⇒c ⇒ S⇒Aa⇒ca）、bba ✓（A⇒bb ⇒ bba）、bbaba ✓（A⇒bbab ⇒ bbaba），且改写后无任何左递归（A 的右部以 b、c 打头，不再回到 S）⇒ **语言等价**。

> **第 11 题（间接左递归·三非终结元成环）**：G[S]：S→Qc | c，Q→Rb | b，R→Sa | a。消除左递归。

**解**：存在间接左递归环 $S \Rightarrow Qc \Rightarrow Rbc \Rightarrow Sabc$（S、Q、R 同在一个圈上）。按非终结符顺序 (S, Q, R) 执行"代入 + 消直接左递归"：

1. **S**：无前序；右部以 Q、c 开头，无直接左递归 ⇒ S→Qc | c 不变。
2. **Q**：前序 S 不出现在 Q 的右部中 ⇒ 无事可做；无直接左递归 ⇒ Q→Rb | b 不变。
3. **R**：右部含前序 S，先代入 S→Qc | c：R→Qca | ca | a；再代入前序 Q→Rb | b：**R→Rbca | bca | ca | a**（已化为直接左递归）。
4. 消直接左递归：α="bca"、β₁="bca"、β₂="ca"、β₃="a" ⇒ $R \to bcaR' \mid caR' \mid aR'$，$R' \to bcaR' \mid \varepsilon$。

结果：

```
S  → Q c | c
Q  → R b | b
R  → b c a R' | c a R' | a R'
R' → b c a R' | ε
```

**验证等价**：代入消元——R = Sa|a 代入 Q = Rb|b 得 Q = Sab|ab|b，再代入 S = Qc|c 得 S = Sabc | abc | bc | c ⇒ $L(S)=(abc \mid bc \mid c)(abc)^*$。新文法：R = (bca|ca|a)(bca)\*，Q = Rb|b，S = Qc|c。核对小串：c ✓、bc ✓、abc（a·bc）✓、cabc（ca·bc）✓、bcabc（bca·bc）✓、abcabc（a·bca·bc）✓ 与 (abc|bc|c)(abc)\* 逐一相同。改写后各右部均不以能推回自身的非终结符开头 ⇒ **无左递归、语言等价**。

> [!tip] 间接左递归的通用套路（题型5 解题步骤）
> 1. 定一个非终结符顺序（如 S, Q, R）；
> 2. 对第 i 个非终结符：把 j < i 的产生式**代入**其右部（直到右部只以 i 或更后面的非终结符开头）；
> 3. 若此时出现直接左递归，套公式消去；
> 4. 顺序不同（如 Q, R, S）结果形状不同但**都等价**，写出"代入 + 消直接左递归"两个动作即可。
> 5. 注：原文法 S→Qc|c 等是**左线性 3 型**文法——左线性文法同样可能左递归、不能直接做自顶向下分析，消左递归正是为 LL 分析做准备（见 [[期末复习专题#5.1 知识点|题型5 知识点]]）。
