## 第1题：带注释的分析树

> 对输入表达式 (4*7+1)*2，根据语法制导定义建立带注释的分析树。

**产生式与语义规则**：

| 产生式 | 语义规则 |
|--------|---------|
| L→E | print(E.val) |
| E→E₁+T | E.val := E₁.val + T.val |
| E→T | E.val := T.val |
| T→T₁*F | T.val := T₁.val * F.val |
| T→F | T.val := F.val |
| F→(E) | F.val := E.val |
| F→digit | F.val := digit.lexval |

**分析树构造过程**：

```
        L
        |
        E.val=58
       /|\
  E.val=29 + T.val=2
    /|\        |
E.val=28 T.val=7 F.val=2
    |    /|\        |
  T.val=28 T.val=7 * F.val=2
  /|\   /|\        |
T.val=4 F.val=7 digit.lexval=2
 /|\   |
T.val=4 F.val=4
 |      |
F.val=4 (E.val=29)
 |     /|\
digit  E.val=29 T.val=7
.lexval=4  /|\     /|\
        E.val=4 T.val=1 F.val=7
        /|\     |        |
      T.val=4 F.val=1 digit.lexval=7
       /|\      |
     F.val=4 digit.lexval=1
       |      |
(E.val=28)  digit.lexval=4
     |     /|\
  E.val=28 T.val=7
  ...      ...
```

**计算过程**（自下而上）：
1. F.val = 4 (digit 4 的 lexval)
2. T.val = 4 (T→F)
3. E.val = 4 (E→T) ... 此为 4*7 中的 4
4. F.val = 7
5. T.val = 7 (T→F)
6. T.val = 4×7 = 28 (T→T₁*F)
7. F.val = 1
8. E.val = 28+1 = 29 (E→E₁+T)
9. F.val = 2
10. T.val = 29×2 = 58 (T→T₁*F)
11. E.val = 58 (E→T)
12. L.val: print(58) → **结果为58**

## 第2题：逆波兰式（后缀表达式）

### (1) 2+3+a+b

$$\text{逆波兰式：} 2\ 3\ +\ a\ +\ b\ +$$

### (2) ab+2cd

> 注：ab 表示 a×b（隐式乘法），2cd 表示 2×c×d

$$\text{逆波兰式：} a\ b\ *\ 2\ c\ *\ d\ *\ +$$

### (3) (x=x+3)*4

$$\text{逆波兰式：} x\ x\ 3\ +\ =\ 4\ *$$

### (4) (x=y=2)+3*(x=4)

$$\text{逆波兰式：} x\ y\ 2\ =\ =\ 3\ x\ 4\ =\ *\ +$$

## 第3题：布尔表达式/语句的四元式翻译

### (1) a≠b and not c or d>c（起始标号10）

> 注：原题 ≠ 为 Symbol 字体符号（docx 内为 Symbol ¹），勿误读为 <。

```
10: (j≠,  a, b, 12)      -- a≠b 为真 → 12；为假则顺序执行
11: (j,   -, -, 14)      -- a=b ⇒ and 为假 → 转判 d>c
12: (jnz, c, -, 14)      -- c 为真 ⇒ not c 为假 → 转判 d>c
13: (j,   -, -, 17)      -- c 为假 ⇒ not c 为真 ⇒ 整体为真
14: (j>,  d, c, 17)      -- d>c 为真 ⇒ 整体为真
15: (j,   -, -, 16)      -- d>c 为假 ⇒ 整体为假
16: ...                  -- 整体为假的处理（E.false）
17: ...                  -- 整体为真的处理（E.true）
```

### (2) while a<b do if c<d then x:=y+z else x:=y-z

```
10: (j<, a, b, 12)       -- a<b 为真进入循环体
11: (j, -, -, 20)        -- a<b 为假退出循环
12: (j<, c, d, 14)       -- c<d 为真走 then 分支
13: (j, -, -, 17)        -- c<d 为假走 else 分支
14: (+, y, z, T1)        -- then: x:=y+z
15: (:=, T1, -, x)
16: (j, -, -, 10)        -- 跳回循环判断
17: (-, y, z, T2)        -- else: x:=y-z
18: (:=, T2, -, x)
19: (j, -, -, 10)        -- 跳回循环判断
20: ...                   -- 循环结束
```

## 第4题：FOR 循环的四元式翻译

> 程序片段：
> ```
> FOR K:=1 TO 10 DO
>   BEGIN
>     A:=I+10*K;
>     B:=J+10*K;
>   END
> ```

### 四元式中间代码

```
10: (:=, 1, -, K)         -- K:=1
11: (j<=, K, 10, 13)      -- K<=10 进入循环
12: (j, -, -, 22)         -- K>10 退出循环
13: (*, 10, K, T1)        -- 10*K
14: (+, I, T1, T2)        -- I+10*K
15: (:=, T2, -, A)        -- A:=I+10*K
16: (*, 10, K, T3)        -- 10*K
17: (+, J, T3, T4)        -- J+10*K
18: (:=, T4, -, B)        -- B:=J+10*K
19: (+, K, 1, T5)         -- K:=K+1
20: (:=, T5, -, K)
21: (j, -, -, 11)         -- 跳回循环判断
22: ...                    -- 循环结束
```

### 优化后的等价四元式代码

**优化1**：循环外提不变表达式（10*K 中 K 变化，但可提取公共子表达式）

**优化2**：强度削减（乘法变加法）

```
10: (:=, 1, -, K)
11: (*, 10, K, T1)        -- 10*K 可用递增替代
12: (+, I, T1, T2)
13: (:=, T2, -, A)
14: (+, J, T1, T3)        -- 复用 T1=10*K
15: (:=, T3, -, B)
16: (j>=, K, 10, 20)
17: (+, K, 1, K)          -- K++
18: (+, T1, 10, T1)       -- T1+=10 (强度削减)
19: (j, -, -, 12)
20: ...
```
