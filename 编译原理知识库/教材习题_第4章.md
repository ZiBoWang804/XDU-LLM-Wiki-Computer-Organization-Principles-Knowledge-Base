## 第1题
> 文法 G[S]: S→a|∧|(T), T→T,S|S

### (1) 最左推导

**(a,(a,a)) 的最左推导**：
```
S ⇒ (T)
  ⇒ (T,S)
  ⇒ (S,S)
  ⇒ (a,S)
  ⇒ (a,(T))
  ⇒ (a,(T,S))
  ⇒ (a,(S,S))
  ⇒ (a,(a,S))
  ⇒ (a,(a,a))
```

**(((a,a),∧,(a)),a) 的最左推导**：
```
S ⇒ (T)
  ⇒ (T,S)
  ⇒ (S,S)
  ⇒ ((T),S)
  ⇒ ((T,S),S)
  ⇒ ((S,S),S)
  ⇒ (((T),S),S)
  ⇒ (((T,S),S),S)
  ⇒ (((S,S),S),S)
  ⇒ (((a,S),S),S)
  ⇒ (((a,a),S),S)
  ⇒ (((a,a),(T)),S)
  ⇒ (((a,a),(T,S)),S)
  ⇒ (((a,a),(S,S)),S)
  ⇒ (((a,a),(∧,S)),S)
  ⇒ (((a,a),(∧,a)),S)
  ⇒ (((a,a),(∧,a)),a)
```

### (2) 改写文法并写出递归子程序

**消除左递归**：
```
S → a | ∧ | (T)
T → ST'
T' → ,ST' | ε
```

**递归子程序**：

```c
void ParseS() {
    switch(lookahead) {
        case 'a': Match('a'); break;
        case '∧': Match('∧'); break;
        case '(': Match('('); ParseT(); Match(')'); break;
        default: error();
    }
}

void ParseT() {
    ParseS();
    ParseT_();
}

void ParseT_() {
    switch(lookahead) {
        case ',': Match(','); ParseS(); ParseT_(); break;
        case ')': break;  // T'→ε
        default: error();
    }
}
```

### (3) 是否是LL(1)文法

计算FIRST集和FOLLOW集：
```
FIRST(S)  = {a, ∧, (}
FIRST(T)  = {a, ∧, (}
FIRST(T') = {,, ε}
FOLLOW(S)  = {,, ), #}
FOLLOW(T)  = {)}
FOLLOW(T') = {)}
```

SELECT集：
```
SELECT(S→a)   = {a}
SELECT(S→∧)   = {∧}
SELECT(S→(T)) = {(}
SELECT(T→ST') = FIRST(S) = {a, ∧, (}
SELECT(T'→,ST') = {,}
SELECT(T'→ε)  = FOLLOW(T') = {)}
```

验证：同一左部产生式的SELECT交集：
- SELECT(S→a) ∩ SELECT(S→∧) ∩ SELECT(S→(T)) = ∅ ✓
- SELECT(T'→,ST') ∩ SELECT(T'→ε) = ∅ ✓

**是LL(1)文法。**

**预测分析表**：

| 非终结符 | a | ∧ | ( | ) | , |
|---------|---|---|---|---|---|
| S | S→a | S→∧ | S→(T) | | |
| T | T→ST' | T→ST' | T→ST' | | |
| T' | | | | T'→ε | T'→,ST' |

### (4) 输入串 (a,a)# 的分析过程

| 步骤 | 符号栈 | 输入串 | 动作 |
|------|--------|--------|------|
| 1 | #S | (a,a)# | S→(T) |
| 2 | #)T( | (a,a)# | 匹配 ( |
| 3 | #)T | a,a)# | T→ST' |
| 4 | #)T'S | a,a)# | S→a，匹配 a |
| 5 | #)T' | ,a)# | T'→,ST' |
| 6 | #)T'S, | ,a)# | 匹配 , |
| 7 | #)T'S | a)# | S→a，匹配 a |
| 8 | #)T' | )# | T'→ε |
| 9 | #) | )# | 匹配 ) |
| 10 | # | # | **接受** |

串 (a,a) 是 G 的句子 ✓

## 第2题
> E→TE', E'→+E|ε, T→FT', T'→T|ε, F→PF', F'→*F'|ε, P→(E)|a|b|^

### (1) FIRST集和FOLLOW集

**FIRST集**：
```
FIRST(E)  = FIRST(T) = FIRST(F) = FIRST(P) = {(, a, b, ^}
FIRST(E') = {+, ε}
FIRST(T') = FIRST(T) ∪ {ε} = {(, a, b, ^, ε}
FIRST(F') = {*, ε}
```

**FOLLOW集**：
```
FOLLOW(E)  = {), #}
FOLLOW(E') = FOLLOW(E) = {), #}
FOLLOW(T)  = FIRST(E')\{ε} ∪ FOLLOW(E) ∪ FOLLOW(E') = {+, ), #}
FOLLOW(T') = FOLLOW(T) = {+, ), #}
FOLLOW(F)  = FIRST(T')\{ε} ∪ FOLLOW(T) ∪ FOLLOW(T') = {(, a, b, ^, +, ), #}
FOLLOW(F') = FOLLOW(F) = {(, a, b, ^, +, ), #}
FOLLOW(P)  = FIRST(F')\{ε} ∪ FOLLOW(F) ∪ FOLLOW(F') = {*, (, a, b, ^, +, ), #}
```

### (2) 证明是LL(1)文法

验证每个非终结符相同左部产生式的SELECT交集为空：

```
SELECT(E'→+E) = {+}
SELECT(E'→ε)  = FOLLOW(E') = {), #}
交集 = ∅ ✓

SELECT(T'→T) = FIRST(T) = {(, a, b, ^}
SELECT(T'→ε) = FOLLOW(T') = {+, ), #}
交集 = ∅ ✓

SELECT(F'→*F') = {*}
SELECT(F'→ε)   = FOLLOW(F') = {(, a, b, ^, +, ), #}
交集 = ∅ ✓

SELECT(P→(E)) = {(}
SELECT(P→a)   = {a}
SELECT(P→b)   = {b}
SELECT(P→^)   = {^}
交集两两为空 ✓
```

**是LL(1)文法。**

### (3) 预测分析表

| 非终结符 | ( | ) | a | b | ^ | + | * | # |
|---------|---|---|---|---|---|---|---|---|
| E | TE' | | TE' | TE' | TE' | | | |
| E' | | E'→ε | | | | E'→+E | | E'→ε |
| T | FT' | | FT' | FT' | FT' | | | |
| T' | T'→T | T'→ε | T'→T | T'→T | T'→T | T'→ε | | |
| F | PF' | | PF' | PF' | PF' | | | |
| F' | F'→ε | F'→ε | F'→ε | F'→ε | F'→ε | F'→ε | F'→*F' | |
| P | P→(E) | | P→a | P→b | P→^ | | | |

### (4) 递归下降分析程序

```c
void ParseE()  { ParseT(); ParseE_(); }
void ParseE_() {
    if (lookahead == '+') { Match('+'); ParseE(); }
    // else E'→ε, do nothing
}
void ParseT()  { ParseF(); ParseT_(); }
void ParseT_() {
    if (lookahead ∈ FIRST(T)) { ParseT(); }
    // else T'→ε, do nothing
}
void ParseF()  { ParseP(); ParseF_(); }
void ParseF_() {
    if (lookahead == '*') { Match('*'); ParseF_(); }
    // else F'→ε, do nothing
}
void ParseP() {
    switch(lookahead) {
        case '(': Match('('); ParseE(); Match(')'); break;
        case 'a': Match('a'); break;
        case 'b': Match('b'); break;
        case '^': Match('^'); break;
        default: error();
    }
}
```

## 第3题
> G[S]: S→MH|a, H→LSo|ε, K→dML|ε, L→eHf, M→K|bLM
> 判断G是否是LL(1)文法。

**计算FIRST集**：
```
FIRST(S) = FIRST(M) ∪ {a} = {d, ε, b, a} → 实际为 {d, b, a}
FIRST(H) = FIRST(L) ∪ {ε} = {e, ε}
FIRST(K) = {d, ε}
FIRST(L) = {e}
FIRST(M) = FIRST(K) ∪ {b} = {d, ε, b}
```

**SELECT集分析**：
- M→K 的 SELECT = (FIRST(K)\{ε}) ∪ FOLLOW(M) = {d} ∪ FOLLOW(M)
- M→bLM 的 SELECT = {b}

若 FOLLOW(M) ∩ {b} ≠ ∅ 则不是LL(1)。

完整计算（见 [[期末复习专题#题型6 自顶向下分析：LL(1) 分析表（FIRST/FOLLOW/SELECT）]] 6.7 补全解）：FOLLOW(S)={#,o}，FOLLOW(M)={e,#,o}，FOLLOW(H)={f,#,o}，FOLLOW(K)={e,#,o}，FOLLOW(L)={a,b,d,e,#,o}；M→K 的 SELECT={d,e,#,o} 与 M→bLM 的 {b} 不交，H/K/S 各组亦不交 ⇒ **G 是 LL(1) 文法**。

## 第4题
> 证明文法不是LL(1)的。
> S→CS, C→bA|aB, A→a|aC|bAA, B→b|bC|aBB

**证明**：

A→a 和 A→aC：
```
SELECT(A→a)  = {a}
SELECT(A→aC) = {a}
交集 = {a} ≠ ∅
```

**不是LL(1)文法。**

**能否改写为LL(1)**：

提取左公共因子：
```
A → aA' | bAA
A' → C | ε
```

但 C→bA|aB 仍可能有问题。改写后需重新验证。该文法本质上描述的是 a 和 b 个数相等的语言，可能无法完全改为LL(1)。

## 第5题
> 文法 G 改写为LL(1)文法。

原问题涉及条件语句的悬挂else问题。

**改写**：
```
<程序> → begin <语句表> end
<语句表> → <语句> <语句表'>
<语句表'> → ; <语句> <语句表'> | ε
<语句> → <无条件语句> | <条件语句>
<条件语句> → <如果子句> <无条件语句> <否则部分>
<否则部分> → else <语句> | ε
<如果子句> → if b then
```

关键改动：将 `else<语句>` 作为可选部分（<否则部分>），用SELECT集区分。

## 第6题
> 判断哪些文法是LL(1)的。

### (1) S→A|B, A→aA|a, B→bB|b

A→aA 和 A→a 有左公共因子 → 提取后：
```
A → aA' | a → A → a(A' | ε)，A' → aA' | ε
```
改写后可能是LL(1)。

### (2) S→AB, A→Ba|ε, B→Db|D, D→d|ε

需计算SELECT集验证。

### (3) S→aAaB|bAbB, A→S|d, B→bB|a

B→bB 和后续产生式需验证。

### (4) S→i|(E), E→E+S|E-S|S

E有左递归 → 消除后：
```
E → SE'
E' → +SE' | -SE' | ε
```
改写后是LL(1)。

### (5) S→SaA|bB, A→aB|c, B→Bb|d

S和B都有左递归 → 消除后可能是LL(1)。

### (6) M→MaH|H, H→b(M)|(M)|b

M有左递归 → 消除后：
```
M → HM'
M' → aHM' | ε
```
改写后是LL(1)。

> <bterm>→<bterm>and<bfactor>|<bfactor>

```

FOLLOW(<bexpr>) = {), #}

FOLLOW(<bfactor>) = {and, or, ), #}
```

## 第10题
> 为语言 L={w|w∈(a|b)* 且 w 中 a、b 个数相等} 写一LL(1)文法。

**答案**：
```
S → aA | bB | ε
A → bS | aAA
B → aS | bBB
```

**验证**：
- S 产生 a 和 b 个数相等的串
- aA：多了一个 a，需要 A 来平衡
- A→bS：用一个 b 消耗掉多出的 a
- A→aAA：再多一个 a，交给两个 A 去平衡

**LL(1)验证**：
```
SELECT(S→aA) = {a}
SELECT(S→bB) = {b}
SELECT(S→ε)  = FOLLOW(S) = {#}
交集为空 ✓
```

是LL(1)文法。
