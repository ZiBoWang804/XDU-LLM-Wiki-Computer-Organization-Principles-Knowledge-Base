# 语义分析与中间代码生成

> **所属章节**：第7章 语义分析与中间代码生成
> **核心问题**：类型检查、四元式、三元式、布尔表达式翻译、控制流翻译

---

## 7.1 语义分析的任务

1. **类型检查**：验证类型是否匹配（如 int + string 报错）
2. **类型转换**：自动类型提升（如 int → float）
3. **作用域分析**：变量的可见性和生命周期
4. **语义信息收集**：填写符号表

---

## 7.2 中间代码的形式

### 三地址代码

每条指令最多三个操作数：`x := y op z`

### 四元式

```
(op, arg1, arg2, result)
```

| 字段 | 含义 |
|------|------|
| op | 运算符 |
| arg1 | 第一个操作数 |
| arg2 | 第二个操作数 |
| result | 结果 |

#### 示例

`a := b + c * d` 的四元式：
```
(1) (*, c, d, T1)
(2) (+, b, T1, T2)
(3) (:=, T2, -, a)
```

### 三元式

```
(op, arg1, arg2)
```

结果用**三元式编号**引用（如 (1)、(2)），不需要临时变量。

### 间接三元式

- **间接码表**：按执行顺序存放三元式编号
- **三元式表**：存放实际运算

## 7.3 布尔表达式的翻译

### 布尔表达式

$$E \to E \text{ and } E \mid E \text{ or } E \mid \text{not } E \mid \text{id relop id}$$

### 翻译方法

#### 方法1：数值计算法
- true = 1, false = 0
- 用四元式计算布尔值

#### 方法2：控制流法（跳转法）
- 不实际计算 true/false 值
- 用**标号**记录跳转目标
- 适合 if-then-else 和 while 语句

### 控制流翻译中的标号管理

- **E.true**：E 为真时跳转的标号
- **E.false**：E 为假时跳转的标号

| 产生式 | 翻译规则 |
|--------|---------|
| E → E₁ and E₂ | E₁.true := newlabel; E₁.false := E.false; E₂.true := E.true; E₂.false := E.false |
| E → E₁ or E₂ | E₁.true := E.true; E₁.false := newlabel; E₂.true := E.true; E₂.false := E.false |
| E → not E₁ | E₁.true := E.false; E₁.false := E.true |

## 7.4 控制语句的翻译

### if-then-else

```
if E then S1 else S2
```

四元式翻译：
```
E.true → L1
E.false → L2
L1: S1的四元式
    goto L3
L2: S2的四元式
L3: ...
```

### while-do

```
while E do S
```

四元式翻译：
```
L1: E的四元式
    E.true → L2
    E.false → L3
L2: S的四元式
    goto L1
L3: ...
```

### 短路求值

- `a and b`：若 a 为 false，不计算 b，直接跳转到 false
- `a or b`：若 a 为 true，不计算 b，直接跳转到 true

## 7.5 数组引用的翻译

数组元素地址计算：

$$\text{addr}(A[i]) = \text{base} + (i - \text{low}) \times w$$

其中：
- base：数组首地址
- low：下标下界
- w：每个元素的宽度

---

## 7.6 过程调用的翻译

参数传递方式：
1. **值传递**（call by value）
2. **引用传递**（call by reference）
3. **值结果传递**（call by value-result）

## 典型例题

### 例：布尔表达式四元式

`a≠b and not c or d>c`（起始标号10）：
```
10: (j≠,  a, b, 12)      -- a≠b 为真 → 12；为假则顺序执行
11: (j,   -, -, 14)      -- a=b ⇒ and 为假 → 转判 d>c
12: (jnz, c, -, 14)      -- c 为真 ⇒ not c 为假 → 转判 d>c
13: (j,   -, -, 17)      -- c 为假 ⇒ not c 为真 ⇒ 整体为真
14: (j>,  d, c, 17)      -- d>c 为真 ⇒ 整体为真
15: (j,   -, -, 16)      -- d>c 为假 ⇒ 整体为假
16: ...                  -- 整体为假的处理（E.false）
17: ...                  -- 整体为真的处理（E.true）
```
