## 第一部分 文法 → 语言，并判断类型（第 1–3 题）

> **第 1 题**：G[S]：S→aS | bB | c，B→bB | c。求 L(G)，并判断文法类型与语言类型。

**答案**（多种等价写法）：

| 形式 | 写法 |
|---|---|
| 集合式 | $L(G)=\{a^i b^j c \mid i,\ j \ge 0\}$ |
| 正规式 | $a^* b^* c$ |
| 文字 | 任意个 a、任意个 b 后固定跟一个 c |
| 例子 | ✓：c、ac、bc、abc、aabc、abbc；✗：ab、cb、cab |

文法 **3 型（右线性）**、语言**正规**。

**解析**：
1. 结构：S→aS 前端加 a；S→bB 入 b 段（B→bB 加 b，B→c 收口）；S→c 直接收口。
2. 正向：$i$ 次 aS、$j$ 次 bB/c ⇒ $a^i b^j c$；反向：先剥首部 $i$ 个 a，$j=0$ 走 S→c，$j\ge 1$ 走 S→bB 再 $j-1$ 次 B→bB、B→c。
3. 类型：五条右部都是 $aB$ 或 $a$ 形 ⇒ **3 型**。

> **第 2 题**：G[S]：S→aSb | b。求 L(G)，并判断文法类型与语言类型。

**答案**（多种等价写法）：

| 形式 | 写法 |
|---|---|
| 集合式 | $L(G)=\{a^n b^{n+1} \mid n \ge 0\}$（等价写法 $\{a^{n-1} b^{n} \mid n \ge 1\}$） |
| 文字 | a、b 交替配对后多出一个 b（b 恒比 a 多 1，a 全在前） |
| 例子 | ✓：b、abb、aabbb、aaabbbb；✗：ab、bb |

文法 **2 型**、语言**非正规**。

**解析**：
1. 结构：S→b 是出口（贡献 1 个 b）；S→aSb 每层两头各加一个 a、一个 b ⇒ b 恒多 1。
2. 正向：$n$ 层 aSb 后落 b ⇒ $a^n b^{n+1}$；反向：首 a 尾 b 则剥一对递归，最终落到 b。
3. 核对：n=2：$S \Rightarrow aSb \Rightarrow a(aSb)b \Rightarrow a(b)bb$ = "aabbb" ✓。
4. 类型：S→aSb 非右线性 ⇒ **2 型**；两边计数差 1 配对 ⇒ 非正规。

> **第 3 题**：G[S]：S→abS | baS | ε。求 L(G)，并判断文法类型与语言类型。

**答案**（多种等价写法）：

| 形式 | 写法 |
|---|---|
| 正规式 | $L(G)=(ab \mid ba)^*$ |
| 集合式 | $\{w \mid w \text{ 每 2 字符一段，每段是 ab 或 ba}\}$（含 ε） |
| 例子 | ✓：ab、ba、abab、abba、baab、baba；✗：aabb、aab |

文法 **2 型（非 3 型）**、语言**正规**。

**解析**：
1. 结构：S→abS、S→baS 前端吐一个块再递归，S→ε 是出口。
2. 正反向：正向逐块吐出；反向按每 2 字符切段（必为 ab/ba），从右往左用 abS/baS 追回。
3. 类型：右部 "abS" 是**两个终结符 + 非终结符**，不是 $A \to aB \mid a$ 形 ⇒ **不是 3 型**（语言虽正规）。

> [!warning] 语言正规 ≠ 文法 3 型
> 判类型判的是**文法形式**。要写 3 型须拆开：$S \to aA \mid bB \mid \varepsilon$，$A \to bS \mid b$，$B \to aS \mid a$（对照 [[期末复习专题#2.3 易错点|题型2 易错点]]）。

## 第二部分 语言 → 文法，并判断类型（第 4–6 题，答案均不唯一）

> **第 4 题**：写一文法 G，使 $L(G)=\{a^m b^n \mid n \ge m \ge 0\}$（b 不少于 a），并判断文法类型。

**答案**（不唯一）：

```
S → aSb | T
T → Tb | ε
```

**另一种**：S→aSb|T，T→bT|ε（b 加在 T 前端，语言相同）。文法 **2 型**、语言**非正规**。

**解析**：
1. 结构：S→aSb 每层配一对 a、b（共 m 层）；T→Tb|ε 只补尾部 b，补足 $n-m$ 个。
2. 正向：$k$ 次 aSb + $T \Rightarrow b^{\,j}$ ⇒ $a^k b^{k+j}$；反向：取 $k=m$、$j=n-m$。
3. 边界：ε（m=n=0）✓；"aabb"（m=n）✓；"aaab"（m>n）✗。

> [!tip] 对比模拟卷第 4 题
> [[期末复习-模拟卷]] 第 4 题是 $n>m$（a 恒多）；本题 $n \ge m$（b 恒多可相等），出口 **T→ε 放行 n=m**。

> **第 5 题**：写一文法 G，使 $L(G)=\{ww^R \mid w \in \{a,b\}^*\}$（偶数长度回文，含 ε），并判断文法类型。

**答案**（不唯一）：

```
S → aSa | bSb | ε
```

**另一种**：S→aA|bB|ε，A→Sa|a，B→Sb|b（先内后外的写法）。文法 **2 型**、语言**非正规**。

**解析**：
1. 结构：每层两头加相同符号（长度 +2），出口 ε ⇒ 偶长回文。
2. 正反向：正向对称包裹；反向剥最外层一对递归落到 ε。
3. 边界：ε、aa、bb、abba、baab ✓；aba（奇长）、ab ✗。

> [!tip] 出口决定奇偶
> [[期末复习-模拟卷]] 第 7 题奇长回文出口是**单字符**；本题偶长回文出口是 **ε**。

> **第 6 题**：写一文法 G，使 $L(G)=\{w \in \{0,1\}^* \mid w \text{ 中不含子串 } 11\}$（含 ε），并判断文法类型。

**答案**（不唯一）：

```
S → 0S | 1A | ε
A → 0S | ε
```

**另一种**：S→0S|10S|1|ε（把"1 后必跟 0"直接写进产生式）。文法 **3 型（右线性）**、语言**正规**。

**解析**：
1. 状态读法：S = 开头或刚读完 0（下个随便）；A = 刚读完 1（下个只能 0 或结束）。S→0S / S→1A / A→0S / ε 收口。
2. 正反向：正向路径不可能连读两个 1；反向逐字符走 S/A 转移。
3. 边界：ε、0、1、01、10、1010 ✓；11、011、110 ✗；核对 "101"：$S \Rightarrow 1A \Rightarrow 10S \Rightarrow 101A \Rightarrow 101$ ✓。

## 第三部分 LR(1) 文法：增广文法 / 项目族 / DFA / 判定 / 分析表 / 分析过程（第 7–9 题）

> **判定三步模板（三题通用）**
> ① **LR(0)**：指出哪几个项目集里"归约项 + 移进项（或两个归约项）"并存 ⇒ 有冲突/无冲突。
> ② **SLR(1)**：算**哪个 FOLLOW 集** → 与**哪个终结符**（冲突处移进项圆点后的符号）求交 → 写结果 ∅/非∅ ⇒ 结论。
> ③ **LR(1)**：把归约项的**展望符**与移进终结符（或另一归约项展望符）求交 → 写结果 ⇒ 结论。

### 第 7 题

> **第 7 题**：G[S]：S→Aa | bAc | dc | bda，A→d。
> (1) 增广文法并编号；(2) LR(1) 项目集规范族（含展望符）与 DFA；(3) 判定 LR(0)/SLR(1)/LR(1)；(4) 展望符与 LR(1) 分析表；(5) 句子 **da** 的分析过程。

**解 (1) 增广文法**：

```
0. S' → S
1. S  → Aa
2. S  → bAc
3. S  → dc
4. S  → bda
5. A  → d
```

终结符 $\{a,b,c,d\}$，非终结符 $\{S',S,A\}$，开始符 $S$。

**解 (2) 项目集与 DFA**

展望符怎么来（本题两个种子，逐个算）：

| 加进来的项目 | 依据项目 | 该处 A 后跟什么 | FIRST | 展望符 |
|---|---|---|---|---|
| A→·d, a | S→·Aa, # | a# | {a} | a |
| A→·d, c | S→b·Ac, # | c# | {c} | c |

**同一产生式 A→d 在不同状态展望符不同**——各状态各算，别互相抄。

| 项目集 | 内容（· 为圆点，逗号后为展望符） |
|---|---|
| I0 | S'→·S, #；S→·Aa, #；S→·bAc, #；S→·dc, #；S→·bda, #；A→·d, a |
| I1 | S'→S·, #（接受） |
| I2 | S→A·a, # |
| I3 | S→b·Ac, #；S→b·da, #；A→·d, c |
| I4 | **S→d·c, #**；**A→d·, a** |
| I5 | S→Aa·, # |
| I6 | S→bA·c, # |
| I7 | **S→bd·a, #**；**A→d·, c** |
| I8 | S→dc·, # |
| I9 | S→bAc·, # |
| I10 | S→bda·, # |

DFA（GOTO）：I0 --S→ I1，--A→ I2，--b→ I3，--d→ I4；I2 --a→ I5；I3 --A→ I6，--d→ I7；I4 --c→ I8；I6 --c→ I9；I7 --a→ I10。关键状态 I4、I7（归约项与移进项并存）。

**解 (3) 判定**：
1. **LR(0)**：I4 内 A→d·（归约）与 S→d·c（移进 c）并存；I7 内 A→d· 与 S→bd·a（移进 a）并存 ⇒ 移进-归约冲突 ⇒ **不是 LR(0)**。
2. **SLR(1)**：求 **FOLLOW(A)**：A 后可跟 a（S→Aa）、c（S→bAc）⇒ $FOLLOW(A)=\{a,c\}$。与移进终结符求交：I4 处 $FOLLOW(A) \cap \{c\} = \{c\} \neq \emptyset$；I7 处 $FOLLOW(A) \cap \{a\} = \{a\} \neq \emptyset$ ⇒ 交集非空、冲突消不掉 ⇒ **不是 SLR(1)**。
3. **LR(1)**：展望符求交：I4 处 $\{a\} \cap \{c\} = \emptyset$；I7 处 $\{c\} \cap \{a\} = \emptyset$ ⇒ 无冲突，其余各集无冲突 ⇒ **是 LR(1)**。

**解 (4) 展望符与 LR(1) 分析表**

| 项目 | 状态 | 展望符 |
|---|---|---|
| A→d· | I4 | { a } |
| A→d· | I7 | { c } |
| S→Aa· / S→dc· / S→bAc· / S→bda· | I5 / I8 / I9 / I10 | { # } |
| S'→S· | I1 | { # }（acc） |

分析表（s=移进，r=归约，编号同解(1)）：

| 状态 | a | b | c | d | # | S | A |
|---|---|---|---|---|---|---|---|
| 0 | | s3 | | s4 | | 1 | 2 |
| 1 | | | | | acc | | |
| 2 | s5 | | | | | | |
| 3 | | | | s7 | | | 6 |
| 4 | r5 | | s8 | | | | |
| 5 | | | | | r1 | | |
| 6 | | | s9 | | | | |
| 7 | s10 | | r5 | | | | |

| 9 | | | | | r2 | | |
| 10 | | | | | r4 | | |

**解 (5) 句子 da 的分析过程**（归约的 GOTO 单独一行，步骤号顺序编）：

| 步骤 | 状态栈 | 符号栈 | 输入 | 动作 |
|---|---|---|---|---|
| 1 | 0 | # | da# | s4：移进 d |
| 2 | 0 4 | #d | a# | r5：A→d（展望符 a ✓），弹 1 态 |
| 3 | 0 | # | a# | GOTO(0,A)=2 |

> 1. 归约只填**展望符列**：r5 在 I4 只填 a 列、I7 只填 c 列，别按 FOLLOW 填两列。
> 2. 判定写全三步，每步带**状态号 + 集合 + 交运算结果**。

### 第 8 题

> **第 8 题（进阶·三非终结符·DFA 带环）**：G[S]：S→L=R | R，L→*R | i，R→L。
> (1) 增广文法并编号；(2) LR(1) 项目集规范族（含展望符）与 DFA（指出环）；(3) 判定 LR(0)/SLR(1)/LR(1)；(4) 展望符与 LR(1) 分析表；(5) 句子 **i=i** 的分析过程。

**解 (1) 增广文法**：

```
0. S' → S
1. S  → L = R
2. S  → R
3. L  → * R
4. L  → i
5. R  → L
```

终结符 $\{=,\ *,\ i\}$，非终结符 $\{S,L,R\}$，开始符 $S$。

**解 (2) 项目集与 DFA**

**展望符合并展开（"=/#" 怎么来的，逐链算、别漏）**：

| 谁把 L 的产生式加进来（种子） | 该处 L 后跟的串 | FIRST | 并入展望符 |
|---|---|---|---|
| S→·L=R, # | =R# | {=} | = |
| R→·L, #（来自 S→·R, #） | # | {#} | # |

1. 同一状态里**同一条产生式只写一次**，展望符取**并** ⇒ L→·\*R, =/#、L→·i, =/#。
2. **各状态各算，种子从哪来展望符就是哪套**：I6 的种子是 S→L=·R, #（只有 #）⇒ L→·i, #（**不是** =/#）；I4 的种子是 I0 带来的 L→\*·R, =/#，CLOSURE 按 β=空 展开（R→·L 的展望符 = 种子 =/#，再传给 L 的产生式）⇒ I4 全部 =/#。
3. I11 的种子是 L→\*·R, # ⇒ 全部只有 #。**成对状态（I4/I11、I5/I12、I7/I13、I8/I10）核心相同、展望符不同，是不同状态，判 LR(1) 不许合并。**

| 项目集 | 内容（=/# 即 {=, #}） |
|---|---|
| I0 | S'→·S, #；S→·L=R, #；S→·R, #；R→·L, #；L→·\*R, =/#；L→·i, =/# |
| I1 | S'→S·, #（接受） |
| I2 | **S→L·=R, #**；**R→L·, #** |
| I3 | S→R·, # |
| I4 | L→\*·R, =/#；R→·L, =/#；L→·\*R, =/#；L→·i, =/# |
| I5 | L→i·, =/# |
| I6 | S→L=·R, #；R→·L, #；L→·\*R, #；L→·i, # |
| I7 | L→\*R·, =/# |
| I8 | R→L·, =/# |
| I9 | S→L=R·, # |
| I10 | R→L·, # |
| I11 | L→\*·R, #；R→·L, #；L→·\*R, #；L→·i, # |
| I12 | L→i·, # |
| I13 | L→\*R·, # |

DFA（GOTO）：I0 --S→ I1，--L→ I2，--R→ I3，--\*→ I4，--i→ I5；I2 --=→ I6；I4 --R→ I7，--L→ I8，--\*→ **I4（自环）**，--i→ I5；I6 --R→ I9，--L→ I10，--\*→ I11，--i→ I12；I11 --R→ I13，--L→ I10，--\*→ **I11（自环）**，--i→ I12。环：I4、I11 在 \* 上自环（读几个 \* 绕几圈）。

**解 (3) 判定**：
1. **LR(0)**：I2 内 R→L·（归约）与 S→L·=R（移进 =）并存 ⇒ 移进-归约冲突 ⇒ **不是 LR(0)**。
2. **SLR(1)**：求 **FOLLOW(R)**：R 后可跟 =（R→L 后接 S→L=R 的 =）、#（S→R 句尾），R→L 与 L→\*R 尾部互传 ⇒ $FOLLOW(R)=FOLLOW(L)=\{=,\#\}$。与移进终结符求交：I2 处 $FOLLOW(R) \cap \{=\} = \{=\} \neq \emptyset$ ⇒ **不是 SLR(1)**。
3. **LR(1)**：展望符求交：I2 处 $\{ \# \} \cap \{ = \} = \emptyset$（R→L· 只在 # 归约，= 只移进）⇒ 无冲突，其余各集无冲突 ⇒ **是 LR(1)**。

### 第 9 题

> **第 9 题（进阶2·四终结符·DFA 带环）**：G[S]：S→L=R | L<R | R，L→*R | i，R→L（终结符 $=,<,*,i$ 四个，不含 #）。
> (1) 增广文法并编号；(2) LR(1) 项目集规范族（含展望符）与 DFA（指出环）；(3) 判定 LR(0)/SLR(1)/LR(1)；(4) 展望符与 LR(1) 分析表；(5) 句子 **\*\*i<i** 的分析过程。

**解 (1) 增广文法**：

```
0. S' → S
1. S  → L = R
2. S  → L < R
3. S  → R
4. L  → * R
5. L  → i
6. R  → L
```

## 第四部分 逆波兰式（第 10–12 题）

> **第 10 题**：写出布尔表达式 `not a and b ≤ c or d` 的逆波兰式。

**答案**：`a not b c ≤ and d or`

**解析**：
1. 优先级 not > ≤ > and > or ⇒ 树 $((\neg a) \wedge (b \le c)) \vee d$。
2. 后序：`a not`、`b c ≤`、and、d、or ⇒ `a not b c ≤ and d or`。

> **第 11 题**：写出算术表达式 `a*(b−c)−d/e` 的逆波兰式。

**答案**：`a b c − * d e / −`

**解析**：
1. 括号先算 $b-c$ ⇒ `b c −`；\* 与 / 各自先于 − ⇒ `a b c − *`、`d e /`。
2. 最后的 − **左结合** ⇒ `a b c − * d e / −`；误写 `a b c − * d e − /` 值就变了。

> **第 12 题**：写出赋值表达式 `x = y = a + b*2` 的逆波兰式。

**答案**：`x y a b 2 * + = =`

**解析**：
1. 优先级 \* > + > = ⇒ 先 `a b 2 * +`。
2. = **右结合**：$x=(y=(a+b*2))$ ⇒ `y a b 2 * + =` 外面再套 x ⇒ `x y a b 2 * + = =`；左结合写法 `x y = …` 无意义。

## 第五部分 四元式（第 13–15 题）

**本卷风格**：① 条件跳转用**取反条件**跳假出口/出口，真出口靠顺序落下；② 表达式结果**直接写目标变量**，无临时变量、无独立 := 式；③ jz = 为假（零）跳，jnz = 为真（非零）跳。（若考试要求 $( := , T, -, x )$ 两条式，把结果行拆成"算入 T + 赋给目标"即可。）

**运算符优先级关系表**（定表达式树用）：

| 级（高→低） | 运算符 | 结合性 |
|---|---|---|
| 1 | ( ) | — |
| 2 | 一元 not、一元负号 − | 右结合 |
| 3 | \* / | 左结合 |
| 4 | 二元 + − | 左结合 |
| 5 | 关系 < ≤ > ≥ = ≠ | 左结合 |
| 6 | and | 左结合 |
| 7 | or | 左结合 |
| 8 | 赋值（:= / =） | 右结合 |

> **第 13 题**：把布尔表达式 `a>b or c and not d` 翻译成四元式序列（跳转法，假定起始标号 10）。

**答案**（13 = E.true，14 = E.false）：

| 标号 | 四元式 | 说明 |
|---|---|---|
| 10 | (j>, a, b, 13) | a>b 为真 → 13（整体真）；为假则顺序执行 |
| 11 | (jz, c, -, 14) | c 为假 ⇒ and 为假 → 14（整体假）；c 真则继续 |
| 12 | (jnz, d, -, 14) | d 为真 ⇒ not d 假 ⇒ 整体假 → 14；d 假则落到 13 |
| 13 | ... | E.true |
| 14 | ... | E.false |

**解析**：
1. 按优先级（not > > and > or）：原式 $=(a>b) \vee (c \wedge \neg d)$。
2. or：a>b 为真直跳 13；为假走右部 $c \wedge \neg d$。
3. and：c 为假 ⇒ 整体假（11→14）；c 为真再判 $\neg d$。
4. not：d 真 ⇒ 整体假（12→14）；d 假 ⇒ 整体真，**顺序落 13**。

> **第 14 题**：把语句 `if x>0 then y:=x+1 else y:=x−1` 翻译成四元式序列（假定起始标号 10）。

**答案**（14 = 出口）：

| 标号 | 四元式 | 说明 |
|---|---|---|
| 10 | (j<=, x, 0, 13) | x≤0（条件取反）→ 13（else 段）；x>0 则顺序进 then |
| 11 | (+, x, 1, y) | then：y := x+1（结果直接写 y） |
| 12 | (j, -, -, 14) | then 做完 → 14，**跳过 else** |
| 13 | (-, x, 1, y) | else：y := x-1 |
| 14 | ... | 出口 |

**解析**：
1. 条件取反跳：x>0 的假分支是 x≤0 ⇒ 10 直接跳 else（13）；真分支顺序落下进 then。
2. (+,x,1,y)、(-,x,1,y) 一条式即一条赋值，无临时变量。
3. **12 别漏**：then 尾不跳就会跌进 else，y 被再赋一次。

> **第 15 题**：把语句 `while a<b do a:=a+b` 翻译成四元式序列（假定起始标号 10）。

**答案**（13 = 循环出口）：

| 标号 | 四元式 | 说明 |
|---|---|---|
| 10 | (j>=, a, b, 13) | a≥b（条件取反）→ 13（出口）；a<b 则顺序进循环体 |
| 11 | (+, a, b, a) | 循环体：a := a+b |
| 12 | (j, -, -, 10) | **回跳判断**（最易漏！指回 10 不是 11） |
| 13 | ... | 循环出口 |

**解析**：
1. 条件取反跳出口：a<b 的假分支是 a≥b ⇒ 10 跳 13；真分支顺序落 11 进体。
2. (+,a,b,a) 即 a:=a+b。
3. **回跳 12 必留**且必须指回**判断那条**（10）。

> [!warning] 四元式易错
> 1. 取反条件方向别弄反：跳的若是假出口，条件就写取反（j<=、j>=、jz）。
> 2. while 必须回跳 10；if-else 的 then 尾必须跳出口。
> 3. 标号从 10 起连续编；jz = 零跳、jnz = 非零跳。
