# 专题 7：中间代码（逆波兰式 / 三元式 / 四元式） — 全库题目与答案汇编

> **题型定义**：表达式→逆波兰式（后缀式）、翻译为三元式/四元式（布尔表达式跳转法、if/while/FOR 控制语句）、语法制导翻译。
> **优先级关系表（定表达式树用）**：1 ( )；2 一元 not、一元负号（右结合）；3 \* /（左结合）；4 二元 + −（左结合）；5 关系 < ≤ > ≥ ≠（左结合）；6 and（左结合）；7 or（左结合）；8 赋值 =/:=（右结合）。
> **两种四元式风格**：经典式 $( := , T, -, x )$ 两条（先算进 T 再赋值）与简洁式（结果槽直接写目标变量、条件取反跳）——见各题标注。

## 一、逆波兰式

### 1. 三小题（出处：[[期末复习-强化卷2-LR1与中间代码]] 第 10–12 题）
**答案**：
- `not a and b ≤ c or d` ⇒ **`a not b c ≤ and d or`**（not > ≤ > and > or ⇒ ((¬a)∧(b≤c))∨d）；
- `a*(b-c)-d/e` ⇒ **`a b c − * d e / −`**（括号先算；− 左结合，误写 `… d e − /` 值就变）；
- `x = y = a + b*2` ⇒ **`x y a b 2 * + = =`**（= 右结合：x=(y=(a+b\*2))；左结合写法无意义）。

### 2. 四小题（多出处：[[应用题题库]] 第 2 题、[[第三次作业-完整题解]] 第 3 题）
**答案**：
- `2+3+a+b` ⇒ `2 3 + a + b +`（+ 左结合）；
- `a*b+2*c*d` ⇒ `a b * 2 c * d * +`（\* 高于 +，2\*c\*d 左结合）；
- `(x=x+3)*4` ⇒ `x x 3 + = 4 *`；
- `(x=y=2)+3*(x=4)` ⇒ `x y 2 = = 3 x 4 = * +`（= 右结合；误写 `x y = 2 =` 是错的）。

## 二、四元式（经典式：$( := , T, -, x )$、真跳 L）

### 3. 布尔表达式跳转法（多出处：[[应用题题库]] 第 3(1) 题、[[第三次作业-完整题解]] 第 1(1) 题）
**题目**：`a≠b and not c or d>c`（起始标号 10）。
**答案**：
```
10: (j≠, a, b, 12)   11: (j, -, -, 14)   12: (jnz, c, -, 14)
13: (j, -, -, 17)    14: (j>, d, c, 17)  15: (j, -, -, 16)
16: …(E.false)       17: …(E.true)
```
and：左真跳右部、左假走假出口；or 相反；not 交换两出口；短路求值已体现。

### 4. while+if 嵌套（多出处：[[应用题题库]] 第 3(2) 题、[[第三次作业-完整题解]] 第 1(2) 题）
**题目**：`while a<b do if c<d then x:=y+z else x:=y-z`（起始 10）。
**答案**：
```
10:(j<,a,b,12) 11:(j,-,-,20) 12:(j<,c,d,14) 13:(j,-,-,17)
14:(+,y,z,T1) 15:(:=,T1,-,x) 16:(j,-,-,10)   ← then 尾回跳
17:(-,y,z,T2) 18:(:=,T2,-,x) 19:(j,-,-,10)   ← else 尾回跳
20: 循环出口
```
⚠ while 必须回跳 10；两分支都要跳回判断。

### 5. FOR 循环 + 优化（多出处：[[应用题题库]] 第 4 题、[[第三次作业-完整题解]] 第 2 题）
**题目**：`FOR K:=1 TO 10 DO BEGIN A:=I+10*K; B:=J+10*K; END`。
**答案**：
```
10:(:=,1,-,K) 11:(j<=,K,10,13) 12:(j,-,-,22) 13:(*,10,K,T1)
14:(+,I,T1,T2) 15:(:=,T2,-,A) 16:(*,10,K,T3) 17:(+,J,T3,T4)
18:(:=,T4,-,B) 19:(+,K,1,T5) 20:(:=,T5,-,K) 21:(j,-,-,11)
```
优化（公共子表达式 10\*K 复用 + 强度削减）：T1 复用、步进改 T1:=T1+10、(+,K,1,K)，共 9 条（见 [[应用题题库]] 第 4 题优化段）。

## 三、四元式（简洁式：取反条件跳 + 结果直写目标，出处：[[期末复习-强化卷2-LR1与中间代码]] 第 13–15 题）

### 6. 布尔表达式 `a>b or c and not d`（起始 10，13=E.true，14=E.false）
**答案**：10:(j>,a,b,13)（真→13）；11:(jz,c,-,14)（c 假→14）；12:(jnz,d,-,14)（d 真⇒not d 假→14，d 假落 13）。

### 7. `if x>0 then y:=x+1 else y:=x-1`（起始 10，14=出口）
**答案**：10:(j<=,x,0,13)（取反跳 else）；11:(+,x,1,y)；12:(j,-,-,14)（**跳过 else，别漏**）；13:(-,x,1,y)；14:出口。

### 8. `while a<b do a:=a+b`（起始 10，13=出口）
**答案**：10:(j>=,a,b,13)（取反跳出口）；11:(+,a,b,a)；12:(j,-,-,10)（**回跳判断**）；13:出口。

### 9. 带注释的分析树（出处：[[应用题题库]] 第 1 题）
**题目**：按语法制导定义对 (4\*7+1)\*2 建带注释分析树。
**答案**：自下而上：F.val=4 → T.val=4 → (4\*7) T.val=28 → (28+1) E.val=29 → (29\*2) T.val=58 → print(58)。

## 五、易错清单

1. 赋值经典式是 $( := , T, -, x )$——第三槽为 -，别写反。
2. 条件跳转 $(j\text{op}, a, b, L)$ 是"**真**跳 L"；简洁式则用取反条件跳假出口。
3. while **必须回跳**判断行；if-then-else 的 then 尾**必须跳过** else。
4. 逆波兰：= 右结合、− / 左结合；not 最高、赋值最低。
5. 临时变量按出现顺序 T1、T2…；标号从给定号连续编。
