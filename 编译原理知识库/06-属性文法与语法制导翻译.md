# 属性文法与语法制导翻译

> **所属章节**：第6章 属性文法和语法制导翻译
> **核心问题**：综合属性、继承属性、S-属性文法、L-属性文法、语法制导定义

---

## 6.1 属性文法

### 属性

每个文法符号可以关联若干**属性**，表示与该符号相关的语义信息。

| 属性类型 | 定义 | 计算方向 |
|---------|------|---------|
| **综合属性** | 由**子结点**的属性计算 | 自下而上（Bottom-Up） |
| **继承属性** | 由**父结点**和**兄弟结点**的属性计算 | 自上而下（Top-Down） |

### 语法制导定义 (SDD)

在产生式上附加**语义规则**，定义属性的计算方法。

#### 示例：表达式求值

| 产生式 | 语义规则 |
|--------|---------|
| L→E | print(E.val) |
| E→E₁+T | E.val := E₁.val + T.val |
| E→T | E.val := T.val |
| T→T₁*F | T.val := T₁.val * F.val |
| T→F | T.val := F.val |
| F→(E) | F.val := E.val |
| F→digit | F.val := digit.lexval |

> 这是典型的**综合属性**（val）——子结点的值传递给父结点。

## 6.2 S-属性文法与 L-属性文法

### S-属性文法

- 所有属性都是**综合属性**
- 可以用**自底向上**分析器（LR分析器）边分析边计算
- 计算顺序：从叶子到根（后序遍历）

### L-属性文法

- 可以有综合属性和继承属性
- 限制：产生式 $A \to X_1X_2...X_n$ 中，$X_j$ 的属性只能依赖于：
  - $X_j$ **左边**符号 $X_1,...,X_{j-1}$ 的属性
  - **A** 的继承属性
- 可以用**深度优先**的方式计算

---

## 6.3 翻译方案

将语义动作嵌入产生式中，用花括号 {} 标记：

$$E \to T \{E'.inh := T.val\} E' \{E.val := E'.syn\}$$

### 与语法制导定义的区别

| 特征 | 语法制导定义 | 翻译方案 |
|------|------------|---------|
| 表示 | 语义规则（声明式） | 语义动作（过程式） |
| 执行顺序 | 不指定 | 按动作出现顺序 |
| 应用 | 理论分析 | 实际实现 |

## 6.4 逆波兰式（后缀表达式）

将中缀表达式转换为后缀表达式（无括号）：

| 中缀 | 后缀（逆波兰式） |
|------|----------------|
| 2+3+a+b | 2 3 + a + b + |
| a*b+2*c*d | a b * 2 c * d * + |
| (x=x+3)*4 | x x 3 + = 4 * |
| (x=y=2)+3*(x=4) | x y 2 = = 3 x 4 = * + |

（四式即第三次作业 第3题，见 [[第三次作业-完整题解]]。）

**优先级与结合性**（中缀转后缀的分组依据）：括号 > 一元 not/负号（右结合）> * /（左结合）> + -（左结合）> 关系符（左结合）> and > or > 赋值 =（**右结合**）。结合性只在同级连排时起作用：a-b-c 左结合 → `a b - c -`；x=y=2 右结合 → `x y 2 = =`。完整优先级表与易错例见 [[期末复习专题#题型7 三元式与四元式|期末复习专题 题型7]]。
