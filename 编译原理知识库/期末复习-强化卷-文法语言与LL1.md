## 第一部分 文法 → 语言，并判断类型（第 1–4 题）

> **第 1 题**：G[S]：S→Sa | Sb | c。求 L(G)，并判断文法类型与语言类型。

**答案**（多种等价写法）：

| 形式 | 写法 |
|---|---|
| 正规式 | $L(G)=c(a \mid b)^*$ |
| 集合式 | $\{c\,w \mid w \in \{a,b\}^*\}$ |
| 文字 | c 后随任意个 a、b 的串（含单独的 "c"） |
| 例子 | ✓：c、ca、cb、cab、caa；✗：a、acb |

文法 **3 型（左线性）**、语言**正规**。

**解析**：
- S→c 是出口；S→Sa、S→Sb 每步在已有串**右端**追加一个字符（递归非终结符在右部**最左端**）。
- **正向**：每用一次 Sa/Sb 多一个 a/b ⇒ 生成 c 后接任意 a/b 串；**反向**：任意 c w，把 w 的字符从右往左逐个用 Sa/Sb 追回，最后 S→c 收口 ⇒ 可推出。
- **边界**：w = ε ⇒ "c" ✓。
- **类型**：三条产生式都是 $A \to Ba \mid a$ 形（"Sa" = B·a，"Sb" = B·b，"c" = a）⇒ **3 型（左线性正规文法）**；语言有正规式 $c(a|b)^*$ ⇒ 正规。

> [!warning] 方向别判反
> S→Sa 的递归非终结符在**左**、终结符在**右**——这是**左线性**（$A \to Ba \mid a$），不是右线性。左线性同属 3 型，但卷面写"右线性"就错了（对照专题 2.1 知识点对 3 型的两种形式）。

> **第 2 题**：G[S]：S→aSbc | abc。求 L(G)，并判断文法类型与语言类型。

**答案**（多种等价写法）：

| 形式 | 写法 |
|---|---|
| 集合式 | $L(G)=\{a^n (bc)^n \mid n \ge 1\}$ |
| 文字 | a 与 bc 块 1:1 配对、a 全在前（n ≥ 1） |
| 例子 | ✓：abc、aabcbc、aaabcbcbc；✗：a、ab、aabbc |

文法 **2 型**、语言**非正规**。

**解析**：
- 出口 abc（n=1）；每套一层 aSbc 在最前加一个 a、最后加一对 bc ⇒ a 与 (bc) 块 1:1 配对。
- **正向**：归纳即得全部 $a^n(bc)^n$；**反向**：串的首字符必是 a、末两字符必是 "bc"，剥掉一层得 $a^{n-1}(bc)^{n-1}$，归纳落到 abc。
- **边界**：n ≥ 1 ⇒ ε、"a"、"ab" 都推不出 ✓。核对 n=2：S→aSbc→a(abc)bc="aabcbc" ✓。
- **类型**：S→aSbc 右部非右线性，左部为单个非终结符 ⇒ **2 型**；a 与 bc 数目需配对计数 ⇒ 语言**非正规**。

> [!tip] 和 aⁿbⁿcⁿ 的区别（关键）
> 本语言的后两段是**交织**的 $(bc)^n$，一条 $S \to aSbc$ 就能配平 ⇒ **上下文无关**；而 $a^n b^n c^n$ 两段要分别配平、CFG 做不到，必须 1 型文法才能描述（对照题解第 4 题 (b)）。串形别看走眼："aabcbc" ∈ L，"aabbc" ∉ L。

> **第 3 题**：G[S]：S→S;S | a。求 L(G)，并判断文法类型与语言类型；G 是否二义文法？

**答案**（多种等价写法）：

| 形式 | 写法 |
|---|---|
| 正规式 | $L(G)=a( ; a)^*$ |
| 文字 | 由分号分隔的 a 组成的非空串 |
| 例子 | ✓：a、a;a、a;a;a；✗：ε、";"、a;;a |

文法 **2 型（非 3 型）**、语言**正规**、**G 是二义文法**。

**解析**：
- S→a 出口；S→S;S 把两段用 ; 拼接 ⇒ 任意 ≥1 个 a 用 ; 串起。
- **正向**：逐次用 S;S 拼接即得 a(;a)\*；**反向**：对 a;a;…;a，任取一个分号用 S→S;S 二分，递归到全是 a ⇒ 只产生这类串。
- **类型**：S→S;S 右部既不是 aB 形也不是 Ba 形（S、;、S 三符号）⇒ 非 3 型，左部单个非终结符 ⇒ **2 型**；语言 $a(;a)^*$ 可用正规式表达 ⇒ **正规**——"语言正规 ≠ 文法 3 型"的又一实例。
- **二义**：句子 "a;a;a" 有两棵语法树——左分 ((S;S);S) 与右分 (S;(S;S)) ⇒ **二义文法**（对分号连接链的结合方式没有规定）。

> **第 4 题**：G[S]：S→aSc | B，B→bB | ε。求 L(G)，并判断文法类型与语言类型。

**答案**（多种等价写法）：

| 形式 | 写法 |
|---|---|
| 集合式 | $L(G)=\{a^n b^m c^n \mid n \ge 0,\ m \ge 0\}$ |
| 文字 | 外层 a、c 等数配对，中间夹任意个 b（可为 0） |
| 例子 | ✓：ε、b、ac、abc、abbc、aacc；✗：ca、abb |

文法 **2 型**、语言**非正规**。

**解析**：
- S→aSc 每层配一对 a、c；出口 S→B 转入 B 段，B→bB|ε 产出任意个 b（含 0 个）。串形：外层 a…c 夹着中间任意 b 串。
- **正向**：用 k 次 aSc 再 S→B、B 产 m 个 b ⇒ $a^k b^m c^k$；**反向**：串若以 a 开头必以 c 结尾（n ≥ 1），剥一层递归；若无 a 则整串是 B 段（b^m 或 ε）⇒ 归纳成立。
- **边界**：**ε ∈ L(G)**（S→B→ε）；m 可为 0（"ac"、"aacc"…）；n 可为 0（纯 b 串 "b"、"bb"、ε）。
- **类型**：S→aSc 非右线性 ⇒ **2 型**；a、c 计数配对 ⇒ 语言**非正规**（中间 b 串不限长只是"填充"，不影响判定）。

> [!warning] 出口不能图省事
> 若写 S→aSc | b | ε：内层每次只能贡献**一个** b，得到的是"两边 a、c 等数、中间至多一个 b"——"abc" 能推，但 "abbc" 推不出 ✗。b^m 要**任意多个**，必须独立非终结符 B 来递归。

## 第二部分 语言 → 文法，并判断类型（第 5–8 题，答案均不唯一）

> **第 5 题**：写一文法 G，使 $L(G)=\{w \in \{a,b\}^* \mid w \text{ 以 ab 结尾}\}$，并判断文法类型。

**答案**（不唯一）：

```
S → aS | bS | aB
B → b
```

**另一种**：S→aS|bS|ab（更简，但右部 "ab" 是两个终结符 ⇒ 只是 **2 型**）。

**解析**：
- 拆两段：**前缀任意**（S→aS | bS 在前面逐字符加）+ **固定尾 "ab"**（S→aB→ab 落底）。
- **正向**：S→aS/bS 反复加前缀，最后 S→aB 产出结尾的 ab ⇒ $(a|b)^*ab$；**反向**：w = x·ab，x 为空直接 S→aB；x = c x' 则 S→cS 递归剥首字符，剥完接 aB。
- **边界**：最小串 "ab" ✓；""、"a"、"b"、"ba" 均推不出 ✓（S 每条路径都必须经过 aB）。
- **类型**：全部 $A \to aB \mid a$ 形 ⇒ **3 型（正规文法）**；语言正规（3 状态 DFA：记住是否刚读过 a）。

> **第 6 题**：写一文法 G，使 $L(G)=\{a^n b a^n \mid n \ge 0\}$（中间一个 b、两边 a 等数：b、aba、aabaa…），并判断文法类型。

**答案**（不唯一）：

```
S → aSa | b
```

**另一种**：S→A，A→aAa|b（多包一层，语言相同）。

**解析**：
- b 是中心，aSa 每层在**两头同时**各加一个 a ⇒ 两边永远等数。
- **正向**：n=0 用 S→b；n 层包裹 ⇒ $a^n b a^n$；**反向**：串首 a 尾 a、中间恰一个 b ⇒ 剥掉外层一对 a 递归，最终落到 b。
- **边界**：n=0 ⇒ "b" ✓；"ab"、"ba"、"aab" 推不出 ✓。
- **核对**：n=2：S→aSa→a(aSa)a→a(aba)a="aabaa" ✓。
- **类型**：aSa 非右线性，左部单 NT ⇒ **2 型**；两边 a 数必须相等 ⇒ 语言**非正规**（DFA 记不住左边有几个 a）。

> **第 7 题**：写一文法 G，使 $L(G)=\{a^m b^n c^{m+n} \mid m \ge 0,\ n \ge 0\}$（c 的个数 = a、b 个数之**和**），并判断文法类型。

**答案**（不唯一）：

```
S → a S c | T
T → b T c | ε
```

**另一种**：S→aSc|bTc|ε，T→bTc|ε（把"转入 T 段"并成一条，语言相同）。

**解析**：
- 读结构：外层由 S→aSc 每层配一对 a、c（共 m 层）；落到 T 后内层由 T→bTc 每层配一对 b、c（共 n 层）；T→ε 允许 m、n 取 0。
- **正向**：m 次 aSc 后 S→T，n 次 bTc 后 T→ε ⇒ $a^m b^n c^{n} c^{m} = a^m b^n c^{m+n}$ ✓；**反向**：串首若为 a 必尾为 c，剥一层外层递归；转入 T 段后同理剥 b…c。
- **核对**：m=1,n=1 ⇒ S→aSc→aTc→abTcc⇒"abcc"（c²=1+1）✓；m=0,n=1 ⇒ "bc" ✓；m=1,n=0 ⇒ "ac" ✓；m=n=0 ⇒ **ε** ✓（S→T→ε，**ε 在语言中**）。
- **类型**：S→aSc 非右线性 ⇒ **2 型**；m+n 两段计数相加配对 ⇒ 语言**非正规**。

> **第 8 题**：写一文法 G，使 $L(G)=\{w \in \{0,1\}^* \mid |w| \text{ 是 3 的倍数}\}$（含 ε），并判断文法类型。

**答案**（不唯一）：

```
S  → 0 A | 1 A | ε
A  → 0 B | 1 B
B  → 0 S | 1 S
```

**另一种**：语言等价写成 $((0 \mid 1)^3)^*$；文法的状态命名/转移顺序互换（如 A、B 对调并同步改转移）都等价。

**解析**：
- 按"已读长度 mod 3"设三个状态：**S**（余 0，也是接受状态）、**A**（余 1）、**B**（余 2）。每读一个字符状态 +1 并循环：S→0A / 1A，A→0B / 1B，B→0S / 1S；余 0 时可用 S→ε 结束。
- **正向**：每步消耗一个字符、状态 S→A→B→S 循环，能结束（回到 S 用 ε）当且仅当长度是 3 的倍数；**反向**：把串按每 3 个字符分段，每段 $0/1 \to 0/1 \to 0/1$ 三步从 S 绕回 S，最后 S→ε 收口。
- **核对**：""（S→ε）✓、"011"（S→0A→01B→011S→011）✓、"111000" ✓；"01"、"1111" 推不出（A、B 没有 ε 或直接收尾的产生式，走不回 S 就断不了）✓。
- **类型**：每条右部都是 aB / a（或 ε）形 ⇒ **3 型（正规文法）**；语言正规。

## 第三部分 LL(1) 文法：FIRST / FOLLOW / SELECT / 判定 / 预测分析表（第 9 题）

> **第 9 题**：已知文法 G[E]：
> E → T E'
> E' → + T E' | ε
> T → F T'
> T' → * F T' | ε
> F → ( E ) | i
> (1) 求各非终结符的 **FIRST 集**；(2) 求各非终结符的 **FOLLOW 集**；(3) 求各产生式的 **SELECT 集**；(4) 判断 G 是否为 LL(1) 文法，并说明理由；(5) 构造 **LL(1) 预测分析表**。

**解 (1) FIRST 集**（先标记可空：F、T 不可空；T'、E' 可空）：

| 非终结符 | FIRST | 依据 |
|---|---|---|
| F | { **(**, **i** } | F→(E)、F→i 直接加入 |
| T' | { **\***, **ε** } | T'→\*FT' 加 \*；T'→ε 使 T' 可空 |
| T | { **(**, **i** } | T→FT'：FIRST(F) 不含 ε，直接取 FIRST(F) |
| E' | { **+**, **ε** } | E'→+TE' 加 +；E'→ε 使 E' 可空 |
| E | { **(**, **i** } | E→TE'：FIRST(T) 不含 ε，直接取 FIRST(T) |

**解 (2) FOLLOW 集**（从开始符号 E 出发，沿"某 X 后面跟什么"传播；**可空则再并上后面的 FOLLOW**）：

| 非终结符 | FOLLOW | 依据 |
|---|---|---|
| E | { **#**, **)** } | ① E 是开始符号 ⇒ #；② F→( E ) 中 E 后是 ) ⇒ ) |
| E' | { **#**, **)** } | E→T E' 中 E' 在右部末端 ⇒ FOLLOW(E') = FOLLOW(E) |
| T | { **+**, **#**, **)** } | E→T E'：T 后跟 E' ⇒ 取 FIRST(E')\{ε} = {+}；又 **E' 可空** ⇒ 再并 FOLLOW(E) = {#,)} |
| T' | { **+**, **#**, **)** } | T→F T' 中 T' 在末端 ⇒ FOLLOW(T') = FOLLOW(T) |
| F | { **\***, **+**, **#**, **)** } | T→F T'：F 后是 T' ⇒ 取 FIRST(T')\{ε} = {\*}；又 **T' 可空** ⇒ 再并 FOLLOW(T) = {+,#,)} |

**解 (3) SELECT 集**（非 ε 产生式取 FIRST(右部)；ε 产生式取 FOLLOW(左部)）：

| 产生式 | 计算 | SELECT |
|---|---|---|
| E → T E' | FIRST(TE') | { **(**, **i** } |
| E' → + T E' | FIRST | { **+** } |
| E' → ε | FOLLOW(E') | { **#**, **)** } |
| T → F T' | FIRST(FT') | { **(**, **i** } |
| T' → \* F T' | FIRST | { **\*** } |
| T' → ε | FOLLOW(T') | { **+**, **#**, **)** } |
| F → ( E ) | FIRST | { **(** } |
| F → i | FIRST | { **i** } |

**解 (4) 判定**：相同左部的产生式两两求 SELECT 集交集：

- E：只有 E→TE' 一条，无交集可算；
- E'：SELECT(E'→+TE') ∩ SELECT(E'→ε) = $\{+\} \cap \{\#, )\} = \emptyset$；
- T：只有 T→FT' 一条，无交集可算；
- T'：SELECT(T'→\*FT') ∩ SELECT(T'→ε) = $\{*\} \cap \{+,\#, )\} = \emptyset$；
- F：SELECT(F→(E)) ∩ SELECT(F→i) = $\{( \} \cap \{i\} = \emptyset$。

全部为空 ⇒ **相同左部的任意两产生式 SELECT 集交集为空，所以 G 是 LL(1) 文法**。

**解 (5) LL(1) 预测分析表**（M[非终结符, 终结符]，表中每格恰好一个产生式，其余空格为报错）：

|        | (     | i     | +       | \*       | )    | #    |
| ------ | ----- | ----- | ------- | -------- | ---- | ---- |
| **E**  | E→TE' | E→TE' |         |          |      |      |
| **E'** |       |       | E'→+TE' |          | E'→ε | E'→ε |
| **T**  | T→FT' | T→FT' |         |          |      |      |
| **T'** |       |       | T'→ε    | T'→\*FT' | T'→ε | T'→ε |
| **F**  | F→(E) | F→i   |         |          |      |      |

（逐格来源：E、T 只有一条产生式按 FIRST 填；E'、T' 的 ε 行按 FOLLOW 填；F 按两条 FIRST 分列。）

> [!warning] 本题易错
> 1. **FOLLOW(T)、FOLLOW(F) 的"可空传播"**是全题最大失分点：E' 可空才让 +,#,) 进入 FOLLOW(T)；T' 可空才让 +,#,) 进入 FOLLOW(F)。漏传播 ⇒ SELECT(T'→ε) 算错 ⇒ 判定跟着错。
> 2. **ε 产生式的 SELECT 用 FOLLOW 不是 FIRST**（FIRST(ε)=∅ 没用）。
> 3. 判定写法：同左部产生式的 SELECT 交集**逐对列出**、全部为空，再下结论。
