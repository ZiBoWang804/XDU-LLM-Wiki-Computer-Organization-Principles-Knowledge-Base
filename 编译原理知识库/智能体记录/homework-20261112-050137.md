# 作业布置 · LL(1)文法与预测分析表作业

标题：LL(1)文法与预测分析表作业
知识点：LL(1)文法
截止：2026-05-14

## 说明
一、作业说明
本次作业围绕LL(1)文法展开，重点考查FIRST集、FOLLOW集、LL(1)判定条件及预测分析表的构造。请独立完成，写出必要的推导过程和计算步骤，提交清晰的手写扫描件或电子文档。

二、作业题目
1. 给定文法 G[S]：
S → A a | b
A → ε | c
(1) 计算每个非终结符的 FIRST 集和 FOLLOW 集；
(2) 判断该文法是否为 LL(1) 文法，并说明理由。

2. 给定文法 G[E]：
E → T E'
E' → + T E' | ε
T → F T'
T' → * F T' | ε
F → ( E ) | id
(1) 求各非终结符的 FIRST 集和 FOLLOW 集；
(2) 构造该文法的预测分析表；
(3) 判断它是否为 LL(1) 文法。

3. 对第2题中的文法，利用预测分析表分析输入串 id + id * id 的分析过程，要求列出分析栈、当前输入符号和所执行动作。

4. 简答题：
(1) 说明 LL(1) 文法需要满足的两个主要条件；
(2) 为什么含有左递归的文法一般不能直接作为 LL(1) 文法使用？应如何处理？

三、提交要求
请按题号作答，计算过程完整；预测分析表需标明行、列含义；分析过程表需逐步列出。截止时间：下周。
