# 变式训练 · 语义分析

## 变式题（LLM 同源生成）
已知赋值语句及算术表达式文法 G[S]：
S → id := E
E → E + T | T
T → id | num
设终结符 num 的类型为 int，id 的类型由符号表给出；类型属性 type 的取值可为 int、float、error，并按下列语义规则进行类型检查：
S → id := E   { S.ok = (id.type == E.type) }
E → E1 + T   { 若 E1.type = T.type，则 E.type = E1.type；否则 E.type = error }
E → T        { E.type = T.type }
T → id       { T.type = id.type }
T → num      { T.type = int }
回答下列问题：
（1）判断 type 与 ok 各是综合属性还是继承属性，说明这组语义规则属于 S-属性定义还是 L-属性定义，并给出属性求值顺序。
（2）对输入 x := y + 2，若符号表中 x:int、y:float，按上述规则求值，判断该语句是否通过类型检查；若有错，指出错误类型及在哪个产生式处发现。
（3）若要在递归下降分析中边分析边执行语义动作，需先消除 E 的直接左递归。写出消除左递归后的文法（T 不变），说明为正确计算 E.type 应引入什么继承属性及如何传递，并求改写后 E' 的 FOLLOW 集。

## 提示
先记住：由子结点算父结点的是综合属性，由父结点或左兄弟传给右部的是继承属性；求 FOLLOW(E') 时先看 E 在赋值产生式末尾，故其后为结束符 #。

## 标准解答
（1）type 在 T→id、T→num、E→T、E→E1+T 中均由子结点或终结符信息求出父结点信息，故是综合属性；S.ok 由 id 的符号表属性与 E.type 比较得到，也是综合属性。表达式中的 id.type 来自符号表，不属于文法符号的综合属性。各产生式的属性依赖均为“左部属性依赖右部属性或右部较左部分属性”，可按自底向上/从左到右的顺序求值；对于原左递归文法，E→E1+T 需要先得到 E1.type 和 T.type，因此该规则集可视为 L-属性定义（在消除左递归后更适合自顶向下求值）。
（2）对 x := y + 2：
T→id（y）：T.type = y.type = float；
E→T：E.type = float；
T→num（2）：T.type = int；
归约到 E→E1+T 时，E1.type = float，T.type = int，二者不相等，按规则 E.type = error。因此该加法发生类型不匹配错误，错误在产生式 E→E1+T 处被发现（float 与 int 不能直接相加，规则中未给隐式转换）。
再执行 S→id := E 的检查：x.type = int，E.type = error，S.ok = (int == error) = false，所以整个赋值语句不通过类型检查。
（3）消除 E 的直接左递归后：
S → id := E
E → T E'
E' → + T E' | ε
T → id | num
由于 E' 需要知道“左边已经算出的类型”才能继续判断后续加法，需引入继承属性 E'.in（表示累加部分当前类型）；同时保留综合属性 E'.out（表示该表达式最终类型）。语义规则框架为：
E → T E'  { E'.in = T.type; E.type = E'.out; }
E' → + T E1'  { 若 E'.in = T.type，则 E1'.in = E'.in；否则 E1'.in = error; E'.out = E1'.out; }
E' → ε  { E'.out = E'.in; }
其中 E'.in 是继承属性，E'.out 是综合属性；T.type 仍为综合属性。
求 FOLLOW(E')：E 出现在 S→id:=E 的末尾，故 FOLLOW(E) = {#}，其中 # 为输入结束符。由 E→T E' 得 FOLLOW(E') ⊇ FOLLOW(E) = {#}；由 E'→+ T E'，右部末尾的 E' 的 FOLLOW 仍来自 FOLLOW(E')，不增加新符号。因此 FOLLOW(E') = {#}。附带地，由 E→T E' 且 FIRST(E')={+, ε}，可得 FOLLOW(T) = {+, #}，这也可用于确定 T 后语义动作/错误恢复的同步时机。

## 解题步骤
- 分析各文法符号属性的求值依赖，区分综合属性与继承属性
- 按输入 x := y + 2 自底向上求 T.type、E.type，并在加法产生式处检查类型一致性
- 执行赋值产生式的类型一致性检查，得出是否通过
- 消除 E 的直接左递归，引入 E' 的继承属性 in 和综合属性 out 传递累加类型
- 按 FOLLOW 集定义，由 S→id:=E 与 E→T E' 求得 FOLLOW(E')={#}
