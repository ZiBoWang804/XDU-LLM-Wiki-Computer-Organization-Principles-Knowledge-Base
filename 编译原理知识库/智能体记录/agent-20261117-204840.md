## 第 1 题【选择·句柄判定】

文法 G[S]：

```
S → aAb
A → cA | d
```

对句子 **acdb**，该句子的句柄是（　）

A. `d`　　B. `cd`　　C. `a`　　D. `c`

<details><summary>🔑 答案与解析（点击展开）</summary>

**答案：A（`d`）**

**思路提示**：先画语法树，再按“短语→直接短语→最左直接短语”三级筛选，不要凭感觉挑最短的串。

**完整解答**

1. 写出 acdb 的推导（最右推导，即规范推导）：
   `S ⇒ aAb ⇒ acAb ⇒ acdb`
2. 语法树结构：根 S 分出 `a`、`A`、`b`；该 A 分出 `c`、`A`；内层 A 分出 `d`。
3. **短语**（任一子树的叶子串，从左到右）：
   - 内层 A 的叶子：`d`
   - 外层 A 的叶子：`cd`
   - 根 S 的叶子：`acdb`（整句本身也是相对于 S 的短语）
4. **直接短语**（高度为 1 的子树，即一步推导的右部）：`d`（A→d）、`cd`（A→cA）。
5. **句柄 = 最左直接短语**：在 `cd` 中，最左的直接短语是 `d`，故句柄为 `d`。

**干扰项辨析**
- B `cd`：是直接短语，但不是**最左**的，属于“最右直接短语”式干扰。
- C `a`：只是终结符叶子，不构成任何子树的完整叶子串，不是短语。
- D `c`：同理不是短语（它是 `cd` 的左半部分，不是独立子树的叶子串）。

**易错点**：把“直接短语”直接当成句柄。句柄必须同时满足“直接短语 + 最左”。另外注意：句柄是针对**某一句型**而言的，同一句子在不同推导步骤上句柄会变。

</details>

## 第 2 题【分析设计·规范归约】

文法 G[S]：

```
S → aAB
A → b | ε
B → c
```

对句子 **abc** 进行规范归约，**第一步**归约后得到的符号串是 ______。

<details><summary>🔑 答案与解析（点击展开）</summary>

**答案：`aAc`**

**思路提示**：规范归约 = 最右推导的逆过程，所以“第一步归约”对应“最右推导的最后一步”。先写出最右推导链，再倒着看。

**完整解答**

1. 求最右（规范）推导：
   `S ⇒ aAB ⇒ aAc ⇒ abc`
   （第一步展开最右非终结符 B→c，第二步展开 A→b）
2. 规范归约是最右推导的逆序：
   `abc ⇒ aAc ⇒ aAB ⇒ S`
3. 因此第一步归约是把 `abc` 中的 `b` 按 A→b 归约为 A，得到 **`aAc`**。

**为什么不是先归约 c？**
虽然 `c` 在串中更靠右，但此时 `c` 已由 B→c 产生，栈顶可归约串是 `b`（对应 A→b 的右部）。规范归约每次归约的是当前规范句型的**句柄**，即最左直接短语。在句型 `abc` 中，直接短语为 `b`（A→b）与 `c`（B→c），最左者为 `b`，故先归约 `b`。

**易错点**
- 把“最右推导”与“最右归约”混淆：规范归约归约的是**句柄（最左直接短语）**，不是最右的串。
- 忽略 ε 产生式：A→ε 使 A 可空，推导中 A 可被直接消去，但本题最右推导路径中 A 走的是 A→b。

</details>
