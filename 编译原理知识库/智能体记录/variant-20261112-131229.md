# 变式训练 · 类型检查

## 变式题（LLM 同源生成）
已知类C语言声明与函数原型：
int a; float x; double y; char c;
float f(int, double);
int g(float, char);
考虑语句：
a = f(a + c, x) + g(x * 2, c + 1);
（1）按类C语言通常的类型检查规则（char在算术运算中提升为int；int→float→double可隐式拓宽，反向窄化不允许；实参类型须能隐式转换为形参类型；赋值右部须能隐式转换为左部类型），判断该语句是否通过类型检查。若不通过，指出错误位置及原因。
（2）为描述“函数调用实参列表”的文法片段：
E → E + T | T
T → id ( A ) | id | num
A → E | E , A
（i）指出该文法含何种左递归并消除之；
（ii）以E为开始符，求FOLLOW(A)，并说明它在检查逗号分隔实参列表时的作用。

## 提示
先看c+1：char提升后是int，而g的第二个形参是char；再求FOLLOW时，A只出现在id(A)的括号内和实参列表自身末尾，注意右括号。

## 标准解答
（1）逐项做类型检查：
① a + c：a为int，c为char。按规则char提升为int，故a + c的类型为int。函数f的第一个形参为int，实参int可隐式转换为int，匹配。
② x：x为float。函数f的第二个形参为double，float可隐式拓宽为double，匹配。
③ 因此f(a + c, x)合法，返回类型为float。
④ x * 2：x为float，2为int；int提升为float，乘法结果类型为float。函数g的第一个形参为float，实参float匹配。
⑤ c + 1：c为char，1为int；char提升为int后与int相加，结果类型为int。函数g的第二个形参为char，而实参类型为int；int到char是窄化转换，按题意不允许隐式进行，故不匹配。
结论：该语句不能通过类型检查。错误位置在g的第二个实参c + 1处：其实参类型为int，不能隐式转换为形参类型char。因g调用类型错误，整个右侧表达式无法确定类型，赋值也不成立。

（2）（i）文法中E → E + T是直接左递归。消除该直接左递归后得：
E → T E′
E′ → + T E′ | ε
T → id ( A ) | id | num
A → E | E , A
注意A → E , A是右递归，不是左递归，不需要消除。

（ii）以E为开始符求FOLLOW(A)：
A出现在产生式T → id ( A )中，A后面紧跟终结符')'，因此')' ∈ FOLLOW(A)。
A还出现在A → E , A的末尾，此处只能得到FOLLOW(A) ⊆ FOLLOW(A)，不增加新符号。
A没有其他出现位置。
故FOLLOW(A) = { ')' }。
作用：FOLLOW(A)给出非终结符A的后续符号集合。在检查或分析逗号分隔的实参列表时，当读到')'，由于')' ∈ FOLLOW(A)，说明实参列表应当结束，可据此完成对A的归约/确认；若读到','，则说明列表还可能继续。它用于确定A的结束边界，避免把右括号误当作实参内容。

## 解题步骤
- 对赋值语句右侧表达式逐项做类型推导，注意char提升为int以及窄化限制
- 判断f、g两个调用的实参兼容性，定位错误在g的第二个实参c+1
- 识别E→E+T为直接左递归并消除
- 按FOLLOW定义，由A在T→id(A)中后跟')'求得FOLLOW(A)
- 说明FOLLOW(A)在实参列表分析中的结束边界与归约作用
