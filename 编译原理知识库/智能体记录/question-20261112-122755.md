## 题面
**[q49]【选择】编译程序处理如下类C语言程序片段：int n; float r; r = n * 2 + 1.5; 关于语句 r = n * 2 + 1.5; 在语义分析与中间代码生成阶段的处理，下列叙述正确的是**
<br>　A. 子表达式 n * 2 为 int 型，与实型常量 1.5 相加前需把 int 型值转换为 float 型；语义分析借助符号表完成类型检查并确定这种隐式转换，表达式结果可直接赋给 float 型变量 r<br>　B. 该语句含有语法错误，因为 int 型变量与 float 型常量不允许出现在同一个表达式中<br>　C. 若该语句存在类型不相容问题，应由词法分析阶段扫描字符时发现并报告<br>　D. 因为 r 是 float 型而表达式中出现了 int 型子表达式，所以该语句一定不能通过编译
<sub>来源：第7章 7.1 语义分析的任务（类型检查、类型转换、符号表）；分析设计题题库第1题“错误信息的编译阶段判断”中“类型不匹配属语义分析”的判据</sub>

## 答案与解析
**[q49] 答案：子表达式 n * 2 为 int 型，与实型常量 1.5 相加前需把 int 型值转换为 float 型；语义分析借助符号表完成类型检查并确定这种隐式转换，表达式结果可直接赋给 float 型变量 r**
解题步骤：①先分清各阶段职责——词法分析只按构词规则识别单词，语法分析只检查结构（如括号、分号、if-else 配对），语义分析才依据符号表检查类型相容性并做隐式类型转换；②本语句结构完全合法：n*2 是 int 型，与 1.5（float）相加时按类型提升规则把 int 值转换为 float，整个表达式为 float 型，赋给 float 型变量 r 类型相容，无需报错；③因此只有“语义分析完成类型检查并确定隐式转换”的叙述正确。易错点：B 把“类型混合运算”误当成语法错误（语法与类型是两回事，混合运算本身合法）；C 把语义错误归给词法分析（词法阶段看不到类型信息）；D 把“含有 int 型子表达式”误判为类型不相容（int 可提升为 float，方向正确的转换是合法的）。若反过来把 float 表达式直接赋给 int 型变量而不做显式转换，才可能触发语义警告或错误。
