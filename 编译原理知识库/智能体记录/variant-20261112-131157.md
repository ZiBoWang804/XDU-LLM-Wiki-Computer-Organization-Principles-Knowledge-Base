# 变式训练 · 类型检查

## 变式题（LLM 同源生成）
某类C语言声明与函数原型如下：
int count; float ratio; char grade; double total;
double calc(int, double);
int check(char, float);

设类型规则为：
① 算术运算中，若两操作数类型不同，按 char→int→float→double 提升到较宽类型；不允许反向隐式转换。
② 赋值 x = e 要求 e 的类型可隐式转换为 x 的类型；只允许窄到宽（char→int→float→double）转换。
③ 函数调用实参必须可隐式转换为对应形参类型。

判断下列语句是否有类型错误，并说明理由：
（1）count = calc(count, ratio) + check(grade, count);
（2）total = calc(count, total) * 2;
（3）ratio = check(grade, count) + total;

（4）为说明语法分析阶段的错误恢复同步集，考虑简化声明文法 G[P]：
P → D S
D → T id | ε
S → id = E ;
T → int | float | char
E → id | num
求 FIRST(D)、FOLLOW(D)、FOLLOW(T)，并说明 D 可空对 FOLLOW(D) 及 D→ε 的 SELECT 集的影响。

## 提示
先做表达式类型提升，再检查赋值方向；FOLLOW 题中先看 D 后面的 S 是否可空，可空非终结符的 ε 产生式要用 FOLLOW 集作为 SELECT 集。

## 标准解答
（1）calc(count, ratio)：count:int 匹配 int，ratio:float 可隐式转为 double，返回 double；check(grade, count)：grade:char 匹配 char，count:int 可隐式转为 float，返回 int。double+int 提升为 double。赋值给 count:int 需要 double→int，规则不允许，故有类型错误。
（2）calc(count, total)：count:int 匹配 int，total:double 匹配 double，返回 double；double*int 提升为 double。赋值给 total:double 合法，故无类型错误。
（3）check(grade, count) 返回 int；int+total(double) 提升为 double。赋值给 ratio:float 需要 double→float，规则不允许，故有类型错误。
（4）FIRST(T)={int,float,char}，D→T id 或 D→ε，所以 FIRST(D)={int,float,char,ε}。S→id=E;，故 FIRST(S)={id}。由 P→D S 得 FOLLOW(D)=FIRST(S)={id}；由 D→T id 得 FOLLOW(T)={id}。D 可空使 D→ε 的 SELECT 集为 FOLLOW(D)={id}，即分析时遇到 id 应选 D→ε；本题 S 不可空，所以 FOLLOW(D) 不需要并入 FOLLOW(P)。

## 解题步骤
- 按类型提升规则推导三条语句中表达式与函数调用的类型
- 依据赋值兼容性规则判断三条语句是否类型正确
- 由 D→T id | ε 求 FIRST(D)
- 由 P→D S 求 FOLLOW(D)，由 D→T id 求 FOLLOW(T)
- 说明 D→ε 的 SELECT 集等于 FOLLOW(D)，体现可空非终结符对 FOLLOW 的影响
