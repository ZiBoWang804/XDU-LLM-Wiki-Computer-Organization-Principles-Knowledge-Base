# 变式训练 · 类型检查

## 变式题（LLM 同源生成）
已知类C语言声明及函数原型：
int n; float r; char c;
float h(int, float);
类型规则：①算术运算 +、* 的操作数须为数值类型，char 可提升为 int；若含 float 则结果为 float，否则为 int；②赋值只允许隐式拓宽 char→int→float，不允许 float→int/char 等窄化，也不允许数值类型与 bool 互转；③函数调用实参可隐式拓宽为形参类型，不允许窄化，h 的返回类型为 float。
语句如下：
① r = n + 1;
② n = r * 2;
③ c = n + 1;
④ r = h(n, n);
⑤ r = h(r, 1.5);
⑥ c = h(n, 1.5);
（1）判断各语句能否通过类型检查，并说明原因；若需显式转换，请写出转换形式；
（2）对声明部分给出文法 G[D]：D→T L ;  T→int | float | char  L→id L'  L'→, id L' | ε。求 FOLLOW(L')、SELECT(L'→ε)，并判断 G[D] 是否为 LL(1) 文法。

## 提示
先分清拓宽允许、窄化不允许；L' 的 FOLLOW 来自 L 后的分号。

## 标准解答
（1）① n+1 的类型为 int，赋给 float 属于拓宽，通过。② r*2 的类型为 float，赋给 int 属于窄化，不通过；若要合法需显式写 n=(int)(r*2)。③ n+1 的类型为 int，赋给 char 属于窄化，不通过；若要合法需写 c=(char)(n+1)。④ h(n,n)：第一实参 int 匹配 int，第二实参 int 可拓宽为 float，返回 float 赋给 r，通过。⑤ h(r,1.5)：第一实参 r 为 float，不能窄化为 int，不通过；若要合法需写 h((int)r,1.5)。⑥ h(n,1.5) 返回 float，赋给 char 属于窄化，不通过；若要合法需写 c=(char)h(n,1.5)。
（2）FIRST(T)={int,float,char}，FIRST(L)={id}，FIRST(L')={',',ε}。由 D→T L ; 知 L 后跟分号，故 FOLLOW(L)={';'}。又 L→id L'，L' 在 L 的末尾，所以 FOLLOW(L')=FOLLOW(L)={';'}。
SELECT(L'→, id L')={','}；SELECT(L'→ε)=FOLLOW(L')={';'}。
检查同一左部各产生式的 SELECT 集：T 的三个产生式的 SELECT 分别为 {int}、{float}、{char}，两两不交；L 只有一个产生式；L' 的两个 SELECT 集 {','} 与 {';'} 不交；D 只有一个产生式。因此 G[D] 是 LL(1) 文法。

## 解题步骤
- 逐条按算术结果类型、赋值拓宽/窄化、函数实参兼容规则检查①—⑥
- 求声明文法的 FIRST 集，并由 D→T L ; 得 FOLLOW(L) 和 FOLLOW(L')
- 求 SELECT(L'→, id L') 与 SELECT(L'→ε)，检查同一左部 SELECT 是否相交
