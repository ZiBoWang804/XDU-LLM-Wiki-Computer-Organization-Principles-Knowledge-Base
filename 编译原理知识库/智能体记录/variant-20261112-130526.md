# 变式训练 · 类型检查

## 变式题（LLM 同源生成）
已知类C语言声明与函数原型：
int a; float b; double c; char d;
int f(int x, float y);
float g(float x);
double h(double x);
类型检查规则：char<int<float<double 为拓宽次序；二元算术运算把两操作数拓宽到较宽类型；赋值和传参允许拓宽、不允许隐式窄化；关系运算结果类型为 bool，bool 不可隐式转数值类型。
（1）对下列语句逐条进行类型检查，合法时指出隐式转换位置，非法时说明原因：
① a = f(a, d);
② b = g(a) + f(a, b);
③ c = h(b) * a;
④ d = a > b;
⑤ f(b, a);
（2）为在语法分析阶段处理变量声明，给出文法 G[D]：
D → T id L ;
L → , id L | ε
T → int | float | double
求 FIRST(L)、FOLLOW(L)、FOLLOW(D)，求 SELECT(L→, id L) 与 SELECT(L→ε)，并判断 G[D] 是否 LL(1) 文法。

## 提示
先按拓宽规则确定每个实参和运算结果类型；L 可推出 ε，所以 SELECT(L→ε) 要用 FOLLOW(L)。

## 标准解答
（1）类型检查：
① a = f(a,d)：f 的形参为 (int,float)。a:int 匹配 x:int；d:char 按拓宽规则可转为 float 作为第二实参。f 返回 int，赋给 a:int 合法。隐式转换：d:char→float。
② b = g(a)+f(a,b)：g 的形参 float，a:int 拓宽为 float，g 返回 float；f(a,b) 中 a:int 匹配 int，b:float 匹配 float，f 返回 int；加法 float+int 将 int 拓宽为 float，结果 float；赋给 b:float 合法。隐式转换：g 实参 a:int→float；加法中 f(a,b) 的 int 结果→float。
③ c = h(b)*a：h 的形参 double，b:float 拓宽为 double，h 返回 double；double*int 将 int 拓宽为 double，结果 double；赋给 c:double 合法。隐式转换：h 实参 b:float→double；乘法中 a:int→double。
④ d = a>b：a>b 中 a:int 拓宽为 float 与 b:float 比较，关系结果类型为 bool；bool 不可隐式转为 char，因此非法。
⑤ f(b,a)：第一实参 b:float 到形参 int 属于隐式窄化，不允许，故非法；第二实参 a:int 到 float 可拓宽，但整体仍非法。
（2）FIRST(L)={',',ε}。在 D→T id L ; 中 L 后跟 ';'，故 ';'∈FOLLOW(L)；在 L→, id L 中末尾 L 继承 FOLLOW(L)，故 FOLLOW(L)={;}。D 为开始符，FOLLOW(D)={$}。SELECT(L→, id L)={,}；SELECT(L→ε)=FOLLOW(L)={;}。二者不相交；T 的三个产生式 SELECT 分别为 {int},{float},{double}，也不相交；D 只有一条产生式。因此 G[D] 是 LL(1) 文法。

## 解题步骤
- 按类型拓宽次序逐条检查实参和运算结果，确定是否发生隐式窄化
- 由 L→, id L | ε 求 FIRST(L) 与 FOLLOW(L)、FOLLOW(D)
- 计算 L 两个候选产生式的 SELECT，结合 T 的产生式判断 LL(1)
