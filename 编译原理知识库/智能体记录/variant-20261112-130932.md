# 变式训练 · 类型检查

## 变式题（LLM 同源生成）
已知类C语言声明与函数原型：
int m; float x; double y; char ch; int a[5];
int g(float, int);
float h(int, char);
设类型检查规则如下：char 可隐式提升为 int，int→float→double 可隐式转换；反向（double/float→int/char）不允许隐式转换，必须显式强制；算术运算按 char→int→float→double 平衡；函数调用实参必须能隐式转换为形参类型；数组下标表达式必须为整型（char/int 可用，char 先提升为 int）。
（1）判断下列语句是否通过类型检查。若通过，写出赋值号右边表达式的最终类型；若不通过，指出错误原因：
① x = m + g(x, m) * h(m, ch);
② y = x + h(m, ch);
③ ch = m + 1.5;
④ x = a[m] + y;
⑤ a[x] = m;
（2）类型检查所依赖的表达式语法片段为：
E → T E'
E' → + T E' | ε
T → id | id ( L )
L → E L'
L' → , E L' | ε
求 FOLLOW(E')、FOLLOW(L)，并判断该文法是否为 LL(1) 文法。

## 提示
类型检查中注意“窄化转换”不能隐式进行；LL(1) 判断中若两个候选式有公共左前缀 id，则它们的 SELECT 集可能相交。

## 标准解答
（1）逐句检查：
① g(x,m)：实参类型为 (float,int)，与形参 (float,int) 匹配，返回 int；h(m,ch)：实参类型为 (int,char)，与形参 (int,char) 匹配，返回 float。于是 m+g(x,m) 为 int+int→int，再与 h(m,ch) 相乘：int*float→float。右值 float 赋给 x(float) 合法。故通过，表达式最终类型为 float。
② h(m,ch) 返回 float，x+h(m,ch) 为 float+float→float。右值 float 赋给 y(double)，float→double 为隐式提升，合法。故通过，表达式最终类型为 float（赋值后 y 的类型为 double）。
③ m+1.5 为 int+double→double。右值 double 赋给 ch(char)，double→char 属于窄化，按规则不允许隐式转换。故不通过，错误原因是 double 不能隐式转换为 char。
④ a[m] 中下标 m 为 int，合法，a[m] 的类型为 int；a[m]+y 为 int+double→double。右值 double 赋给 x(float)，double→float 属于窄化，按规则不允许隐式转换。故不通过，错误原因是 double 不能隐式转换为 float。
⑤ a[x] 中下标 x 为 float，不是整型，不能作为数组下标。故不通过，错误原因是数组下标表达式必须为整型。

（2）先求 FIRST 集：FIRST(E)=FIRST(T)={id}，FIRST(E')={+,ε}，FIRST(T)={id}，FIRST(L)=FIRST(E)={id}，FIRST(L')={',',ε}。
FOLLOW(E')：由 E→T E'，E' 位于产生式末尾，所以 FOLLOW(E')=FOLLOW(E)。E 是开始符，故 $∈FOLLOW(E)；又由 L→E L'，E 后跟 L'，FIRST(L')={',',ε}，故 ','∈FOLLOW(E)，且 ε∈FIRST(L') 时 FOLLOW(L)⊆FOLLOW(E)。因此 FOLLOW(E)={$, ','}，从而 FOLLOW(E')={$, ','}。
FOLLOW(L)：由 T→id ( L )，L 后紧跟 ')'，所以 ')'∈FOLLOW(L)。文法中没有其他位置把符号放在 L 之后，因此 FOLLOW(L)={')'}。
判断 LL(1)：T 的两个候选式为 T→id 和 T→id ( L )。它们的 FIRST 集均为 {id}，故 SELECT(T→id)={id}，SELECT(T→id ( L ))={id}，交集非空。因此原文法不是 LL(1) 文法（需先提取公共左前缀，例如改写为 T→id T'，T'→( L ) | ε，再重新判断）。

## 解题步骤
- 确定各变量、函数形参与返回值的类型
- 逐句检查函数调用实参、算术表达式类型平衡与赋值兼容性
- 对数组语句检查下标是否为整型
- 求表达式文法各非终结符的 FIRST 集
- 由开始符和产生式右部上下文求 FOLLOW(E') 与 FOLLOW(L)
- 比较 T 的两个候选式的 SELECT 集，判断是否为 LL(1)
