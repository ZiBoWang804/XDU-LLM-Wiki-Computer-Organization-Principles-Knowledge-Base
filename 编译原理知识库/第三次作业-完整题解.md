## 第1题 把下列布尔表达式或语句翻译成四元式（假设语句起始标号是10）

### （1）a≠b and not c or d>c

> 注：作业原题中 ≠ 以 Symbol 字体符号给出（docx 内为 Symbol 字体 ¹ = ≠），即 a≠b，不可误读为 a<b。

**【答案】四元式序列（16 为整体假出口，17 为整体真出口）：**

```
10: (j≠,  a, b, 12)      -- a≠b 为真 → 12；为假则顺序执行
11: (j,   -, -, 14)      -- a=b ⇒ and 为假 → 转判 d>c
12: (jnz, c, -, 14)      -- c 为真 ⇒ not c 为假 → 转判 d>c
13: (j,   -, -, 17)      -- c 为假 ⇒ not c 为真 ⇒ 整体为真
14: (j>,  d, c, 17)      -- d>c 为真 ⇒ 整体为真
15: (j,   -, -, 16)      -- d>c 为假 ⇒ 整体为假
16: ...                  -- 整体为假的处理（E.false）
17: ...                  -- 整体为真的处理（E.true）
```

**【解析】** 原式即 (a≠b and not c) or (d>c)。用跳转法：不求 true/false 值，为每个子式定 E.true / E.false 两个出口。and 要求左部为真跳右部、左部为假走 E.false；or 相反（左部为真走 E.true、为假跳右部）；not 交换两出口。

① a≠b：为真跳 12 判 not c，为假落 11（跳过 and 右部）；② not c：c 为真(非0)则 not c 为假 → 跳 14 判 d>c，c 为假(0)则 not c 为真 → 整体为真跳 17；③ d>c：为真跳 17，为假顺序落 16。运算符 ≠ 也可写作 <>。短路求值已体现在跳转中：a=b 时不判 not c，and 为假时不判整体真出口。

### （2）while a<b do if c<d then x := y + z; else x:= y - z;

**【答案】四元式序列（20 为循环出口）：**

```
10: (j<,  a, b, 12)      -- a<b 为真 → 进入循环体
11: (j,   -, -, 20)      -- a<b 为假 → 退出循环
12: (j<,  c, d, 14)      -- c<d 为真 → then 分支
13: (j,   -, -, 17)      -- c<d 为假 → else 分支
14: (+,   y, z, T1)      -- then: x := y+z
15: (:=, T1, -, x)
16: (j,   -, -, 10)      -- 回跳循环判断
17: (-,   y, z, T2)      -- else: x := y-z
18: (:=, T2, -, x)
19: (j,   -, -, 10)      -- 回跳循环判断
20: ...                  -- 循环出口
```

**【解析】** while E do S 骨架：L1: E 的跳转 → 真进循环体/假退出；循环体结束后回跳 L1。本题循环体是 if-then-else：c<d 为真走 then（14~16），为假走 else（17~19）；两个分支执行完都回跳判断语句 10（易漏点：while 必须回跳）。赋值四元式为 (:=, T, -, x)，第三槽为空 -。

## 第2题 FOR 循环的四元式翻译

> FOR K:=1 TO 10 DO BEGIN A:=I+10*K; B:=J+10*K; END

**【答案】四元式序列（22 为循环出口）：**

```
10: (:=,   1, -, K)      -- K := 1
11: (j<=, K, 10, 13)     -- K≤10 → 进入循环体
12: (j,   -, -, 22)      -- K>10 → 退出循环
13: (*,  10, K, T1)      -- T1 = 10*K
14: (+,   I, T1, T2)     -- T2 = I+10*K
15: (:=, T2, -, A)       -- A := I+10*K
16: (*,  10, K, T3)      -- T3 = 10*K
17: (+,   J, T3, T4)     -- T4 = J+10*K
18: (:=, T4, -, B)       -- B := J+10*K
19: (+,   K, 1, T5)      -- T5 = K+1
20: (:=, T5, -, K)       -- K := K+1
21: (j,   -, -, 11)      -- 回跳循环判断
22: ...                  -- 循环出口
```

**【解析】** FOR k:=e1 TO e2 DO S 的语法制导翻译骨架：① 赋初值 k:=e1；② 判断 k<=e2（真进循环体、假退出）；③ 循环体 S；④ 步进 k:=k+1（显式两条：先 + 后 :=）；⑤ 回跳判断。表达式自底向上翻译：I+10*K 先算 10*K 入 T1，再算 I+T1 入 T2，最后 (:=, T2, -, A)；J+10*K 同理（直接按语法制导翻译，两处 10*K 各生成一条乘法，优化时可复用）。语义验证：K=1..10 各执行一轮，A=I+10K、B=J+10K 逐轮正确，终止时 K=11。

## 第3题 写出下列表达式的逆波兰式

### （1）2＋3＋a＋b

**【答案】** `2 3 + a + b +`

**【解析】** + 为左结合：((2+3)+a)+b，后缀式按"左子树、右子树、根"输出，逐层归约即 2 3 + a + b +。

### （2）a*b + 2*c*d

**【答案】** `a b * 2 c * d * +`

**【解析】** * 优先级高于 +：a*b → a b *；2*c*d 为左结合 (2*c)*d → 2 c * d *；最后 + → a b * 2 c * d * +。

### （3）(x = x +3) *4

**【答案】** `x x 3 + = 4 *`

**【解析】** 括号内 x = x+3 先算 x+3 → x 3 +，再与 x 做赋值 = → x x 3 + =；整体乘 4 → x x 3 + = 4 *。（= 视作赋值运算符。）

### （4）(x = y = 2) + 3*(x = 4)

**【答案】** `x y 2 = = 3 x 4 = * +`

**【解析】** 赋值 = 为右结合：x = y = 2 即 x = (y = 2) → y 2 = 再 x ... = → x y 2 = =；3*(x=4) → 3 x 4 = *；最后 + → x y 2 = = 3 x 4 = * +。两个 = 连排若误按左结合写 `x y = 2 =`，就变成往 x=y 的"值"上赋 2，无意义。优先级/结合性总表与易错例见 [[期末复习专题#题型7 三元式与四元式|期末复习专题 题型7]]。
