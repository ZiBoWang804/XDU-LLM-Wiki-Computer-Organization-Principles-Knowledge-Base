# 文法和语言

> **所属章节**：第2章 高级语言及其语法描述
> **核心问题**：文法的形式化定义、Chomsky分类、推导与归约、语法树与二义性

---

## 2.1 基本概念

### 符号与符号串

| 术语 | 定义 |
|------|------|
| **字母表（Σ）** | 元素的非空有穷集合，元素称为符号 |
| **符号串** | 字母表中符号的有穷序列 |
| **空串（ε）** | 不含任何符号的符号串 |
| **符号串集合** | 由符号串组成的集合 |
| **闭包 Σ*** | Σ上所有符号串（含ε）的集合 |
| **正闭包 Σ+** | Σ上所有非空符号串的集合 |

### 运算

- **连接**：xy 表示符号串 x 后接符号串 y
- **幂**：x⁰=ε, xⁿ=xⁿ⁻¹x
- **集合乘**：AB={ab | a∈A, b∈B}
- **闭包**：A*=A⁰∪A¹∪A²∪...

---

## 2.2 文法的形式化定义

### 四元组定义

$$G = (V_N, V_T, P, S)$$

| 符号 | 含义 |
|------|------|
| $V_N$ | **非终结符**集合（变量，可被替换） |
| $V_T$ | **终结符**集合（不可再分的基本符号） |
| $P$ | **产生式**（规则）集合 |
| $S$ | **开始符号**（$S \in V_N$） |

### 产生式

形式：$A \to \alpha$ 或 $A ::= \alpha$

其中 $A \in V_N$，$\alpha \in (V_N \cup V_T)^*$

---

## 2.3 推导与归约

### 核心概念

| 术语             | 定义             |
| -------------- | -------------- |
| **直接推导（⇒）**    | 用一个产生式替换一个非终结符 |
| **推导（⇒⁺）**     | 经过一步或多步直接推导    |
| **最左推导**       | 每步替换**最左**非终结符 |
| **最右推导（规范推导）** | 每步替换**最右**非终结符 |
| **归约**         | 推导的逆过程         |

### 句型与句子

| 术语 | 定义 |
|------|------|
| **句型** | 从开始符号 S 推导出的任意符号串（$S \stackrel{*}{\Rightarrow} x$，$x \in V^*$） |
| **句子** | 仅含终结符的句型（$S \stackrel{*}{\Rightarrow} x$，$x \in V_T^*$） |
| **语言 L(G)** | 文法 G 产生的所有句子的集合 |

> [!important] 句型 vs 句子
> 句型可以包含非终结符，句子只能包含终结符。句子一定是句型，句型不一定是句子。

---

## 2.4 语法树与二义性

### 语法树

语法树是推导过程的图形表示，满足：
1. 根结点标记为开始符号 S
2. 叶结点标记为终结符或 ε
3. 内部结点标记为非终结符
4. 若内部结点 A 的子结点从左到右为 A₁A₂...Aₖ，则 $A \to A_1A_2...A_k$ 是产生式

### 二义性文法

> **定义**：若一个文法存在某个句子有**两棵不同的语法树**，则该文法是**二义性文法**。

等价说法：存在某个句子有两种不同的**最左推导**（或最右推导）。

> [!warning] 重要结论
> - 程序设计语言的文法**必须是无二义的**
> - 证明二义性：找一个句子，给出两棵不同的语法树
> - 证明无二义性：需要严格证明每个句子只有一棵语法树（较难）

---

## 2.5 Chomsky 文法分类

| 类型     | 名称      | 产生式限制                                                                                         | 识别自动机   |     |     |     |     |     |     |     |     |
| ------ | ------- | --------------------------------------------------------------------------------------------- | ------- | --- | --- | --- | --- | --- | --- | --- | --- |
| **0型** | 无限制文法   | $\alpha \to \beta$，$\alpha$ 至少含一个非终结符                                                         | 图灵机     |     |     |     |     |     |     |     |     |
| **1型** | 上下文有关文法 | $\alpha A \beta \to \alpha \gamma \beta$（$\|\gamma\|\geq\|A\|$$，即不缩短； 约定 S\to\varepsilon$ 除外） | 线性有界自动机 |     |     |     |     |     |     |     |     |
| **2型** | 上下文无关文法 | $A \to \alpha$（$A \in V_N$）                                                                   | 下推自动机   |     |     |     |     |     |     |     |     |
| **3型** | 正规文法    | $A \to aB$ 或 $A \to a$（$A,B \in V_N, a \in V_T$）                                              | 有穷自动机   |     |     |     |     |     |     |     |     |

> [!tip] 包含关系
> 3型 ⊂ 2型 ⊂ 1型 ⊂ 0型
> 每一种正规文法都是上下文无关文法，每一种上下文无关文法都是上下文有关文法。

---

## 2.6 上下文无关文法 (CFG)

程序设计语言的语法主要用 **2型文法（上下文无关文法）** 描述。

### 短语、直接短语与句柄

设句型 $\alpha = xuy$，若 $S \stackrel{*}{\Rightarrow}_m xAy \Rightarrow xuy$，则 u 是句型 α 关于 A 的**短语**。

| 术语 | 定义 |
|------|------|
| **短语** | 句型中可被某个非终结符推导出的子串 |
| **直接短语（简单短语）** | 通过一步推导得到的短语 |
| **句柄** | **最左**直接短语 |

> [!important] 句柄的作用
> 句柄是自底向上语法分析中每步**归约的对象**。找到句柄，就可以用对应的产生式进行归约。

### 素短语

- **素短语**：至少含一个终结符，且不含更小的素短语的短语
- **最左素短语**：句型中最左边的素短语

---

## 2.7 左递归的消除

### 直接左递归消除

若 $A \to A\alpha | \beta$（$\beta$ 不以 A 开头），等价变换为：

$$A \to \beta A'$$
$$A' \to \alpha A' | \varepsilon$$

### 间接左递归消除

先代入化为直接左递归，再用上述方法消除。

---

## 2.8 左公共因子的提取

若 $A \to \alpha\beta | \alpha\gamma$，等价变换为：

$$A \to \alpha A'$$
$$A' \to \beta | \gamma$$

> 左递归和左公共因子都会导致 LL(1) 分析失败，必须消除。

---

## 2.9 文法与自动机的对应关系（PPT补充）

| 文法类型 | 产生式限制 | 识别系统（自动机） |
|---------|-----------|------------------|
| **0型** | α→β，α含非终结符 | **图灵机** |
| **1型** | \|β\| ≥ \|α\| | **线性界限自动机** |
| **2型** | A→β | **不确定的下推自动机** |
| **3型** | A→aB 或 A→a | **有穷自动机（FA）** |

> [!important] PPT重点
> - 0型文法能力 = 图灵机，可表征任何递归可枚举集
> - 1型文法（上下文有关）：只有A出现在α₁和α₂的上下文中时，才允许β取代A
> - 2型文法（上下文无关）：β取代A时与A的上下文无关
> - 3型文法（正规文法）：有穷自动机所接受的集合
> - **任何能用图灵机描述的计算都能机械实现，任何能在现代计算机上实现的计算都能用图灵机描述**

### 四种文法的包含关系

```
3型 ⊂ 2型 ⊂ 1型 ⊂ 0型
正规 ⊂ 上下文无关 ⊂ 上下文有关 ⊂ 无限制
```

- 存在0型语言不是上下文有关语言
- 存在1型语言不是上下文无关语言
- 存在2型语言不是正规语言

---

## 2.10 上下文无关文法的特点（PPT补充）

- 所定义的语法范畴完全**独立于**该范畴可能出现的环境
- 足以描述现今的**程序设计语言**
- **自然语言**需要用其他文法来描述
- 有穷条产生式产生无穷集，要求产生式必须**递归**

---

## 2.11 语言的描述方法（PPT补充）

| 方法 | 适用场景 |
|------|---------|
| **枚举法** | 语言只有有限个句子 |
| **文法规则** | 用有限条规则产生所有句子（推荐） |
| **自动机** | 建立识别装置来定义语言 |

## 典型例题

### 例1：求 L(G)
文法 G=({A,B,S},{a,b,c},P,S)，P: S→Ac|aB, A→ab, B→bc
- L(G[S]) = {abc}（两条路：S⇒Ac⇒abc，S⇒aB⇒abc）

### 例2：偶正整数文法
允许0打头：
- $S \to AB$，$A \to 0|1|...|9$，$B \to 0|2|4|6|8$

不允许0打头：
- $S \to AB$，$A \to 1|2|...|9$，$B \to 0|2|4|6|8$
- 或：$S \to A0|A2|A4|A6|A8$，$A \to 1|2|...|9$

### 例3：上下文无关文法构造
$\{a^nb^n | n \geq 1\}$：
- $S \to aSb | ab$

$\{WaW^R | W \in \{0,a\}^*\}$：
- $S \to 0S0 | aSa | \varepsilon$
