# comporg-doctor

## 作用

`comporg-doctor` 是当前《计算机组成原理》知识库的治理与巡检 skill。

它不直接负责课程答题，而是负责：

- 审计知识库结构
- 发现冲突、污染、错误和覆盖率缺口
- 自动修复低风险结构问题
- 为高风险内容修改准备待确认项

## 适用场景

- 巡检知识库
- 检查这批页有没有问题
- 查知识点是否有冲突
- 修索引、修死链
- 检查题型页、模板页、代表题页
- 做知识库治理报告

## 触发词

- `巡检知识库`
- `检查这批页`
- `查一下有没有错`
- `治理这个知识点`
- `doctor 治理`
- `检查题型页`
- `检查代表题`
- `检查模板`
- `修死链`
- `修索引`

## 标准工作流

1. 确定本轮审计范围
2. 先读索引，再读目标页，再按需回读证据层
3. 按固定问题分类法归类发现
4. 自动修复低风险结构问题
5. 为高风险问题准备权限门控修复建议
6. 对已修项复核
7. 输出四段式治理报告

## 重点审计层级

优先级从高到低：

1. `题型页 / 代表题页 / 标准化答题模板`
2. `知识点页`
3. `资料整理稿 / 图像解读 / 勘误 / 分歧`
4. `个人演化层`

## 固定问题分类

- 知识冲突
- 代表题错误
- OCR / 证据污染
- 死链 / 索引不同步
- 层违规
- 模板漂移
- 演化层混乱
- 覆盖率缺口

## 关键约束

- Markdown 是唯一主知识资产
- 不偷偷改写原始资料
- 不把规范层、证据层、演化层混写
- 不无差别全库暴力读取
- 低风险结构问题可自动修
- 规范结论、标准答案、高风险内容修改必须先征得许可

## 输出要求

- 使用中文
- 明确区分“已自动修复”和“需要确认”
- 给出涉及文件
- 标出风险等级
- 对重要发现说明证据链

## 与其他 skill 的关系

- 与 `comporg-answer`
  - 当答题 skill 发现答案与知识库冲突时，可回挂给 doctor 做治理
- 与 `comporg-kb-builder`
  - 当资料入库后出现结构问题、污染或冲突时，由 doctor 负责后续治理
