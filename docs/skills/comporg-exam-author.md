# comporg-exam-author

## 作用

`comporg-exam-author` 用于基于当前 Markdown 知识库和本地试卷风格，生成正式的《计算机组成原理》试卷包。

它的目标不是随便拼几道练习题，而是：

- 学习本地试卷的章节覆盖和题型分布
- 以“同口径改编”为主生成整张卷子
- 控制原题复用比例
- 同时给出参考答案、给分点、覆盖表和命题说明

## 适用场景

- 正式组卷
- 按本地试卷风格出卷
- 生成参考答案
- 生成给分点
- 生成知识点覆盖表

## 触发词

- `组卷`
- `出正式试卷`
- `命题`
- `生成试卷`
- `出一套计组卷子`
- `按本地试卷风格出卷`
- `生成参考答案`
- `生成给分点`

## 标准工作流

1. 固定试卷规格
2. 学习本地试卷结构
3. 锁定知识点和题型覆盖
4. 以同口径改编为主选择或改写题目
5. 检查直接原题复用比例
6. 生成正式试卷
7. 生成参考答案
8. 生成给分点
9. 生成知识点覆盖表和命题说明
10. 进入最终大模型复核层
11. 复核通过后再输出

## 核心规则

- Markdown 是唯一主知识资产
- 正式试卷模式优先
- “同口径改编”是主模式
- 直接原题复用比例不超过 10%
- 必须覆盖章节层和知识点层
- 文档输出时应尽量采用报告式结构
- 参考答案要贴近知识库中的标准化答题模板

## 默认试卷形态

在用户不另行指定时，默认采用：

- `100 分`
- `90 分钟`
- `6~8 道大题`
- 重点覆盖 `第2/3/4/5/7/8章`

常见题型包括：

- 概念简答
- 编码 / 数值计算
- 寻址 / 程序分析
- 存储器扩展
- 微操作 / 控制器

## 默认入口页

- `知识库/题型/index.md`
- `知识库/知识点/index.md`
- `知识库/专题/期末重点/高频题型覆盖表.md`
- `知识库/专题/期末重点/代表题与标准答案.md`
- `知识库/专题/期末重点/标准化答题模板.md`

## 输出要求

- 使用中文
- 输出完整试卷包，而不是只给题面
- 说明原题复用比例
- 给出知识点覆盖表
- 给出命题说明
- 参考答案尽量贴近仓库已有模板和题型页风格

## 与其他 skill 的关系

- 与 `comporg-answer`
  - 参考答案风格应与答题 skill 保持一致
- 与 `comporg-doctor`
  - 若组卷过程中发现题型页或标准答案存在明显问题，可回挂治理
