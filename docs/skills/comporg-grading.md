# comporg-grading

## 作用

`comporg-grading` 用于基于当前 Markdown 知识库，对学生的作业、随堂测验、试卷和练习题答案进行细粒度批改。

它负责：

- 识别题目与学生答案
- 检索本地批改证据
- 按小问 / 步骤 / 知识点给分
- 生成评语
- 形成错因和弱项候选
- 输出前经过最终大模型审核

## 适用场景

- 批改作业
- 批改试卷
- 逐项评分
- 给评语
- 做错因分析
- 记录弱项候选

## 触发词

- `批改作业`
- `批改试卷`
- `评分`
- `给评语`
- `看学生答案`
- `逐项给分`
- `错因分析`
- `弱项记录`

## 标准工作流

1. 识别题目、小问和学生实际作答内容
2. 路由到相关题型和知识点
3. 以 `md-first` 顺序检索批改证据
4. 按子问题、步骤、知识点逐项评分
5. 生成评语、错因候选和弱项候选
6. 进入最终大模型审核层
7. 审核通过后输出
8. 若结论不稳，标记为教师复核

## 核心规则

- Markdown 是唯一主知识资产
- 必须基于本地证据评分，不能只凭模型印象
- 细粒度给分是默认要求
- 解法不同但知识正确时允许给分
- 格式问题默认只记录，不单独扣格式分
- 不确定项必须标记为 `教师复核`
- 未经最终复核，不得直接输出批改结论

## 默认入口页

- `知识库/题型/index.md`
- `知识库/知识点/index.md`
- `知识库/专题/期末重点/标准化答题模板.md`
- `知识库/专题/期末重点/高频题型覆盖表.md`
- `知识库/专题/期末重点/代表题与标准答案.md`

## 输出要求

- 使用中文
- 给分依据可追溯
- 区分“明确扣分 / 得分事实”和“需要复核的不确定项”
- 给出简洁的学生可读评语
- 生成写回候选，而不是静默改知识库

## 与其他 skill 的关系

- 与 `comporg-answer`
  - 批改时参考的标准答案风格应与答题 skill 的成稿口径一致
- 与 `comporg-doctor`
  - 若发现代表题或模板有误，应回挂治理
