# 计组知识工程与任务智能体 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个面向《计算机组成原理》课程的、可纠错、可审计、可持续记忆的知识工程与 5 Skill / 5 Agent 任务套件，并完成本地 Quartz 展示、知识关系网络图、思维导图、审核与复核工作流。

**Architecture:** 以 Python 项目承载机器知识层、任务 Agent、记忆层与审核层；以 SQLite/FTS5 作为结构化索引底座，以 Markdown/Quartz 作为可读 Wiki 层；所有 Agent 统一先走 Knowledge API 获取证据，再由模型路由器根据任务复杂度选择 `gpt-5.4-mini` 或 `gpt-5.4` 及对应思考强度。

**Tech Stack:** Python 3.11+, sqlite3/FTS5, pytest, Markdown, Quartz, OpenAI-compatible model client, 本地已有 skills 与 MCP 工具接入

---

## Scope Note

该设计包含多个子系统，但不是独立产品线。`Agent 2-5` 全部依赖同一套知识库、记忆和审核接口，因此保留为一个统一计划；实现顺序体现依赖关系，不代表任何功能降级或只交付局部版本。

# src/comporg_agents/ingest/classifier.py
from pathlib import Path


def classify_source(path: Path, mime_type: str, text_density: float) -> str:
    name = path.name.lower()
    if mime_type == "application/pdf" and text_density < 0.05 and ("试卷" in name or "扫描" in name):
        return "scanned_exam"
    if mime_type == "application/pdf" and text_density < 0.05:
        return "image_pdf"
    if mime_type == "application/pdf" and ("spring" in name or "课件" in name):
        return "ppt_like_pdf"
    if mime_type == "application/pdf":
        return "text_pdf"
    return "mixed_layout_doc"
```

# src/comporg_agents/ingest/quality.py
from dataclasses import dataclass


@dataclass(slots=True)
class QualityReport:
    score: float
    label: str


def score_page_quality(text_density: float, ocr_confidence: float, symbol_integrity: float, image_legibility: float) -> QualityReport:
    score = (text_density + ocr_confidence + symbol_integrity + image_legibility) / 4
    if score < 0.55:
        return QualityReport(score=score, label="manual_review_required")
    if score < 0.75:
        return QualityReport(score=score, label="medium_quality")
    return QualityReport(score=score, label="high_quality")
```

# src/comporg_agents/knowledge/chunker.py
def chunk_document(structured: dict, source_id: str) -> list[dict]:
    chunks = []
    for index, section in enumerate(structured["sections"], start=1):
        chunks.append(
            {
                "chunk_id": f"{source_id}-{index}",
                "source_id": source_id,
                "chapter": structured["chapter"],
                "topic": section["title"],
                "content_type": section["kind"],
                "content": section["text"],
            }
        )
    return chunks
```

# src/comporg_agents/wiki/maps.py
def build_mindmap_markdown(chapter: str, tree: dict[str, list[str]]) -> str:
    lines = ["```mermaid", "mindmap", f"  root(({chapter}))"]
    for parent, children in tree.items():
        lines.append(f"    {parent}")
        for child in children:
            lines.append(f"      {child}")
    lines.append("```")
    return "\n".join(lines)
```

from dataclasses import dataclass


@dataclass(slots=True)
class ModelRoute:
    model: str
    reasoning: str


def route_model(task_type: str, complexity: str, submission_quality_required: bool) -> ModelRoute:
    del task_type
    if submission_quality_required or complexity == "high":
        return ModelRoute(model="gpt-5.4", reasoning="xhigh")
    if complexity == "medium":
        return ModelRoute(model="gpt-5.4", reasoning="high")
    return ModelRoute(model="gpt-5.4-mini", reasoning="medium")
```
