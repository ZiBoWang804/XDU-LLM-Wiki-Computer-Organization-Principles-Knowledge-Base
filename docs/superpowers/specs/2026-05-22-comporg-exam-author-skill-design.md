# comporg-exam-author Skill 设计

## 1. 定位

`comporg-exam-author` 是一个依托当前《计算机组成原理》 Markdown 知识库的正式组卷 Skill。

它的目标不是随便凑题，而是：

- 学习本地试卷的覆盖范围与出题结构
- 按本地课程口径生成正式试卷
- 同时生成参考答案、给分点、知识点覆盖表和命题说明

## 2. 默认主模式

第一版默认主模式固定为：

- `正式试卷`

而不是：

- 练习卷
- 专题卷

练习卷 / 专题卷后续可再做成附加模式，但不作为第一版主模式。

## 3. 默认卷面规格

默认正式试卷模板固定为：

- `100 分`
- `90 分钟`
- `6~8 道大题`
- 重点覆盖 `第2/3/4/5/7/8章`

默认题型至少应包含：

- 概念简答
- 编码 / 计算
- 寻址 / 程序分析
- 存储器扩展
- 微操作 / 控制器

## 4. 依托对象

`comporg-exam-author` 依托以下 Markdown 主库工作：

- `知识库/题型/**/*.md`
- `知识库/知识点/**/*.md`
- `知识库/专题/期末重点/高频题型覆盖表.md`
- `知识库/专题/期末重点/代表题与标准答案.md`
- `知识库/专题/期末重点/标准化答题模板.md`
- `知识库/资料整理稿/试卷/**/*.md`
- `知识库/资料整理稿/作业/**/*.md`
- `知识库/资料整理稿/课件/**/*.md`
- `知识库/个人演化/**/*.md`

工作时必须遵守：

- `.md` 是唯一主知识库
- 优先围绕题型页、知识点页、代表题页组织出卷
- 不全库粗暴读取，必须先索引后正文

## 5. 出题来源优先级

出题来源优先级固定为：

1. 知识库中已有代表题 / 高频题型
2. 在本地课程资料口径内做改编题
3. 只有覆盖不足时，才由模型补新题
4. 新题必须挂回知识点和题型链

原则：

- 先复用结构
- 再改编
- 最后才补新题

## 6. 主出题策略

第一版默认主策略固定为：

- `同口径改编`

含义：

- 保持知识点不变
- 保持题型不变
- 保持难度结构不变
- 改参数
- 改数据
- 改问法

## 7. 原题复用比例限制

这是硬规则。

试卷中直接出现的资料原题，占整张试卷的比例：

- **不超过 10%**

默认应尽量避免原题直接照搬，优先采用：

- 改编数据
- 改编参数
- 改编问法

输出时必须附：

- 原题复用占比说明

## 8. 知识点覆盖约束

组卷时必须满足：

1. 每张正式卷至少覆盖 `6~10` 个核心知识点
2. 每章至少有 `1` 个主考点落题
3. 同一知识点不能在整张卷里重复作为主考点过多次
4. 允许单题同时覆盖“主考点 + 支撑知识点”
5. 组卷后必须输出一份知识点覆盖表

## 9. 学习本地试卷结构

在正式出题前，Skill 必须先学习本地试卷的：

- 出题范围
- 涵盖的知识点数量
- 涵盖的知识点范围
- 各章覆盖比例
- 题型分布
- 常见题目组合方式

也就是说，出卷不是单题质量优化，而是：

1. 先学已有试卷的卷面结构
2. 再按这个结构去出正式卷

## 10. 配套输出

正式试卷默认同时生成以下 5 项：

### 10.1 正式试卷

给学生看的卷面。

### 10.2 参考答案

按当前课程认可口径与答题风格输出的标准答案。

### 10.3 评分要点 / 给分点

供后续 `comporg-grading` 复用。

### 10.4 知识点覆盖表

说明：

- 每题主考哪些知识点
- 整张卷覆盖了哪些知识点
- 各章覆盖情况如何

### 10.5 命题说明

简要说明：

- 本卷参考了哪些本地题型
- 覆盖了哪些章节
- 主要改编来源是什么

## 11. 最终输出前的大模型审核层

这是本 Skill 的硬规则。

流程不是：

- 组卷 -> 输出

而是：

1. 学试卷结构
2. 选题 / 改编 / 补缺
3. 生成试卷
4. 生成参考答案与给分点
5. 生成覆盖表与命题说明
6. **进入大模型审核层**
7. 若审核有问题，回退修正
8. 审核通过后才正式输出

### 11.1 审核重点

至少检查：

1. 题目本身是否正确
2. 参考答案是否正确
3. 覆盖分布是否偏科
4. 难度梯度是否失衡
5. 原题复用比例是否超标
6. 改编后是否仍符合课程口径

### 11.2 审核后的处理规则

- 审核通过：正式输出
- 审核不通过：退回改题 / 改答案 / 调整覆盖
- 若多轮后仍不稳定：标注为“待人工复核的组卷结果”

## 12. 与现有技能关系

### 12.1 与 `comporg-answer`

`comporg-answer` 负责：

- 标准答案生成
- 答疑

`comporg-exam-author` 负责：

- 正式组卷
- 参考答案配套生成

### 12.2 与 `comporg-grading`

`comporg-grading` 负责：

- 学生答案批改
- 评分建议

`comporg-exam-author` 生成的“评分要点 / 给分点”可供其后续复用。

### 12.3 与 `comporg-doctor`

若组卷过程中发现：

- 本地代表题或参考答案本身有误
- 题型模板存在结构性冲突
- 某知识点长期缺代表题导致无法稳定出卷

应生成：

- `doctor_hook_required`

候选，交给 `comporg-doctor` 做治理。

## 13. 工作流

`comporg-exam-author` 的内部流程固定为：

1. 确定卷面规格
2. 学习本地试卷覆盖结构
3. 锁定目标知识点与题型
4. 选题 / 改编 / 补缺
5. 检查原题复用比例
6. 生成正式试卷
7. 生成参考答案
8. 生成评分要点 / 给分点
9. 生成知识点覆盖表
10. 生成命题说明
11. 进入大模型审核层
12. 审核通过后正式输出

## 14. 非目标与禁止事项

当前 `comporg-exam-author` 不负责：

- 直接替老师发布最终不可更改试卷
- 为了凑覆盖而无依据生成大量新题
- 在原题复用比例失控时强行出卷

明确禁止：

- 直接照搬大量原题
- 改编后脱离本地课程口径
- 不做审核直接输出正式卷
- 不输出覆盖表和命题说明

`comporg-exam-author` 的核心使命是：

**先学习本地试卷结构，再以同口径改编为主生成正式试卷，并在输出前经过大模型审核，从而得到覆盖合理、风格贴本地课程、原题复用受控的组卷结果。**
