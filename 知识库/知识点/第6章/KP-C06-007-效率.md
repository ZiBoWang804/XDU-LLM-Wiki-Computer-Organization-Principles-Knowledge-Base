# 效率

## 定义

效率是指流水线的设备利用率，也就是各段真正工作的时空面积与总时空面积之比。教材在 `6.2.3` 中说明：通过时间和排空时间都会造成部分流水段空闲，因此效率通常小于 `1`。

## 结构 / 规则 / 公式

- 各段时间相等时，每一段的设备利用率相同，可记为 `e0`：

$$
{ \mathrm { e } } _ { 0 } = { \mathrm { e } } _ { 1 } = \cdots = { \mathrm { e } } _ { m } = \frac { n \Delta t } { T }\tag{6-10}
$$

- 整条流水线的效率为：

$$
\mathrm { E } = \frac { m e_0 } { m } = \frac { m n \Delta t } { mT }\tag{6-11}
$$

- 代入各段时间相等时的总时间公式，可得：

$$
\mathbf { E } = { \frac { \mathbf { n } \Delta \mathbf { t } } { \mathbf { m } \Delta \mathbf { t } + ( \mathbf { n } - 1 ) \Delta \mathbf { t } } } = { \frac { 1 } { 1 + { \frac { \mathbf { m } - 1 } { \mathbf { n } } } } }\tag{6-12}
$$

- 教材进一步给出效率与加速比、吞吐率的关系：

$$
\mathrm { E } = \mathrm { S } / m,\quad \mathrm { S } = m \mathrm { E }\tag{6-13}
$$

$$
\mathrm { E } = \mathrm { T P } \Delta t,\quad \mathrm { T P } = \mathrm { E } / \Delta t\tag{6-14}
$$

- 各段时间不相等时：

$$
\mathrm { E } = \frac { n \sum _ { i = 1 } ^ { m } \Delta t_i } { m \left[ \sum _ { i = 1 } ^ { m } \Delta t_i + ( n - 1 ) \Delta t_{\max} \right] }\tag{6-15}
$$

## 易混点 / 易错点

- 效率不是“做完得快不快”，而是设备利用率；它和加速比相关，但不是同一个量。
- 各段时间相等时可直接用式 `(6-12)`；各段时间不相等时必须改用式 `(6-15)`。
- `E = TP·Δt` 只是在教材该组定义下的关系式，不能把效率直接当作吞吐率本身。

## 常见关联场景

- 由时空图解释为什么流水线开始和结束阶段效率较低。
- 计算各段时间相等或不等时的流水线效率。
- 对比“吞吐率高但效率不一定高”的情况。
