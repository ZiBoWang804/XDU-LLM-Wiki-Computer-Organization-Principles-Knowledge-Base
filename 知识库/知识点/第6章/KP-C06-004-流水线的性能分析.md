# 流水线的性能分析

## 定义

教材在 `6.2` 中以线性流水线为对象，分析三个核心性能指标：吞吐率、加速比和效率，并区分“各段时间相等”与“各段时间不相等”两类情况。

## 课程资料中的表述

- 教材认为，流水线性能分析首先要看吞吐率，其次看加速比和效率。
- 当各段时间不相等时，最长时间段会成为瓶颈，直接限制最大吞吐率，并降低整条流水线效率。
- 当任务数 `n` 很大时，实际吞吐率、加速比和效率才分别更接近其理想上限。

## 结构 / 规则 / 公式

- 最大吞吐率：
  - 各段时间相等时

$$
\mathrm { T P } _ { \mathrm { max } } = \frac { 1 } { \Delta t }\tag{6-1}
$$

  - 各段时间不相等时

$$
\mathrm { T P } _ { \mathrm { max } } = \frac { 1 } { \max \{ \Delta t_i \} }\tag{6-2}
$$

- 完成 `n` 个任务的时间：
  - 各段时间相等时

$$
\mathrm { T } = \mathrm { m } \Delta \mathrm { t } + ( \mathrm { n } - 1 ) \Delta \mathrm { t }\tag{6-4}
$$

  - 各段时间不相等时

$$
\mathrm { T } = \sum _ { i = 1 } ^ { m } \Delta t_i + (n-1)\Delta t_{\max}\tag{6-6}
$$

- 实际吞吐率：

$$
\mathrm { T P } = \frac { n } { T }\tag{6-5,6-7}
$$

- 加速比：

$$
\mathrm { S } = \frac { \mathrm { T } _ { \mathrm { 顺序 } } } { \mathrm { T } }\tag{6-8,6-9}
$$

- 效率：

$$
\mathrm { E } = \frac { \text{各段实际工作时空面积} } { \text{总时空面积} }\tag{6-11,6-15}
$$

- 教材还给出关系：

$$
\mathrm { E } = \mathrm { S } / m
$$

并指出当 `n >> m` 时，效率更接近 `1`。

## 易混点 / 易错点

- 最大吞吐率是稳定连续工作时的理想值，实际吞吐率还与任务数 `n` 有关。
- 流水线段数 `m` 越多，不代表一定更好；若出现严重瓶颈，效率会明显下降。
- 加速比的极限与段数有关，但真正达到这一极限需要大量连续任务。

## 常见关联场景

- 计算吞吐率、加速比和效率。
- 解释为什么瓶颈段会限制流水线性能。
- 分析“任务数不够大时，流水线为什么没有想象中快”。
