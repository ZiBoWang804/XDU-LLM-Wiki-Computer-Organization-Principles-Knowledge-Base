# 加速比

## 定义

加速比是指顺序执行完成同样任务所需时间与采用流水线执行所需时间之比。教材在 `6.2.2` 中分别给出各段时间相等和不相等时的计算式，并强调当任务数足够大时，加速比才接近理想上限。

## 课程资料中的表述

- 流水线的加速比是指m段流水线顺序执行n个任务的时间与流水线执行的时间之比。同样分两种情况。
- 当各段时间均为△t的m段流水线，顺序完成n个任务所用的时间 $\Delta { \sf t }$ ${ \mathrm { T } } _ { \parallel \perp } = { \mathrm { n m } } \Delta { \mathrm { t } }$ ；而采用流水线所用的时间为 $\mathrm { T } { = } \mathrm { m } \Delta \mathrm { t } { + } ( \mathrm { n } { - } 1 ) \Delta \mathrm { t }$ 。则此流水线的加速比S表示如下。
- 由式(6-8)可以看到，在各段时间相等均为△t的m段流水线中，当n很大 $\Delta { \sf t }$ $( > > { \mathfrak { m } } )$ 时，
- 流水线的加速比就接近于流水线的段数m。可以说，流水线的段数越多，加速比就越大。
- $$
- \mathbf { S } = { \frac { \mathrm { T } _ { \mathsf { s g } } } { \mathrm { T } } } = { \frac { \mathrm { n m } \Delta \mathbf { t } } { \mathrm { m } \Delta \mathbf { t } + ( \mathbf { n } - 1 ) \Delta \mathbf { t } } } = { \frac { \mathbf { m } } { 1 + { \frac { \mathrm { m } - 1 } { \mathbf { n } } } } }\tag{6-8}
- $$
- 当各段时间不相等的m段流水线，顺序完成n个任务所用的时间 $\mathrm { T _ { \parallel f } }$ 和利用流水线完成n个任务所用时间T分别表示如下。

## 结构 / 规则 / 公式

- 各段时间相等、每段时间均为 `Δt` 的 `m` 段流水线，完成 `n` 个任务时：

$$
\mathbf { S } = { \frac { \mathrm { n m } \Delta \mathbf { t } } { \mathrm { m } \Delta \mathbf { t } + ( \mathbf { n } - 1 ) \Delta \mathbf { t } } } = { \frac { \mathbf { m } } { 1 + { \frac { \mathrm { m } - 1 } { \mathbf { n } } } } }\tag{6-8}
$$

- 因此，当 `n >> m` 时，加速比才接近流水线段数 `m`。

- 各段时间不相等时，顺序时间与流水线时间分别为：

$$
\mathrm { T } _ { \mathrm { 顺序 } } = \mathrm { n } \sum _ { i = 1 } ^ { m } \Delta t_i
$$

$$
\mathrm { T } = \sum _ { i = 1 } ^ { m } \Delta t_i + ( n - 1 ) \Delta t_{\max}
$$

- 相应加速比为：

$$
\mathrm { S } = \frac { n \sum _ { i = 1 } ^ { m } \Delta t_i } { \sum _ { i = 1 } ^ { m } \Delta t_i + ( n - 1 ) \Delta t_{\max} }\tag{6-9}
$$

## 易混点 / 易错点

- 加速比是“顺序时间 / 流水线时间”，不是吞吐率的直接别名。
- “段数越多加速比越大”只是在任务数足够大且结构合理时才近似成立。
- 各段时间不相等时，瓶颈段会压低加速比，不能简单把结果近似成 `m`。

## 常见关联场景

- 计算流水线相对于顺序执行的加速效果。
- 解释为什么同一条流水线在任务数少时“看起来不够快”。
- 分析各段时间不均衡时加速比下降的原因。
