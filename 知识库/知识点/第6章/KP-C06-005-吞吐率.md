# 吞吐率

## 定义

吞吐率是指流水线在单位时间内完成的任务数或输出的结果数。教材在 `6.2.1` 中区分最大吞吐率与实际吞吐率，并分别讨论各段时间相等和不相等两种情况。

## 课程资料中的表述

- 流水线的吞吐率是指流水线在单位时间里所完成的任务数或输出的结果数。
- 1.最大吞吐率 $\mathbf { T P _ { m a x } }$
- 流水线的最大吞吐率是指流水线连续工作达到稳定状态后，单位时间里所完成的任务数或输出的结果数。
- 若流水线各段的时间 $\Delta \mathfrak { t }$ 都一样，如图6-1和图6-5所示的那样，则这样的流水线的最大吞吐率 $\mathrm { T P } _ { \operatorname* { m a x } }$ 为
- $$
- \mathrm { T P } _ { \mathrm { m a x } } = { \frac { 1 } { \Delta t } }\tag{6-1}
- $$
- 当流水线各段时间不相等时，流水线就会产生瓶颈。图6-9表示了具有瓶颈的流水线及其时空图。

## 结构 / 规则 / 公式

- 最大吞吐率：
  - 各段时间相等时

$$
\mathrm { T P } _ { \mathrm { m a x } } = { \frac { 1 } { \Delta t } }\tag{6-1}
$$

  - 各段时间不相等时

$$
\mathrm { T P } _ { \mathrm { m a x } } = \frac { 1 } { \max \{ \Delta t_i \} }\tag{6-2}
$$

- 实际吞吐率取决于完成 `n` 个任务所用总时间 `T`：
  - 各段时间相等时

$$
\mathrm { T } = \mathrm { m } \Delta \mathrm { t } + ( \mathrm { n } - 1 ) \Delta \mathrm { t }\tag{6-4}
$$

$$
\mathrm { T P } = \frac { \mathrm { n } } { \mathrm { T } } = \frac { \mathrm { T P } _ { \mathrm { m a x } } } { 1 + \frac { \mathrm { m } - 1 } { \mathrm { n } } }\tag{6-5}
$$

  - 各段时间不相等时

$$
\mathrm { T } = \sum _ { i = 1 } ^ { m } \Delta t_i + ( n - 1 ) \Delta t_{\max}\tag{6-6}
$$

$$
\mathrm { T P } = \frac { n } { T }\tag{6-7}
$$

- 教材明确指出：当各段时间不相等时，最长时间段构成瓶颈，最大吞吐率由该段决定。

## 易混点 / 易错点

- 最大吞吐率是理想稳定工作状态下的上限，实际吞吐率还取决于任务数 `n`。
- 各段时间不相等时，不能继续套用 `1/Δt`，应改用最长段时间 `Δtmax`。
- “完成一个任务以后每隔多久流出一个任务”对应的是稳定区间的吞吐能力，不等于整个过程的平均吞吐率。

## 常见关联场景

- 计算流水线的最大吞吐率与实际吞吐率。
- 说明为什么瓶颈段会限制整个流水线的输出速度。
- 分析“任务数不大时，实际吞吐率为何达不到理想值”。
