# 数值数据的编码

## 定义

数值数据的编码是指用机器可识别的进位计数制和编码规则来表示数量大小。教材在 `2.1.1` 中先说明常用进位计数制及按权展开，再区分机器数与真值、无符号数与有符号数，以及定点数与浮点数。

## 课程资料中的表述

- 常见的进位计数制有十进制、二进制、八进制和十六进制。
- 十进制数中共有0～910个数码，其计数特点及进位原则为“逢十进一”。十进制的基数为10,位权为 $1 0 ^ { \mathrm { I } } ( \mathrm { I }$ 是整数)。十进制数后面常用字母D标记或者默认。
- 计算机中常用的计数制还有二进制、八进制、十六进制。
- 二进制数中只有0和1两个数码，其计数特点及进位原则为"逢二进一”。二进制的基数为2,位权为 $2 ^ { 1 } \mathrm { ( I }$ 是整数)。二进制数的后面常用字母B标记。
- 八进制数中共有 $0 \sim 7 ~ 8$ 个数码，其计数特点及进位原则为“逢八进一”。八进制的基数为8,位权为 $8 ^ { 1 } \mathrm { { ( } I }$ 是整数)。八进制数的后面常用字母O标记。
- 十六进制数中共有0～9、A、B、C、D、E、F16 个数码,其计数特点及进位原则为"逢十六进-”。十六进制的基数为16,位权为 $1 6 ^ { 1 } ( \mathrm { I }$ 是整数)。十六进制数的后面常用字母H标记。

## 结构 / 规则 / 公式

- 任意一个 `r` 进制数都可以写成按权展开的多项式之和：

$$
{ \sf N } _ { \sf r } = \sum _ { { \sf i } = { \sf m } - 1 } ^ { - { \sf k } } { \sf D } _ { \sf i } \times { \sf r } ^ { \sf i }\tag{2-1}
$$

- 教材把“数值数据”分成两层来理解：
  - 真值：实际的数值大小。
  - 机器数：真值在机器中的编码形式。

- 无符号数的每一位都表示数值；有符号数则把最高位作为符号位，通常约定 `0` 表示正、`1` 表示负。

- 定点数与浮点数的区分在于小数点位置是否固定：
  - 定点整数：小数点固定在最低有效位之后。
  - 定点小数：小数点固定在最高有效位之前。
  - 浮点数：写成尾数与阶码的乘积形式。

- 基数为 `2` 的浮点表示为：

$$
\mathrm { F } = \mathbf { M } \times 2 ^ { \mathtt { E } }\tag{2-2}
$$

- 教材在这一节的功能是总述，因此后续原码、补码、移码、BCD 码、浮点表示等细节，都应继续回到各自子知识点中理解。

## 易混点 / 易错点

- “机器数”不是实际数值本身，而是机器内部采用的编码形式；求解题目时经常需要先从机器数还原到真值。
- “定点 / 浮点”的区别是小数点位置是否固定，不是有没有符号位。
- 进位计数制转换、编码规则和运算规则是三个不同层次，不能混成同一件事。

## 常见关联场景

- 作为后续原码、补码、移码、BCD 码和浮点表示的总入口。
- 说明为什么同一个真值在不同编码规则下会对应不同机器数。
- 解释题型中“先判定编码类型，再求真值或范围”的第一步依据。
