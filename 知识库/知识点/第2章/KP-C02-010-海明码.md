# 海明码

## 定义

海明码是根据编码最小距离理论构造的一类纠错码。教材在 `2.3.2` 中强调它具有 1 位纠错能力，并通过 8 位数据示例说明其编码、校验和定位错误的过程。

## 课程资料中的表述

- 在计算机运行过程中，由于种种原因致使数据在存储过程中可能出现差错。为了能及时发现错误并及时纠正错误，通常将原数据配成海明编码。
- 海明码具有一位纠错能力。由编码纠错理论得知，任何一种编码是否具有检错能力和纠错能力，都与编码的最小距离有关。
- 当编码最小距离 `L = 3` 时，可视为最多能检错二位，或能检错一位、纠错一位。

## 结构 / 规则 / 公式

- 编码能力关系：
  - `L - 1 = D + C`
  - `D >= C`
- 检测位数条件：
  - `2^k >= n + k + 1`
  - 其中 `n` 为信息位位数，`k` 为新增检测位位数。
- 编码思路：
  1. 先根据上式确定所需的检测位数 `k`。
  2. 按教材给出的位序，为校验位和数据位安排位置。
  3. 先假定各个校验位 `H` 为 `0`，再利用对应校验方程计算出 `P0、P1 ...`。
  4. 用求出的 `P` 值替代相应的 `H` 位，得到最终海明码。
- 译码和纠错思路：
  1. 读出数据位和海明校验位。
  2. 再次利用相同校验方程求综合校验结果。
  3. 若结果全为 `0`，说明未检测到错误。
  4. 若结果不全为 `0`，其二进制编码值就表示出错 bit 的位置编号。
- 教材给出的 8 位示例中：
  - 8 位数据需要 4 位检测位，总编码长度为 12 位。
  - 数据和校验位可以按 `D7 D6 D5 D4 H3 D3 D2 D1 H2 D0 H1 H0` 的混合形式存储。

## 易混点 / 易错点

- 容易把 `2^k >= n + k + 1` 写错，导致检测位数少算。
- 容易把“求出的 `P` 值”和“最终写入的 `H` 位”看成两套互不相关的量。
- 综合校验结果不为 `0` 时，要把它理解为“错误位置编号”，不是只判断“对/错”。
- 综合校验结果全为 `0` 表示未检测到错误，不是“第 0 位出错”。

## 常见关联场景

- 已知若干信息位，构造海明码。
- 已知读出的编码字，判断是否为合法海明码并定位 1 位错误。
