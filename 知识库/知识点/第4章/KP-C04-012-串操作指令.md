# 串操作指令

## 定义

串操作指令是对一串连续存放的字节或字进行同类操作的指令。教材在 `4.3.4` 中重点说明它们的默认寻址、地址自动修改规则，以及重复前缀在连续处理中的作用。

## 课程资料中的表述

- 在存储器中存放的一串字或字节，可以是二进制数，也可以是BCD码或ASCII码。它们存放在某一个连续的内存区中，若对它们的每个字或字节均做同样的操作，就称为串操作。把能完成这样功能的指令称为字符(或字)串操作指令或简称为串操作指令。
- 在串操作中，一般假定源串在数据段中(DS),而目的串在附加段中(ES)，用 SI做指针对源串寻址，用DI做指针对目的串寻址。在每做一次串操作后，若是对字节进行操作，则SI和 DI的值会自动加1或减1;若是对字进行操作,则 SI和DI的值就自动加2或减2,是加还是减由标志寄存器的方向标志位决定。若DF=0,则做加;否则，则做减。在操作前可用 STD指令使DF位置1;也可以用CLD指令使DF位清0。
- 该类指令是串传送指令，用于内存区之间字节串或字串的传送。
- 该类指令执行时，将把当前数据段中用SI指针指出的源串的一个字节或一个字传送到用 DI指针指向的附加段的目的地址中去。当DF=0且字节传送时，则传送后SI,DI加1,以使指针指向下一个地址;当DF=0且是字传送时，则 SI和 DI都加2。若DF=1,则 SI和DI都减1或减2。
- 可见，上述指令只做两件事 字节或字从源地址传送到目的地址;地址修改。做完这两件事，这条指令就执行完了。该类指令一般格式为
- MOVS OPRD1,OPRD2 ;OPRD2是源串,OPRD1是目的串
- MOVSB ;字节传送
- MOVSW ;字传送

## 结构 / 规则 / 公式

- 默认寻址关系：
  - 源串在数据段 `DS` 中，由 `SI` 指向
  - 目的串在附加段 `ES` 中，由 `DI` 指向
- 地址自动修改规则：
  - 字节操作后，`SI`、`DI` 自动加 `1` 或减 `1`
  - 字操作后，`SI`、`DI` 自动加 `2` 或减 `2`
- 地址增减方向由方向标志 `DF` 决定：
  - `DF = 0` 时，从低地址向高地址处理，通常用 `CLD` 清零
  - `DF = 1` 时，从高地址向低地址处理，通常用 `STD` 置位
- 教材给出的典型串操作包括：
  - `MOVSB / MOVSW`：串传送
  - `LODSB / LODSW`：把源串送入 `AL/AX`
  - `STOSB / STOSW`：把 `AL/AX` 送入目的串
- 串操作指令本身每执行一次只完成一次传送或处理；若要连续处理整串数据，需配合重复前缀 `REP`，并把重复次数放在 `CX` 中。

## 易混点 / 易错点

- `DS:SI` 与 `ES:DI` 的角色不能写反：前者通常是源串，后者通常是目的串。
- `MOVSB / MOVSW` 不是“自动把整串都搬完”，它们默认只完成一次字节或字传送；整串处理要靠 `REP`。
- `DF` 控制的是地址增减方向，不是是否重复执行。

## 常见关联场景

- 分析 `REP MOVSB`、`LODSB`、`STOSB` 执行后寄存器和内存的变化。
- 判断串操作中 `SI`、`DI`、`CX` 与 `DF` 的联动关系。
- 解释汇编程序中的内存块搬移、字符串遍历与批量处理。
