# 中断方式

## 定义

中断方式是输入/输出系统中一种非常重要的工作方式。教材在 `8.3` 开头强调，中断既能提高 CPU 的效率，又能对突发事件做出实时响应，因此在监测控制系统中应用极为广泛。

## 课程资料中的表述

- 教材把中断放在“计算机与外部世界交换信息”的大背景下讨论，指出掌握中断概念及其应用是学习计算机的人必须做到的。
- 采用中断的优点在于：CPU 平时可继续做自己的工作，而在外设或突发事件需要处理时，再暂停当前工作去响应，这样既提高效率，又能及时响应。
- 教材也明确提醒：中断实现起来比较麻烦，调试也比较困难，一旦出现故障需要认真仔细地排除。

## 结构 / 规则 / 公式

- 本节是总入口，后续展开包括：中断的基本概念、中断优先级控制、8086(88)的中断系统以及 8259 中断控制器。
- 教材在引入中断时，核心关注的是两点：提高 CPU 效率、满足实时响应。

## 易混点 / 易错点

- 中断方式的优势不是“让 CPU 一直处理外设”，而是“需要时才转去处理外设”。
- 教材同时强调了收益与代价，不能只记住优点而忽略实现和调试的复杂性。

## 常见关联场景

- 比较程序查询方式与中断方式。
- 作为理解中断一般过程和中断优先级控制的入口。
