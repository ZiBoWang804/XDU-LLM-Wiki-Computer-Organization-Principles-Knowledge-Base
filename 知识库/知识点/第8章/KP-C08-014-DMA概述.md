# DMA 概述

## 定义

DMA 概述主要回答两个问题：为什么在程序控制方式和中断方式之外还要引入 DMA，以及 DMA 想要解决的性能瓶颈到底是什么。

## 课程资料中的表述

- 教材先肯定程序控制和中断方式在慢速、中速外设场景下是适合的。
- 但当高速外设需要与内存快速交换数据时，这两种方式都必须执行程序，而 CPU 执行指令本身要花时间，因此数据传送率上不去。
- 教材举例指出：8088CPU 时钟接近 5MHz 时，用程序方法传送一个字节大约需要几十微秒，速率大致只有每秒几十 KB。
- 正是在这样的瓶颈下，才引出了 DMA。

## 结构 / 规则 / 公式

- 逻辑链条：
  - 慢/中速外设：查询或中断方式通常足够
  - 高速外设：CPU 按程序搬运数据成为瓶颈
  - 因此需要 DMA，把高速数据传送从 CPU 的逐条指令搬运中解放出来
- 教材在这一节给出的重点不是公式，而是性能对比背景。

## 易混点 / 易错点

- DMA 产生的原因不是“中断方式不能工作”，而是“中断方式虽然能工作，但速率不够高”。
- 这一节讨论的是“为什么要 DMA”，不是“DMA 的控制过程如何实现”。

## 常见关联场景

- 回答“为什么高速外设不用普通程序搬运数据”。
- 比较查询、中断与 DMA 在数据传送效率上的差异。
