# 通道方式

## 定义

通道方式是在一种称为 `I/O通道处理机` 或 `I/O通道控制器` 的控制部件控制下，实现计算机与外设间数据输入/输出的方法。它比 DMA 更进一步，把更多传送控制功能交给了专门部件。

## 课程资料中的表述

- 教材把通道方式看作一种更高层次的输入/输出控制方法。
- 其核心思想是：CPU 把数据传送控制功能交给 I/O 通道处理机，从而实现 CPU 与 I/O 控制工作的并行。
- 通道处理机一边接在系统总线上接收 CPU 命令，另一边通过自身总线连接设备控制器，再由设备控制器管理外设。
- 教材进一步把系统概括为三级管理：CPU 管理通道，通道管理设备控制器，设备控制器管理外设。

## 结构 / 规则 / 公式

- 通道方式的基本特征：
  - CPU 与通道并行工作
  - 通道一端接系统总线，另一端接设备控制器
  - 整个系统形成三级管理结构
- 教材在后续又把通道分为：
  - 选择通道
  - 数组多路通道
  - 字节多路通道
- 通道方式与 DMA 的差别，在于通道不仅搬运数据，而且承担了更完整的输入/输出控制职责。

## 易混点 / 易错点

- 通道方式不是“更快一点的 DMA”这么简单，它在控制层次上已经更接近专门 I/O 处理机。
- 三级管理结构里，通道并不直接代替 CPU，而是接受 CPU 管理。
- 教材在最后明确指出，通道作为历史上重要的输入/输出方式，今天更多是理解体系结构演化的知识点。

## 常见关联场景

- 比较中断、DMA、通道三种方式。
- 理解图8-50中的通道结构和三级管理关系。
- 为通道类型和发展页做总入口。
