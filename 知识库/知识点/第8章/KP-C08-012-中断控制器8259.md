# 中断控制器8259

## 定义

8259 是一种可编程中断控制器，用来解决多中断源的优先级控制问题。教材强调它不仅能对 8 个中断源进行控制，还能通过级联控制更多中断源，并向 CPU 提供中断向量码。

## 课程资料中的表述

- 教材把 8259 看作最常用的中断优先级控制器件，并把学习重点放在“如何把它真正用起来”。
- 围绕 8259，教材按“外部引线与内部结构 -> 工作方式 -> 控制字 -> 寻址 -> 初始化 -> 应用”这样的顺序展开。
- 在应用层面，8259 最关键的两个能力是：对多个中断源进行优先级管理，以及在中断响应时向 CPU 提供中断向量码。

## 结构 / 规则 / 公式

- 关键外部引线：
  - `D0~D7`：双向数据线
  - `WR`、`RD`：写/读控制
  - `CS`：片选
  - `A0`：内部寄存器选择
  - `INT`：向 CPU 输出中断请求
  - `INTA`：接收 CPU 的中断响应
  - `CAS0~CAS2`：级联控制线
  - `SP/EN`：主从或缓冲相关控制
  - `IR0~IR7`：8 个中断请求输入端
- 三个重要内部状态寄存器：
  - `IRR`：中断请求寄存器
  - `IMR`：中断屏蔽寄存器
  - `ISR`：中断服务寄存器
- 主要工作方式：
  - `8080/85` 模式与 `8086/88` 模式
  - 固定优先级、循环优先级、特殊全嵌套等优先级管理方式
  - 电平触发与边沿触发
  - 自动结束与一般结束等中断结束方式
- 控制字分两大类：
  - 初始化命令字 `ICW1~ICW4`
  - 操作命令字 `OCW1~OCW3`
- 教材明确指出：8259 外部只有一条地址线 `A0`，因此它只占两个接口地址。

## 易混点 / 易错点

- `IRR`、`IMR`、`ISR` 三者作用不同：请求、屏蔽、服务，不能混淆。
- `8086/88` 模式下，8259 在第二个 `INTA` 周期送出的是中断向量码，不是完整入口地址。
- 8259 的很多字共用地址，必须依靠 `A0`、控制字位含义和写入顺序来区分。
- 若中断服务程序结束前没有正确发出 `EOI`，8259 的服务状态不能正常复位。

## 常见关联场景

- 解释 8259 如何和 8086(88) 配合构成中断系统。
- 理解 `ICW/OCW`、`IRR/IMR/ISR` 在初始化和中断服务中的作用。
- 分析 8259 与系统总线连接、级联和中断结束命令。
