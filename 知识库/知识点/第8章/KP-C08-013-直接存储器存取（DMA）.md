# 直接存储器存取（DMA）

## 定义

DMA，即直接存储器存取，是为了实现高速外设与内存之间的高速率数据传送而提出的一种方法。它的核心思想是：数据传送时尽量不再让 CPU 像程序控制方式那样逐条指令搬运数据。

## 课程资料中的表述

- 教材把 DMA 放在“程序控制输入/输出”和“中断方式”之后，是为了说明当设备速率更高时，前两种方法为什么不够用。
- DMA 的目标不是让 CPU 完全消失，而是把具体的数据传送工作交给 DMA 控制器，从而显著提高传送率。
- 教材在本节中依次讨论 DMA 概述、常用方法和一般过程，并进一步引出通道方式。

## 结构 / 规则 / 公式

- 本专题的主要内容结构：
  - DMA 概述：为什么需要 DMA
  - 常用的方法：CPU 停止工作、周期挪用、CPU 与 DMA 交替分时工作
  - DMA 一般过程：DMAC 初始化、请求、响应、占总线、传送、归还总线
  - 通道方式：比 DMA 更进一步的 I/O 控制方式
- DMA 控制器 `DMAC` 在不同阶段扮演两种角色：
  - CPU 初始化它时，它作为总线上的接口存在
  - 获得总线控制权后，它作为系统总线控制器存在

## 易混点 / 易错点

- DMA 不是“CPU 完全不参与”，CPU 仍要完成初始化、响应总线请求和最后恢复总线控制。
- DMA 主要解决的是高速数据块传送问题，不是事件响应问题，这一点与中断方式不同。
- 通道方式与 DMA 有继承关系，但通道方式的控制能力更强、层次更高。

## 常见关联场景

- 比较程序控制 I/O、中断方式和 DMA。
- 解释为什么高速外设场景下必须引入 DMA。
- 作为阅读 DMAC、通道方式和外设总线控制的入口。
