# 常用的方法

## 定义

本节讨论的是计算机中常用的 DMA 实现方法。教材不是只讲一个“DMA标准过程”，而是先介绍几种让 DMA 能获得总线使用权的典型办法。

## 课程资料中的表述

- 教材给出三类常用方法：CPU 停止工作、周期挪用、CPU 与 DMA 交替分时工作。
- CPU 停止工作法依靠总线请求/总线响应或 HOLD/HLDA 信号，让 CPU 放弃系统总线控制权，把总线完全交给 DMA。
- 周期挪用又分两种：
  - 固定挪用周期：在取指周期中预留一段时间给 DMA
  - 周期延长：利用 `READY/WAIT` 等机制把机器周期拉长，并把延长出的时间用于 DMA
- CPU 与 DMA 交替分时工作则是人为把时间切成片，一片给 CPU 机器周期，一片给 DMA 传送。

## 结构 / 规则 / 公式

- 三种方法的特点：
  - CPU 停止工作：实现直接，但 CPU 会完全让出总线
  - 周期挪用：尽量利用 CPU 暂时不用总线的时间
  - 交替分时：实现较简单，但可能造成总线空闲
- 周期挪用的两种实现：
  - 图8-46：固定在取指周期中挪出时间
  - 图8-47：用 `READY` 延长周期，在延长段做 DMA 传送
- 教材评价：
  - 交替分时实现简单
  - 另外两种方式因为只在需要 DMA 时占用总线，更能提高总线利用效率

## 易混点 / 易错点

- “周期挪用”不是只有一种实现方式，教材明确分成固定挪用周期和周期延长两类。
- 交替分时工作并不一定更高效，它的简化是以可能出现总线闲置为代价的。
- 这一页说的是“怎么给 DMA 腾出总线时间”，不是 `DMAC` 内部寄存器和握手步骤本身。

## 常见关联场景

- 比较不同 DMA 方法的实现思路和代价。
- 解释图8-46、图8-47中“挪用周期”和“延长周期”的区别。
