# 8086(88)的中断系统

## 定义

8086(88) 具有功能很强的中断系统，可以处理 256 个不同方式的中断。每一个中断都赋予一个字节的中断向量码，CPU 根据向量码识别不同中断源。

## 课程资料中的表述

- 教材把 8086(88) 的中断源分为内部中断和外部中断两大类。
- 内部中断主要有五种：除法错中断、单步中断、断点中断、溢出中断、用户自定义的软件中断 `INTnnH`。
- 外部中断包括 `NMI` 和 `INTR`。其中 `NMI` 不受 `IF` 限制，请求输入为上升沿有效；`INTR` 受 `IF` 约束，高电平有效。
- `INTR` 与内部中断、`NMI` 的不同点在于：CPU 响应 `INTR` 时，要通过两个连续的中断响应总线周期发出两个 `INTA` 脉冲，并由外部中断系统把中断向量码送到数据总线上。
- 教材进一步说明：从 CPU 硬件查询中断源，到获得中断向量码、自动保护 `FLAG`、`CS`、`IP` 并转向中断服务程序，这一整套过程都由 CPU 硬件自动完成。

## 结构 / 规则 / 公式

- 内部中断向量码：
  - 除法错：`00H`
  - 单步：`01H`
  - 断点：`03H`
  - 溢出：`04H`
  - 软件中断：由 `INTnnH` 中的 `nnH` 给出
- 外部中断向量码来源：
  - `NMI`：由 CPU 内部硬件自动产生 `02H`
  - `INTR`：由外部中断系统在第二个 `INTA` 周期送到数据总线
- 教材根据图8-33总结的优先级顺序是：
  - 除单步外的内部中断优先级最高
  - 其次是 `NMI`
  - 再次是 `INTR`
  - 单步中断优先级最低
- 中断向量表：
  - 地址范围：`00000H ~ 003FFH`
  - 总大小：`1KB`
  - 每个中断向量码占 4 个地址
  - 偏移地址存放在 `向量码×4` 及其加 1 地址
  - 段地址存放在 `向量码×4+2` 及其加 3 地址

## 易混点 / 易错点

- 中断向量码和中断向量不是同一个概念。前者是类型码，后者是中断服务程序入口地址。
- `INTR` 的中断向量码不是 CPU 直接固定生成，而是 CPU 通过中断响应总线周期从数据总线上读入。
- 填写中断向量表时，每个中断源要占连续 4 个单元，其中前 2 个是偏移地址，后 2 个是段地址。
