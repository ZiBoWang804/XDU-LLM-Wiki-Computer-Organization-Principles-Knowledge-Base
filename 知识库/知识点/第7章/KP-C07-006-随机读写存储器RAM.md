# 随机读写存储器RAM

## 定义

随机读写存储器 RAM 是计算机主存中最常见的一类半导体存储器。教材在 `7.2.1` 中先从地址译码和单元电路说起，再把 RAM 分为 SRAM 和 DRAM 两大类。

## 课程资料中的表述

- 在计算机中，常用的随机读写存储器RAM分为两大类：一类是静态随机读写存储器SRAM；另一类是动态随机读写存储器DRAM。
- 一种RAM芯片，其外部有地址引线、数据引线和控制信号引线。
- 当芯片容量较小时可采用一维译码；容量较大时多采用二维译码。

## 结构 / 规则 / 公式

- 基本外部结构：
  - 地址线：决定可寻址单元数。若芯片有 `n` 条地址线，则可表示 `2^n` 个地址。
  - 数据线：决定每个单元一次读写的数据位数。
  - 控制线：控制读、写、片选等操作。
- 地址译码方式：
  1. 一维译码
     - 容量较小的芯片常用，一个译码器直接选中存储单元。
  2. 二维译码
     - 容量较大的芯片常用，分别用行译码器和列译码器选择单元。
- RAM 的两大类别：
  - SRAM
    - 数据在通电状态下能稳定保持，不需要刷新。
  - DRAM
    - 信息存放在电容上，需要定时刷新。
- 共性：
  - RAM 是可读可写的。
  - 初始加电时状态是随机的。
  - 掉电后不能保持原有数据。

## 易混点 / 易错点

- 不要把“RAM”只理解为 DRAM；教材明确把 SRAM 和 DRAM 都归在 RAM 下。
- 不要把“随机访问”误解为“数据随机产生”；这里指任一地址都能按同等方式访问。
- 仅凭地址线条数算出单元数后，还要结合数据线判断总容量。

## 常见关联场景

- 由地址线条数和数据线条数判断 RAM 芯片容量。
- 作为比较 SRAM、DRAM、ROM 的总入口知识点。
