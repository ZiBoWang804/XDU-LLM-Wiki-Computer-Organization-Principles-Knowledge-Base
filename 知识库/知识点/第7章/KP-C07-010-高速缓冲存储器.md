# 高速缓冲存储器

## 定义

高速缓冲存储器是在 CPU 和主存之间设置的一种容量较小而速度高的存储器。教材把它放在 `7.3` 小节，用来说明如何缓和“CPU 速度提高很快而存储器速度增加相对较慢，同时高速存储器价格很贵”这一矛盾。

## 课程资料中的表述

- 教材先指出矛盾：若计算机内存全部采用低价的慢速存储器，则 CPU 的高速度无法发挥；若全部采用高价的快速存储器，则价格又使人无法接受。
- 为了解决这一矛盾，就在主存前面设置 cache。教材以 PC 为例说明，从 80386CPU 之后，人们采用高速缓冲存储器来解决这个问题，使计算机既具有较低价格，又能发挥出 CPU 的高速度。

## 结构 / 规则 / 公式

- 从层次位置看，高速缓冲存储器位于 CPU 和主存之间，离 CPU 更近。
- 从作用看，它不是用来代替主存，而是把当前正在执行的程序和正在访问的数据放在速度更高的位置，以缩短访存时间。
- 从系统目标看，教材强调的是“两头兼顾”：访存速度尽量接近 CPU，而成本又不至于完全按高速存储器来计算。

## 易混点 / 易错点

- cache 不是一个独立替代主存的大容量存储器，而是主存前面的高速缓冲层。
- 教材讨论 cache 时，核心出发点是“速度与价格的矛盾”，不能只把它理解成单纯“加一个更快的存储器”。

## 常见关联场景

- 说明为什么计算机要设置 cache。
- 说明 cache 在存储系统层次结构中的位置和作用。
