# 内部存储器(主存储器）

## 定义

内部存储器，也称主存储器或内存，是计算机中用于存放当前正在执行或刚执行的程序和数据的存储器。教材在 `7.2` 中把它作为后续 `RAM / ROM / DRAM / 其他存储器` 的总入口来说明。

## 课程资料中的表述

- 在本节中将描述与计算机内存有关的问题，包括主存的构成、高速缓存及虚拟存储器等。

## 结构 / 规则 / 公式

- 教材把主存储器放在整个存储系统层次中理解：
  - 主存用于存放当前程序和数据
  - cache 用于缓解主存速度太慢的问题
  - 外存用于存放当前暂不使用的大量信息

- 现代计算机的主存储器本质上是半导体存储器。

- 从主存工作方式看，教材强调了几个总特征：
  - 按地址访问
  - 通过地址线、数据线和控制线与 CPU / 总线连接
  - 当前主存的具体芯片类型主要包括 `RAM`、`ROM` 及其派生类型

- 主存相关的基础性能指标包括：
  - 存储容量
  - 存取时间
  - 存取周期
  - 带宽
  - 可靠性
  - 功耗与价格

- 这些指标直接决定后续容量扩展、总线扩展以及存储器类型比较题中的分析方式。

## 易混点 / 易错点

- “主存储器”和“cache”不是一回事；cache 速度更高、容量更小，作用是缓冲主存。
- 主存是“当前工作区”，外存是“大容量长期存放区”，两者用途不同。
- 题目里说“主存扩展”“内存容量”时，默认讨论的是内部存储器芯片及其组织，不是外存设备。

## 常见关联场景

- 作为 `RAM / ROM / DRAM` 分类比较的总入口。
- 作为主存容量扩展、地址译码和总线扩展题的背景知识。
- 解释为什么存储系统设计必须在速度、容量、价格之间折中。
