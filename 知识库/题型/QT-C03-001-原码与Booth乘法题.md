# QT-C03-001 原码与Booth乘法题

## 题型定义
围绕原码一位乘、原码两位乘和 Booth 补码乘法展开的步骤计算题。

## 常见问法
- 用原码一位乘法 / 两位乘法求乘积，并写出部分积过程。
- 用 Booth 法求补码乘积，并写出每轮加减与移位。

## 主考点
- 原码一位乘、原码两位乘的乘数位分组规则。
- Booth 判别位与补码加减规则。
- `[-X]补`、必要时的 `[2X]补` 等辅助量是否先准备到位。
- 乘积符号、小数点位置和最终机器数的回写。

## 常用解题骨架
1. 先写出操作数 `X`、`Y` 的编码形式、位宽、小数点位置和符号处理方式。
2. 若是原码一位乘 / 两位乘，先说明按哪几位一组考察乘数，并据此给出部分积。
3. 若是 Booth 法，先写 `[-X]补`，再根据 `Y_0` 与 `Y_{-1}` 或课件中的相邻判别位规则决定 `+X / -X / +0`。
4. 全过程按轮次写出每一步操作和右移后的新状态，不要只给最后的乘积。
5. 最后统一恢复小数点和符号，写出最终积。

## 期末高频证据

- `2020_final` 明确点名“浮点数布斯乘法”。
- `2022_final` 和 `计组2022` 把 Booth 补码一位乘法列为完整大题。
- `运算方法3/4` 课件与 `2026春计组1` 题单反复强化了 Booth 的表格式步骤。
- `部分作业题-计算机组成与结构1-5答案` 给出了较完整的表格式答案口径，说明这类题不是只考原理，更考步骤呈现。

## 建议作答模板

1. 先写出 `X`、`Y` 的编码、符号和小数点位置。
2. 原码题先写清是一位乘还是两位乘；Booth 题先写出 `[-X]补`，必要时写出 `[2X]补`。
3. 全过程尽量按表格写：
   - 原码两位乘可贴近课件列为 `符号 / D / Y / Y_1 / Y_0 / 操作说明`
   - Booth 一位乘可贴近课件列为 `符号 / D / Y / Y_0 / Y_{-1} / 操作说明`
4. 若一轮中既有“加 / 减”又有“右移”，建议拆成两行，先写本轮操作，再写右移后的状态。
5. 最后单独写出最终乘积，并恢复小数点与符号。

## 易错点
- 原码题把符号位也直接参与数值部分乘法。
- Booth 法中相邻判别位或 `Y_0 / Y_{-1}` 的判别写错。
- 漏写 `[-X]补`，导致后续每一轮操作没有依据。
- 写了表格，但没有把每轮右移后的新状态落下来。
- 乘法过程算对了，却忘记最后恢复小数点或没有说明结果符号。
