# QT-C01-002 绪论基础概念辨析题

## 题型定义

围绕冯·诺依曼机硬件组成与“存储程序”思想、Flynn 分类法（SISD / SIMD / MISD / MIMD）、摩尔定律、机器语言执行层级等基础概念展开的选择 / 判断 / 简答题。

## 常见问法

- 简述冯·诺依曼计算机体系架构 / 硬件的基本组成及其主要特点。
- 冯诺依曼计算机硬件能直接执行的只有哪种语言。
- SISD / SIMD / MIMD 分类辨析，判断某种并行结构属于哪一类。
- 机器语言、汇编语言与高级语言的执行层级判断。
- 摩尔定律的含义辨析。

## 主考点

- 冯·诺依曼机五大部件（运算器、控制器、存储器、输入设备、输出设备）和"存储程序"核心思想。
- Flynn 分类的四个类别及其含义：按指令流和数据流的并行度划分。
- 基础概念边界是否清楚，术语之间是否混淆。
- “硬件能直接执行什么语言”“摩尔定律描述的到底是什么”这类概念边界是否清楚。

## 常用解题骨架

1. 先判断题目考查的是"组成"、"分类"还是"术语定义"，锁定到具体知识点。
2. 若考冯·诺依曼机组成，回到五大部件 + "存储程序"思想的教材标准表述。
3. 若考 Flynn 分类，先写指令流 / 数据流的两维划分，再把 SISD / SIMD / MISD / MIMD 逐一写出含义和典型例子。
4. 若考语言执行层级，记住“机器语言是硬件能直接执行的唯一语言”，汇编语言需经汇编程序翻译，高级语言需经编译程序翻译。
5. 若考摩尔定律，要回到“集成电路上晶体管数量随时间增长”的原始表述，不要泛化成一切性能结论。
6. 答题时使用教材术语，不用口语替代。

## 建议作答模板

1. **若考"组成"**，固定写五大部件：运算器、控制器、存储器、输入设备、输出设备。并补充"以运算器为中心"或"以存储器为中心"的教材说法。
2. **若考"特点"**，固定写教材口径：存储程序、指令和数据均以二进制表示、指令和数据存储在同一存储器中、指令由操作码和地址码组成、自动顺序取出指令并执行。
3. **若考 Flynn 分类**，先写分类依据（指令流 / 数据流的并行度），再列四类：`SISD`（单指令单数据流）、`SIMD`（单指令多数据流）、`MISD`（多指令单数据流）、`MIMD`（多指令多数据流），并各举一个典型例子。
4. **若考语言层级**，明确写"硬件能直接执行的只有机器语言"。汇编语言需经汇编程序翻译，高级语言需经编译 / 解释程序翻译。
5. **若考摩尔定律**，明确写它描述的是“集成电路上可容纳的晶体管数目大约每隔 18 个月翻一番”这一经验规律，不要直接替换成“性能翻倍”。
6. 不要用口语化表达替代教材术语，如不要把"存储程序"说成"把程序放进去"。

## 易错点

- 把"能直接执行"误认为汇编语言也可以。汇编语言和高级语言都必须翻译后才能执行。
- 把 Flynn 分类中 MISD 与 SIMD 的含义混淆。MISD 实际上几乎不存在实际系统，考试中仅作为分类辨析出现。
- 把冯·诺依曼机的"以运算器为中心"和现代计算机的"以存储器为中心"混为一谈。
- 把摩尔定律的适用范围从"集成电路上晶体管数量"泛化到"计算机性能"。
