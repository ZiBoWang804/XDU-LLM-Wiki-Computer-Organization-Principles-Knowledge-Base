# QT-C01-001 性能计算与Amdahl综合题

## 题型定义

围绕 `CPI / MIPS / 执行时间 / 加速比 / Amdahl 定律` 展开的综合计算题。

## 常见问法

- 已知主频、指令条数和平均周期数，求有效 CPI、MIPS、执行时间。
- 已知某些部件可改进比例和部件加速比，求系统总加速比或剩余部分占比。
- 已知主频和平均 CPI，求时钟周期和 MIPS。

## 主考点

- 性能指标之间的换算关系。
- `平均CPI = \sum (CPI_i \times IC_i / IC)` 的使用。
- `执行时间 = IC × CPI × 时钟周期 = IC × CPI / 主频` 的换算。
- Amdahl 定律中“可改进部分占比”和“部件加速比”的组合。

## 常用解题骨架

1. 先判断题目要求的是 `平均CPI / 时钟周期 / MIPS / 程序执行时间 / 总加速比` 中的哪一个。
2. 若给的是各类指令条数和每类 `CPI`，先求平均 `CPI`，再继续算 `MIPS` 或执行时间。
3. 若给的是主频，先写 `时钟周期 = 1 / 主频`，不要把 `MHz` 直接代成秒。
4. 若问 `MIPS`，优先使用 `MIPS = 主频(MHz) / CPI` 或 `MIPS = 指令条数 / (执行时间 × 10^6)`。
5. 若出现 `Amdahl`，先从题意中抽出 `f_e` 和 `r_e`，再写
   `S_p = 1 / ((1 - f_e) + f_e / r_e)`。
6. 若题目是多个部件同时改进，再换成多部件公式，不要继续套单部件形式。

## 期末高频证据

- `课件-绪论2-Spring-2025` 连续给出平均 `CPI`、`MIPS`、执行时间和 `Amdahl` 例题，是绪论部分最稳定的计算入口。
- `笔记-计算机组织与体系结构课程复习要点` 直接把 `Amdahl 定律应用` 列为应会内容。
- 拆分后的 `卷2-试题` 仍保留了典型 `Amdahl` 小题：计算部分提速 `10` 倍、原系统计算占 `40%`、I/O 占 `60%`，要求求总加速比。
- 这说明第 1 章虽然不像后续章节那样全是大题，但 `性能换算 + Amdahl` 是卷面稳定保留的计算题型。

## 建议作答模板

1. `已知：` 列出主频、指令条数、各类指令 `CPI`、可改进比例、部件加速比等量。
2. `先求基础量：` 如平均 `CPI`、时钟周期。
3. `再求目标量：` 如 `MIPS`、执行时间、总加速比。
4. 若是 `Amdahl` 题，必须显式写出 `f_e` 和 `r_e` 分别对应题干中的哪一部分。
5. 最后单独写 `因此：` 给出数值结果和单位，不要把过程和结论混成一行。

## 易错点

- 把主频和时钟周期混用。
- 把平均 `CPI` 误写成若干 `CPI` 的简单算术平均。
- 把 `MIPS`、`IPC`、`CPI` 三者混用，漏掉互为倒数的条件前提。
- 把“部件加速比”误写成“系统加速比”。
- 多部件同时改进时仍使用单部件 `Amdahl` 公式。
