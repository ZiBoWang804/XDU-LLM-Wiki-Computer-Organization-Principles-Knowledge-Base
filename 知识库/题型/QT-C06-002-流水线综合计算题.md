# QT-C06-002 流水线综合计算题

## 题型定义
围绕带反馈回路或循环结构的流水线，要求画出时空图并计算吞吐率、效率和加速比的综合计算题。与 QT-C06-001（通用流水线性能分析）的区别在于：本题型的流水线具有结果回送输入端的循环结构，需要展开多轮迭代才能得到完整时空图。

## 常见问法
- 已知流水线各段延迟和功能段划分，运算结果可回送输入端，画出指定运算的时空图，并计算吞吐率、效率和加速比。
- 浮点乘法流水线框图如图所示，现有浮点数 A、B、C、D，试画出 R = A·B·C·D 运算的时空图。

## 主考点
- 流水线各段时间划分与流水线周期确定。
- 带反馈回路的流水线时空图展开。
- 吞吐率、效率、加速比的计算。

## 常用解题骨架
1. 先确定流水段数和各段延迟，取最长段作为流水线周期。
2. 识别运算中是否有回送结构（结果直接加到输入端），若有则需展开多轮迭代。
3. 按时间步逐段填入各功能段的占用情况，画出完整时空图。
4. 从时空图中统计总时间、有效计算时间、段数，代入吞吐率 = 任务数/总时间、加速比 = 串行时间/流水时间、效率 = 有效占用/总占用。

## 期末高频证据

- 这不是“题量最多”的题型，但它是第 6 章最容易把通用流水线题做错的一个变体。
- 关键不在公式，而在于先识别反馈回路 / 回送结构，再决定时空图怎么展开。
- 六套混合卷中的卷 `2 / 4` 说明：期末卷并不只考理想线性流水线，还会考静态双功能流水线、带停顿或不等长段的综合计算。
- `教材第6章例6-1` 直接给出“浮点乘法流水线 + 结果回送输入端”的经典题型，是本页最核心的教材母题。
- `卷2-试题` 和 `卷4-试题` 说明：这类题不只是背吞吐率公式，而是要先识别反馈回路、静态双功能路径或综合运算结构，再决定时空图如何展开。
- 这类题常以“画时空图 + 算吞吐率 / 加速比 / 效率”的大题形式出现，因此过程展开比最后公式更容易丢分。

## 建议作答模板

1. 先写流水段数、各段延迟，取最长段为流水线周期。
2. 识别反馈回路：判断运算是否需要把前一轮结果回送到下一轮输入端。
3. 判断需要展开的迭代轮数，每轮按流水段逐拍填入，不要只画第一轮。
4. 时空图上标注：装入期、每轮占用区间、反馈回送空拍（若有）、排空期。
5. 由时空图统计：总时间 $T$、任务数 $n$、段数 $k$、各段时长 $t_i$。
6. 分别计算：
   - 吞吐率 $TP = n / T$
   - 加速比 $S = T_{串行} / T$
   - 效率 $\eta = (n \times k \times t_i) / (k \times T)$ 或由时空图直接统计有效占用格 / 总占用格
7. 若题目给的是不等间隔输入（如每隔 $3\Delta t$ 输入一个），必须从时空图重新数总时间，不能直接套理想公式。
8. 若涉及静态双功能流水线（如乘法 / 加法交替），先分别确认各功能路径占用段和延迟，再合并画时空图。

## 易错点
- 未识别回送结构，直接按单次流水线计算。
- 展开多轮迭代时漏算回送延迟。
- 把各段时间不等的流水线周期取错（应取最长段）。
