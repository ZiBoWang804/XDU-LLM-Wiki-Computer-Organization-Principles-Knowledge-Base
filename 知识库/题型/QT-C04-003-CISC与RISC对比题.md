# QT-C04-003 CISC与RISC对比题

## 题型定义

围绕 CISC（Complex Instruction Set Computer）和 RISC（Reduced Instruction Set Computer）体系结构特征辨析、优缺点比较、选择题判断的题型。核心考点来自"20-80 规律"和 RISC 的五项结构特征。

## 常见问法

- 判断哪一项属于 RISC 或 CISC 的特征（选择题，往往有一个干扰项）。
- 简述 RISC 架构的主要特点。
- 比较两类体系在指令复杂度、寻址方式、寄存器数量、控制逻辑、流水线支持上的差异。
- 说明 CISC 指令系统存在的问题，以及 RISC 如何解决这些问题。

## 主考点

- **20-80 规律**：在 CISC 中，大约 20% 的指令占据了 80% 的处理机执行时间。这是 RISC 设计思想的出发点。
- **CISC 的典型问题**：指令条数多、格式复杂、长度不固定；寻址方式多；大多采用微程序控制；复杂指令执行周期长。
- **RISC 的五项结构特征**：
  1. 指令系统简单：指令条数少、格式少、长度固定、功能简单。
  2. 寻址方式少。
  3. 通用寄存器数量多（通常 32 个以上）。
  4. 采用硬布线控制逻辑（不用或少用微程序控制器）。
  5. 支持流水线高效执行。
- **哪些说法是"常见对比结论"，哪些是干扰项**：例如"RISC 寻址方式很多"是典型的错误干扰项（RISC 寻址方式少）；"CISC 执行一条指令用的时钟周期很多"是正确的。

## 常用解题骨架

1. **先确认题干问的是 CISC 还是 RISC 的特征**。
2. **按五条线逐项比较**：
   - 指令复杂度（条数、格式、长度）
   - 寻址方式数量
   - 通用寄存器数量
   - 控制逻辑实现方式（硬布线 vs 微程序）
   - 流水线友好性（单周期 vs 多周期）
3. **判断题干陈述是否与教材结论一致**：逐一对照，找出错误项。
4. **简答题需完整列举**：不能只说"快/慢"，要写具体结构性差异。

## 建议作答模板

1. **选择题——逐项排除法**：
   - 先在草稿纸列出 RISC 五项特征和 CISC 对应特征。
   - 逐项对照选项：
     - "指令类型很多" → CISC ✓
     - "内部寄存器很多" → RISC ✓
     - "寻址方式很多" → CISC（不是 RISC！）
     - "执行一条指令用的时钟周期很多" → CISC ✓
   - 找出与列对不上的选项，就是答案。

2. **简答题——完整列举 RISC 特点**：
   ```
   RISC（精简指令集计算机）的主要特点：
   1. 指令系统简单：指令条数少、格式少、长度固定、功能简单。
   2. 寻址方式少，减少指令译码复杂度。
   3. 通用寄存器数量多（通常 32 个以上），减少访存次数。
   4. 采用硬布线控制逻辑（不用或少用微程序控制器），加快单条指令执行速度。
   5. 面向流水线设计：指令长度固定、格式规整，有利于流水线高效执行。
   ```

3. **对比题——按维度列表**：
   ```
   | 对比维度       | CISC                          | RISC                          |
   |---------------|-------------------------------|-------------------------------|
   | 指令条数       | 多                            | 少                            |
   | 指令格式       | 多种，长度不固定               | 少种，长度固定                |
   | 寻址方式       | 多                            | 少                            |
   | 通用寄存器     | 少                            | 多（≥32）                     |
   | 控制逻辑       | 微程序控制                     | 硬布线控制                    |
   | 流水线支持     | 因指令周期不等而效率低          | 指令周期均等，流水线效率高     |
   | 设计出发点     | 用一条指令代替一串指令          | 20-80 规律：只保留高频简单指令 |
   ```

## 易错点

- **误把"寻址方式很多"当成 RISC 特征**：这是最经典的干扰项。寻址方式多是 CISC 的特征，RISC 的寻址方式少。`计组2022` 选择题第 7 题 C 选项正是考这个陷阱。
- **只记"快/慢"，不记具体结构性区别**：RISC 不是"所有指令都更快"，而是通过简化指令系统、增加寄存器、硬布线控制和流水线来提高整体效率。
- **把 RISC 的"指令条数少"和"功能弱"混为一谈**：RISC 指令条数少但通过编译器组合可以实现复杂功能，功能并不弱。
- **忽略 20-80 规律**：这是 RISC 设计的理论基础。如果简答题只罗列特征而不提理论背景，会丢掉"为什么"的分。
- **把"采用微程序控制"说成 RISC 特征**：RISC 采用硬布线控制，CISC 才采用微程序控制。
- **混淆 RISC 和 CISC 的寄存器数量方向**：RISC 寄存器多，CISC 寄存器少（因为 CISC 用复杂指令操作内存，减少对寄存器数量的需求）。
