# QT-C08-004 8253定时方波与波形题

## 题型定义

围绕 `8253` 的工作方式、计数链路、级联连接、周期为 `1s` 的方波设计，以及 `OUT` 波形和脉宽标注的题型。

## 常见问法

- 外部时钟为 `1MHz` 或 `2MHz` 时，如何只用 `8253` 产生指定周期的对称方波。
- 已知 `8253` 的工作方式和计数初值，画出 `OUT` 波形并标出周期 / 脉宽。
- 给出 `8253` 的接口地址、控制字和初始化程序，说明设计思路。

## 主考点

- `8253` 的 3 个计数器与 `CLK / GATE / OUT` 信号作用。
- 方式 `3` 的方波输出规律。
- 两级级联时总计数值、时钟周期与输出周期的关系。
- 波形题中 `OUT2` 周期和 `OUT1` 脉宽的分步计算。

## 常用解题骨架

1. 先写输入时钟周期。
2. 再判断一个计数器是否足够；若不足，明确写“两个计数器级联”。
3. 列出各级计数值与总计数链。
4. 若题目给方式 `3`，必须说明偶数/奇数计数值下高低电平持续区间。
5. 波形题最后必须把周期或脉宽直接标到图旁。

  - 给定时钟频率，设计 `1s` 周期方波
  - 已给初值与连接关系，画 `OUT` 波形并标宽度

## 建议作答模板

1. 先写：`Tclk = 1/f`。
2. 再求目标总计数值。
3. 若单个计数器不够，明确写级联链路：`OUT0 -> CLK1` 一类。
4. 再写各计数器的工作方式和计数值。
5. 波形题按“先 OUT2、后 OUT1”分段写。
6. 最后把周期、脉宽和极性标清。

## 易错点

- 直接把 `1s` 除以 `1MHz`，算出总计数值后忘记检查 16 位计数器能否单独实现。
- 只写计数值，不写 `CLK / GATE / OUT` 的连接关系。
- 画波形不标周期和脉宽。
- 把方式 `3` 写成“任意占空比波形”，忽略其对称方波特性。
