# QT-C05-002 微操作流程与控制信号题

## 题型定义
围绕取指、取数、执行三个阶段写微操作流程，或写对应控制信号的题型。

## 常见问法
- 写出某条指令的取指流程和执行流程。
- 用“数据通路描述 / 控制信号描述 / 混合描述”给出微流程。

## 主考点
- 指令执行分阶段展开。
- 访存、寄存器传送、ALU 运算和控制信号之间的对应关系。

## 常用解题骨架
1. 先写取指通用流程。
2. 再根据寻址方式展开有效地址与取操作数过程。
3. 最后写执行阶段的运算和结果回写。

## 建议作答模板

1. 先写取指公共流程。
2. 再根据寻址方式写“形成有效地址 / 取操作数”。
3. 再写执行阶段。
4. 若题目要求控制信号，可在每步后括号补控制信号。
5. 若课程课件已采用英文阶段名，优先按 `Fetch / Fetch Operands / Execute / Store` 分段书写。
6. 若题目或老师更偏好时序节拍写法，再把各段步骤整理为 `T1/T2/T3/...`。

## 易错点
- 只写执行阶段，不补取指阶段。
- 忽略寻址方式对取操作数流程的影响。
- 把“数据通路描述”和“控制信号描述”混成一句话，导致步骤层次不清。
