# QT-C05-003 控制器实现方式比较题

## 题型定义
围绕组合逻辑控制器与微程序控制器的实现方式、结构特点、优缺点、适用场景，以及相关判断说法展开的比较题。

## 常见问法
- 判断某个特征属于组合逻辑控制器还是微程序控制器。
- 比较两种控制器在速度、灵活性、设计复杂度、修改代价上的差异。
- 解释“字段译码法”“控制存储器”“微程序”“硬连线”等关键词分别对应什么。
- 结合判断题说明“控制器用硬件实现”“控制器大多采用微程序控制器来实现”等说法为何成立。

## 主考点
- 组合逻辑控制器通过组合逻辑电路直接产生控制信号，强调硬件实现、速度较快。
- 微程序控制器把微命令编成微指令存入控制存储器，通过执行微程序产生控制信号，强调规整、灵活、便于修改。
- 题目中的特征描述能否准确归类到“控制信号形成方式”而不是别的层次。
- “字段译码法”属于微指令控制字段的编码方法，不能误当成“控制器实现方式”本身。

## 常用解题骨架
1. 先写清两类控制器的控制信号来源：一个是组合逻辑直接形成，一个是控制存储器中的微程序逐条给出。
2. 若是比较题，再按“实现方式 -> 速度 -> 灵活性 -> 设计复杂度 -> 修改代价 -> 适用场景”依次对比。
3. 若是判断题，先抓关键词：`控制存储器 / 微程序 / 修改方便 / 规整` 多半指微程序控制器；`硬连线 / 组合逻辑 / 速度快` 多半指组合逻辑控制器。
4. 若题目同时提到“字段译码法”“垂直型微指令”等术语，必须单独指出它们属于微程序控制器内部的控制字段设计问题。

## 期末高频证据

- `笔记-计组上_复习笔记` 直接把“微程序控制器与组合逻辑控制器比较”单列成复习条目。
- `习题课-指令系统-Spring-2021` 与 `计算机组成与结构1-5答案` 中都出现了“控制器大多采用微程序控制器来实现”“控制器用硬件实现，采用组合逻辑控制器”等判断口径。
- 这类题通常和“字段译码法 / 微指令格式 / 控存容量”同章出现，常作为判断题、简答题或填空补点题。

## 建议作答模板

1. 先用两句话写定义：
   - `组合逻辑控制器由组合逻辑电路直接形成控制信号。`
   - `微程序控制器把微命令写成微指令存入控制存储器，通过执行微程序产生控制信号。`
2. 再按固定维度比较：`实现方式 / 速度 / 灵活性 / 设计复杂度 / 修改代价 / 适用场景`。
3. 若题目是判断题，必须把“为什么”补出来，不要只写“对 / 错”。
4. 若题目同时问到字段译码法，应单独补一句：`字段译码法是微指令控制字段的编码方法，不是控制器实现方式的分类名。`

## 易错点
- 只记住“微程序更灵活”，却忘了组合逻辑通常速度更高。
- 把“字段译码法”误当成组合逻辑控制器独有特征，或误当成“第三种控制器”。
- 认为“控制器用硬件实现”只对应微程序控制器，忽略组合逻辑控制器本来就是硬连线实现。
- 比较时只写优点，不写代价，导致答案没有形成成对对照。
