# QT-C07-004 SRAM与DRAM工作原理题

## 题型定义

围绕 SRAM 与 DRAM 的工作原理、存储结构、刷新机制、地址译码方式以及速度 / 密度 / 功耗 / 成本等特性差异展开的原理说明题与比较题。

## 常见问法

- 解释 SRAM 和 DRAM 的工作原理及优缺点。
- 比较 SRAM 与 DRAM 在存储结构、是否需要刷新、读写速度、集成度和成本上的差异。
- 说明 DRAM 的几种刷新方式（集中刷新、分散刷新、异步刷新）及其对性能的影响。
- 说明一维地址译码和二维地址译码的设计动机与各自特点。
- 说明字线和位线在存储器中的作用。
- 解释 RAS / CAS 地址复用的含义和工作方式。

## 主考点

- SRAM 采用六管（6T）交叉耦合触发器结构，不需要刷新，读写速度快，但集成度低、成本高。
- DRAM 采用单管加电容（1T1C）结构，需要定期刷新（典型周期约 64ms），集成度高、成本低，但速度较慢。
- DRAM 刷新方式：集中刷新、分散刷新、异步刷新，以及各自对 CPU 访存时间的影响。
- 地址译码方式：一维译码（线性译码）连线多但速度快，二维译码（行列译码）连线少但需要分两次送地址。
- DRAM 的 RAS（行地址选通）与 CAS（列地址选通）地址复用机制。
- SRAM vs DRAM 在速度、密度、功耗、成本和是否需要刷新等维度上的系统性对比。

## 常用解题骨架

1. **先判断题目是"原理辨析"还是"特性对比"**。
2. 若是原理辨析，分别写 SRAM 和 DRAM 的存储单元结构：SRAM 用触发器存储，DRAM 用电容存储。
3. 若是特性对比，按"存储结构 / 是否需要刷新 / 读写速度 / 集成度 / 功耗 / 成本 / 典型应用"逐项对照。
4. 若题目涉及刷新，说明三种刷新方式的含义和区别：集中刷新在一段集中时间内逐行刷新，分散刷新将刷新均匀分散到各读写周期，异步刷新按最大刷新间隔平均分配。
5. 若题目涉及地址译码，说明一维译码 $n$ 位地址需要 $2^n$ 条字线，二维译码将地址分为行地址和列地址，各需 $2^{n/2}$ 条线，总连线数从 $2^n$ 降到 $2 \times 2^{n/2}$。
6. 最后以表格或成对对照形式给出结论。

## 建议作答模板

1. **先写结构差异**：SRAM 用六管触发器存储一位，DRAM 用电容加一个晶体管存储一位。
2. **再写是否需要刷新**：SRAM 不需要刷新，DRAM 需要定期刷新。
3. **接着对比关键指标**：
   ```
   | 指标     | SRAM       | DRAM        |
   |----------|------------|-------------|
   | 速度     | 快         | 较慢        |
   | 集成度   | 低         | 高          |
   | 功耗     | 较高       | 较低        |
   | 成本     | 高         | 低          |
   | 刷新     | 不需要     | 需要        |
   | 典型应用 | Cache      | 主存        |
   ```
4. **若涉及刷新方式**，补充三种刷新方式的定义和区别。
5. **若涉及地址译码**，补充一维译码和二维译码的连线数对比，以及 RAS / CAS 复用的含义。

## 易错点

- 把 SRAM 说成"不需要电源"或把 DRAM 说成"掉电不丢"。两者都是易失性存储器，掉电后数据均丢失。
- 把 DRAM 刷新理解为"CPU 每次读写时顺便刷新"——刷新是 DRAM 控制器主动完成的周期性操作。
- 混淆"速度快"与"集成度高"——SRAM 速度快但集成度低，DRAM 速度较慢但集成度高，二者恰好相反。
- 在二维译码中忘记行地址和列地址是分时复用同一批引脚（RAS / CAS 机制）。
- 把 SRAM vs DRAM 比较题答成容量扩展题——本题型聚焦原理和特性差异，不考片数计算和译码连线。
