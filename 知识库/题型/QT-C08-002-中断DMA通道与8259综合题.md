# QT-C08-002 中断DMA通道与8259综合题

## 题型定义
围绕中断、DMA、通道方式的比较，以及 8259 工作方式、初始化和系统角色理解的综合题型。

## 常见问法
- 比较程序控制 I/O、中断、DMA、通道方式的差异。
- 说明 DMA 的实现方法和一般过程。
- 说明 8259 的工作方式、优先级、初始化或在 8086 系统中的作用。

## 主考点
- 几种 I/O 控制方式的适用场景和差异。
- DMA 与 CPU / DMAC 的总线控制权交替。
- 8259 的中断管理能力与初始化逻辑。

## 常用解题骨架
1. 比较题先按“CPU 参与程度 / 传输效率 / 适用场景”三列展开。
2. DMA 题先写方法，再写一般过程。
3. 8259 题先写器件作用，再写工作方式或初始化顺序。

## 建议作答模板

1. 比较题（程序控制 I/O / 中断 / DMA / 通道）固定按三列展开：
   - CPU 参与程度
   - 数据传输效率
   - 典型适用场景
2. DMA 题先写三种实现方法（CPU 停止、周期挪取、交替访问），再写一般过程：
   - 预处理（设置地址、计数、方向）
   - 数据传送（DMAC 接管总线、逐块传输）
   - 后处理（DMAC 发中断通知 CPU 结束）
3. 8259 题先写器件作用（管理多级外部可屏蔽中断），再写：
   - 工作方式（优先级方式、屏蔽方式、触发方式、结束方式）
   - 初始化顺序：`ICW1 -> ICW2 -> (ICW3) -> (ICW4) -> OCW1`
   - 说明 `ICW3 / ICW4` 是否需要写入取决于 `ICW1` 的 `SNGL` 和 `IC4` 位
4. 若题目涉及 8086 外部中断，先区分 NMI / INTR，再说明 8259 如何管理 INTR。
