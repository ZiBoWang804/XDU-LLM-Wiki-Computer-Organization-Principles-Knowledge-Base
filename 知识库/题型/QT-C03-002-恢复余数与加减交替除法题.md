# QT-C03-002 恢复余数与加减交替除法题

## 题型定义
围绕恢复余数法、原码加减交替法和补码加减交替法的表格式除法题。

## 常见问法
- 用恢复余数法求商，写出每轮余数恢复过程。
- 用补码加减交替法求商，并说明商 0 时余数如何处理。

## 主考点
- 余数符号判断与商位确定。
- 恢复余数法中“减负了就恢复，再写商位”的步骤。
- 交替除法中依据 `R` 与 `D` 同号 / 异号决定 `-D / +D` 的规则。
- 原码和补码除法流程的区别，尤其是“商 0 时余数如何处理”。

## 常用解题骨架
1. 先统一被除数、除数的编码、符号和位宽，必要时写出 `+D / -D` 或对应补码。
2. 若是恢复余数法，按“左移 -> 减除数 -> 若余数为负则恢复 -> 写商位”的顺序展开。
3. 若是加减交替法，按“看当前 `R` 与 `D` 的符号关系 -> 决定 `+D / -D` -> 看新余数符号 -> 写商位”的顺序展开。
4. 每一轮都要把 `R` 的新状态写出来，不能只写“商1 / 商0”。
5. 最后检查余数修正、商末位、小数点位置和符号。

## 建议作答模板

1. 先写被除数、除数、位宽、编码方式和辅助量。
2. 全过程尽量按表格写，列名优先贴近课件：`符号 / 余数(R) / 商 / 操作说明`。
3. 恢复余数法每轮至少写清：`左移`、`减除数`、`若负则恢复`、`商0/1`。
4. 交替除法每轮至少写清：`R与D同号还是异号`、`因此执行 +D 还是 -D`、`新余数与D同号还是异号`、`商0/1`。
5. 最后一行单独写：`所以商为……，余数为……`，并恢复小数点位置。

## 易错点
- 商 0 时没有按方法要求修正余数，直接进入下一轮。
- 把恢复余数法和交替除法的判断规则混在一起。
- 补码除法时把“加 / 减”的方向写反，或把“同号 / 异号”判据写反。
- 余数已经出错，却没有在表格式过程中显式写出恢复依据。
- 只给最终商和余数，不给逐轮步骤表。
