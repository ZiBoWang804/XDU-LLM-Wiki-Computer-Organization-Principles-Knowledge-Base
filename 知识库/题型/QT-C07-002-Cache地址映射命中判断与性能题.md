# QT-C07-002 Cache地址映射命中判断与性能题

## 题型定义

围绕 Cache 地址字段划分、直接映射 / 组相联映射、命中判断、替换与平均访问时间的题型。

## 常见问法

- 已知 Cache 容量、块大小和主存容量，求地址字段划分。
- 给定主存地址和映像表，判断命中与对应 Cache 块号。
- 已知命中率、访问时间，求平均访问时间。
- 已知多级 Cache（L1/L2/L3）的失效率和访问时间，求整体平均访问时间。

## 主考点

- 地址字段划分：标记、块号 / 组号、块内地址。
- 映射关系与命中条件。
- Cache 性能分析公式。

## 常用解题骨架

1. 先求主存地址位数、Cache 组数 / 块数和块内地址位数。
2. 再写出主存地址字段划分。
3. 命中判断时先定位块 / 组，再比较标记位。

## 期末高频证据

- `2022_final` 和 `计组2022` 都把 Cache 直接映射题列为完整大题。
- 这些题几乎固定会同时考：地址字段划分、命中判断、Cache 块号或组号、变换后的 Cache 地址。
- `课件-存储系统4` 还反复出现平均访问时间和多级 Cache 的性能例题。

## 建议作答模板

1. 先求：
   - 主存地址位数
   - 块内地址位数
   - Cache 块号 / 组号位数
   - 标记位位数
2. 再把主存地址字段写出来。
3. 命中判断时按“主存块号 -> Cache块号/组号 -> 标记比较”写。
4. 若命中，再单独写 Cache 地址。
5. 性能题最后要把公式代入算到最终数值。

## 易错点

- 把主存块号和 Cache 块号直接混同。
- 命中率题只写公式，不代入题目参数算出最终结果。
- 字段位数算对了，但没有把具体地址拆成二进制 / 十六进制对应字段去判断命中。
