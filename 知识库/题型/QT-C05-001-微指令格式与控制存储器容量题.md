# QT-C05-001 微指令格式与控制存储器容量题

## 题型定义

围绕微指令格式设计展开的综合题：给定微指令字长、若干字段中互斥微命令的个数、条件控制产生次地址的条件种数，要求设计微指令的字段划分，求各字段位数、次地址字段位数和控制存储器（控存）最大容量。

## 常见问法

- 已知微指令字长和各字段互斥微命令个数，设计微指令格式，说明字段划分方法。
- 已知条件种数，求次地址字段位数和控制存储器的最大容量。
- 在给定字段数和互斥微命令数的条件下，说明是否需要为"空操作（NOP）"保留编码。

## 主考点

- 字段译码法下每字段所需位数的计算：若有 $k$ 个互斥微命令，至少需要 $\lceil \log_2(k+1) \rceil$ 位（为 NOP 保留全零编码）。
- 条件控制字段、次地址字段与总字长之间的分配关系。
- 次地址字段位数 = 总字长 - 各微命令字段位数之和 - 条件控制字段位数。
- 控存最大容量 = $2^{\text{次地址字段位数}}$。
- "全零编码必须预留为 NOP（空操作）"是影响字段位数计算的核心约束。

## 常用解题骨架

1. **先列题面条件**：微指令字长 $W$ 位、$m$ 个字段、各字段互斥微命令个数分别为 $k_1, k_2, \ldots, k_m$、条件种数为 $c$。
2. **逐字段计算编码位数**：每个字段需要 $\lceil \log_2(k_i + 1) \rceil$ 位，其中 $+1$ 是为全零编码（NOP / 空操作）预留。特别注意当 $k_i = 2^n$ 时（如 8 个、16 个），$2^n - 1$ 不够编码，必须升到 $n+1$ 位。
3. **计算条件控制字段位数**：$c$ 种条件需要 $\lceil \log_2(c+1) \rceil$ 位（含"无条件"状态）。
4. **计算次地址字段位数**：次地址位数 = 总字长 $W$ - 各微命令字段位数之和 - 条件控制字段位数。
5. **求控存最大容量**：最大容量 = $2^{\text{次地址位数}}$ 个微指令字。
6. **以"字段划分表 + 容量结论"的形式整理答案**：列一个表格，写出字段编号、字段内容、微命令个数、编码位数，最后写次地址位数和控存容量。

## 建议作答模板

1. **先逐字段计算所需位数**，用表格呈现：
   ```
   | 字段 | 互斥微命令数 | 含NOP所需编码数 | 编码位数 |
   |------|-------------|----------------|---------|
   | 1    | k1          | k1+1           | ⌈log2(k1+1)⌉ |
   | ...  | ...         | ...            | ...     |
   ```

2. **明确写出是否预留全零空操作状态**：
   ```
   每个字段的全零编码预留为"空操作（NOP）"，因此字段可用编码数为 2^n - 1，不是 2^n。
   ```

3. **计算条件控制字段位数**：
   ```
   条件种数为 c，需要 ⌈log2(c+1)⌉ 位（含"无条件"状态）。
   若 c = 3，需要 2 位；若 c = 4，需要 3 位。
   ```

4. **回推次地址字段位数**：
   ```
   次地址位数 = 总字长 W - (各字段位数之和) - 条件控制字段位数
   ```

5. **写出控存最大容量**：
   ```
   控制存储器最大容量 = 2^(次地址位数) 个微指令字。
   ```

6. **最终答案以"字段划分表 + 容量结论"形式给出**，不要只给一个数字。

## 易错点

- **把"字段包含的互斥微命令个数"直接当成字段位数**。例如有 8 个互斥微命令，不能写"需要 3 位"，而应写"需要 $\lceil \log_2(8+1) \rceil = 4$ 位"，因为全零编码必须预留。
- **漏留空操作状态**：每个字段的全零编码必须预留为"空（NOP）"，因此字段可用编码数为 $2^n - 1$，不是 $2^n$。特别是字段有 $2^k$ 个微命令时（如 8 个、16 个），$2^k - 1$ 不够用，必须升到 $k + 1$ 位。这是扣分率最高的错误。
- **只算字段位数，不继续回推控制存储器容量**。题目通常要求"说明字段划分方法"和"指出控存最大容量"两项，缺一不可。
- **条件控制字段的位数算错**。$c$ 种条件需要 $\lceil \log_2(c+1) \rceil$ 位（含"无条件"状态），不是 $\lceil \log_2(c) \rceil$。
- **总字长减法算错**，忘记扣除条件控制字段的位数。
- **把字段译码法和直接表示法的区别混为一谈**。字段译码法是编码方式，每字段用 $n$ 位编码 $2^n - 1$ 个互斥微命令；直接表示法是每位对应一个微命令，不需要译码。
