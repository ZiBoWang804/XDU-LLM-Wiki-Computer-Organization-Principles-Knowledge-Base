# QT-C08-003 8259工作方式与初始化题

## 题型定义

围绕 8259 的外部引线、工作方式、内部寄存器、控制字、寻址与初始化程序的分析题型。

## 常见问法

- 说明 8259 在 `8080/85` 模式和 `8086/88` 模式下的中断响应差别。
- 解释 `IRR / IMR / ISR`、`ICW1~ICW4`、`OCW1~OCW3` 的作用。
- 写出初始化顺序，或判断某个控制字位设置对应的工作方式。
- 说明 `EOI / AEOI`、`OCW3` 读 `ISR / IRR`、`A0` 寻址等细节。

## 主考点

- 8259 在 `8086 / 8088` 中断系统中的角色，以及外部引线和内部寄存器分工。
- 工作方式中的优先级、屏蔽、触发和结束机制。
- `ICW / OCW`、接口寻址和初始化流程的对应关系。

## 常用解题骨架
1. 先判断题目问的是外部接口、工作方式、控制字、寻址还是初始化程序。
2. 若问工作方式，按“模式 -> 优先级 -> 屏蔽 -> 触发 -> 结束”分类回答。
3. 若问控制字，先区分 `ICW` 还是 `OCW`，再说明对应位的作用。
4. 若问初始化，按 `ICW1 -> ICW2 -> (ICW3) -> (ICW4) -> OCW1` 展开，并指出 `ICW3 / ICW4` 是否需要写入取决于 `ICW1`。
5. 若问状态读取，先用 `OCW3` 指定读 `ISR / IRR`，再从 `A0=0` 的地址读出；`IMR` 则在 `A0=1` 地址直接读取。
6. 若问“固定优先级 / 自动循环优先级”，优先按“谁优先级最高、是否轮换”两句写清。
7. 若是判断题，优先核对 `A0`、`IRR / IMR / ISR`、`ICW3 / ICW4` 是否为条件写入、以及主从 `8259` 连接口径。

## 建议作答模板

1. 先判断题目问的是哪一类：外部接口、工作方式、控制字、寻址还是初始化程序。
2. 工作方式题按五类分别回答：
   - 模式（全嵌套 / 特殊全嵌套 / 优先级自动循环）
   - 优先级（固定优先级：IR0 最高；自动循环：最低优先级轮换）
   - 屏蔽（`OCW1` 设置 `IMR` 对应位）
   - 触发（电平触发 / 边沿触发，由 `ICW1` 的 `LTIM` 位确定）
   - 结束（`AEOI` 由 `ICW4` 的 `AEOI=1` 设定；非自动 `EOI` 由程序写 `OCW2` 发出）
3. 控制字题先区分 `ICW` / `OCW`，再说明 `A0` 寻址规则：`ICW1 / OCW2 / OCW3` 对应 `A0=0`，`ICW2~ICW4 / OCW1` 对应 `A0=1`。
4. 初始化题按 `ICW1 -> ICW2 -> (ICW3) -> (ICW4) -> OCW1` 展开，说明 `ICW3` 受 `SNGL` 位控制，`ICW4` 受 `IC4` 位控制。
5. 判断题优先核对 `A0`、`IRR / IMR / ISR` 读取方式、`ICW3 / ICW4` 是否条件写入、以及主从 8259 `CAS0~CAS2` 级联线对应关系。

## 期末高频证据

- 卷 `1` 直接把 `8259` 放进简答题，考固定优先级与自动循环优先级的含义。
- 卷 `6` 又把 `8259` 放进判断题，考主控 / 从属连接的口径边界。
- 这说明 `8259` 不是只会初始化程序就够，而是“工作方式 + 细节判断 + 初始化流程”三种问法都会反复出现。

## 易错点

- 把 `IRR / IMR / ISR` 三个寄存器混为一谈。
- 认为 `ICW3 / ICW4` 必须无条件写入，忽略它们受 `ICW1` 控制。
- 把 `AEOI` 和程序发出的 `EOI` 混成同一件事。
- 忽略 8259 只有一条 `A0` 地址线，误以为每个控制字都有独立地址。
- 只记住初始化顺序，却不会解释固定优先级和自动循环优先级的差别。
