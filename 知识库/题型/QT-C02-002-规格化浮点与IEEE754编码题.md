# QT-C02-002 规格化浮点与IEEE754编码题

## 题型定义

围绕规格化浮点数的格式定义（基值、阶码位数与编码方式、尾数位数与编码方式）、表示范围（最大正数 / 最小正数 / 最大负数 / 最小负数）、十进制数与机器数互写，以及 IEEE 754 单精度浮点数编码展开的综合计算题。

## 常见问法

- 给定浮点数字长、阶码位数、尾数位数和各自的编码方式，求阶码范围、尾数范围、最大正数、最小正数、最大负数、最小负数。
- 给定一个非规格化浮点数真值，要求写成规格化浮点数表示。
- 以 IEEE 754 短浮点数（32 位）格式表示给定的十进制数。
- 判断规格化浮点数的精度主要取决于阶码还是尾数。
- 给定十进制数，判断能否表示为某种规格化浮点格式。

## 主考点

- 阶码与尾数的位数、编码方式（移码 / 补码 / 原码）和规格化条件。
- 规格化补码尾数的取值约束：符号位与最高数值位必须相异。
- IEEE 754 中符号位（1 位）、阶码（8 位移码、偏置值 127）、尾数（23 位隐含前导 1）的字段含义与填写规则。
- 浮点数数值范围主要取决于阶码，精度主要取决于尾数。

## 常用解题骨架

1. **先写格式定义**：基值（通常为 2）、阶码位数（含阶符？）、尾码位数（含数符？）、阶码编码方式（移码 / 补码）、尾数编码方式（补码 / 原码）。
2. **再求阶码和尾数各自范围**：
   - 移码阶码：如 n 位移码（含 1 位阶符），范围为 $-(2^{n-1}) \sim +(2^{n-1}-1)$。
   - 补码尾数（规格化）：范围为 $-1 \sim -(2^{-1} + 2^{-(m-1)})$ 和 $+(2^{-1}) \sim +(1 - 2^{-(m-1)})$，其中 m 为尾数位数（含数符）。
3. **分四项写表示范围**：最大正数（最大阶码 × 最大正尾数）、最小正数（最小阶码 × 最小正尾数）、最大负数（最大阶码 × 最大负尾数）、最小负数（最小阶码 × 最小负尾数）。每一项同时写出阶码码值、尾数码值和十进制真值。
4. **若题目要求真值写机器数**：先把十进制化成二进制，再规格化（保证符号位与最高数值位相异），最后分别填写阶码和尾数字段。
5. **若考 IEEE 754 单精度**：先做二进制规格化，然后填写符号位（0 正 1 负）、阶码字段（实际指数 + 127 后转 8 位二进制）、尾数字段（去掉隐含前导 1 后取低 23 位）。
6. **最后检查**：结果是否仍满足规格化条件；IEEE 754 阶码全 0 和全 1 是特殊值，不要落入该区段。

## 建议作答模板

1. **第一步写格式定义**：
   ```
   已知：浮点数字长 N 位，阶码 n 位（含/不含阶符），用移码/补码表示；
         尾数 m 位（含/不含数符），用补码/原码表示。基值为 2。
   ```

2. **第二步单独求阶码范围**：
   ```
   阶码范围：移码 n 位 → 阶码最小值 = -(2^(n-1))，阶码最大值 = +(2^(n-1)-1)
   ```

3. **第三步单独求尾数范围**：
   ```
   补码规格化尾数 m 位 → 正尾数范围：[+2^(-1), +(1 - 2^(-(m-1)))]
                         负尾数范围：[-1, -(2^(-1) + 2^(-(m-1)))]
   ```

4. **第四步分四项写极值**：每一行写出"阶码码值（十六进制）| 尾数码值（十六进制）| 十进制真值"。格式参照：
   ```
   最大正数：阶码码值 = ..., 尾数码值 = ..., 真值 = ...
   最小正数：阶码码值 = ..., 尾数码值 = ..., 真值 = ...
   最大负数：阶码码值 = ..., 尾数码值 = ..., 真值 = ...
   最小负数：阶码码值 = ..., 尾数码值 = ..., 真值 = ...
   ```

5. **若要求写机器数**：先做二进制规格化，再按字段顺序写：`符号位 | 阶码 | 尾数`。IEEE 754 题还需写明"隐含前导 1"的处理。

6. **最后检查**：规格化条件是否满足、结果符号是否正确、是否落入特殊值区段（IEEE 754 题）。

## 易错点

- 忘记规格化补码尾数的取值约束：符号位与最高数值位必须相异。不规格化时范围算错。
- 把 IEEE 754 的偏置阶码（实际指数 + 127）当成普通补码处理，导致阶码字段写错。
- 只写十进制范围，不把结果写回题目要求的浮点格式（阶码码值和尾数码值需要写成十六进制）。
- 求"最大负数"时误用最小阶码。最大负数是负数中绝对值最小的（最接近 0 的负数），应使用最小阶码。
- 求"最小负数"时误用最大阶码。最小负数是负数中绝对值最大的（最远离 0 的负数），应使用最大阶码。
- 做 IEEE 754 编码时忘记去掉隐含前导 1，直接把整条尾数放入 23 位字段。
- 对非规格化数做规格化时，左规 / 右规方向搞反，导致阶码调整方向错误。
