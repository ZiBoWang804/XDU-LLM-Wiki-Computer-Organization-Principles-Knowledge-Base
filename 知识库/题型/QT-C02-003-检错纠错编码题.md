# QT-C02-003 检错纠错编码题

## 题型定义

围绕奇偶校验、海明码、CRC 编码与校验的计算型、分析型题型。

## 常见问法

- 对给定数据添加奇校验位、偶校验位，或构造垂直/水平垂直校验码。
- 已知信息位，构造海明码，或根据综合校验结果指出哪一位出错。
- 已知生成多项式，求 CRC 编码字，或对接收码做模 2 除法校验。

## 主考点

- 奇偶校验的构造规则与检错能力边界。
- 海明码校验位数、校验位组织方式和错位定位方法。
- CRC 的生成多项式、模 2 运算和余数拼接规则。

## 常用解题骨架
1. 先判断题目要求的是奇偶校验、海明码还是 CRC。
2. 若是奇偶校验，先明确奇/偶规则，再按行、列或二维结构求校验位。
3. 若是海明码，先用 `2^k >= n + k + 1` 求校验位数，再根据校验组求出校验位，并用综合校验结果定位错位。
4. 若是 CRC，先将信息位左移 `k` 位补 `0`，再做模 2 除法求余数，并把余数拼接回编码字；接收端再做一次除法校验。

## 建议作答模板

1. **奇偶校验题**：
   ```
   ① 明确题目要求的是奇校验还是偶校验。
   ② 对给定信息位按位模 2 加，求出校验位。
   ③ 若是水平垂直校验码（二维校验），分别按行和列求校验位，写出完整编码矩阵。
   ④ 写明结论：奇偶校验只能检错（检 1 位错），不能纠错。
   ```

2. **海明码题**：
   ```
   ① 用 2^k >= n + k + 1 确定校验位数 k，其中 n 为信息位数。
   ② 将校验位放在位号为 1, 2, 4, 8, ... 的位置上，信息位填入其余位置。
   ③ 按校验组规则（位号二进制展开法）列出每个校验位覆盖的位集合。
   ④ 分别求出各校验位的值（偶校验或奇校验，按题目要求）。
   ⑤ 若题目给出接收码要求纠错：计算综合校验值 S = s_k ... s_2 s_1，
      将其二进制值转为十进制，即为出错位号；对该位取反即完成纠错。
   ⑥ 若 S = 0，说明无错。
   ```

3. **CRC 编码题**：
   ```
   ① 确定生成多项式 G(x) 及其对应的二进制位数 r+1 位（校验位 r 位）。
   ② 将信息位左移 r 位（低位补 r 个 0）。
   ③ 对补零后的信息做模 2 除法（除以 G(x) 对应的二进制），求出 r 位余数。
   ④ 将余数拼接到信息位低位，得到完整 CRC 编码字。
   ⑤ 接收端校验：将收到的编码字再做一次模 2 除法，
      若余数为 0 则传输无错；若余数不为 0 则传输出错。
   ⑥ 教材写有"CRC码可以发现并纠正错误""余数指出哪一位出错，即可纠正"，
      但当前本地课程资料中缺少"余数→定位错位→纠正"的完整操作例题
      （参见 [ERR-C02-002](../勘误/ERR-C02-002-第2章CRC纠错能力表述待核定.md) 已分析结论）。
      若题目只问编码与校验，按 ①~⑤ 作答即可；
      若题目明确要求说明纠错能力，可引用教材原文表述，但需注明
      纠错前提是生成多项式和编码参数满足特定条件。
   ```

## 易错点

- 把奇偶校验当成可纠错编码，忽略它只能做简单检错。
- 海明码不先确定校验位数和位序，直接硬套结果。
- CRC 用普通十进制除法替代模 2 除法，或把余数拼接到错误位置。
