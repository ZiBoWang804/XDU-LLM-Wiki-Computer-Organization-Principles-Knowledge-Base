# QT-C07-001 存储器类型比较与容量扩展题

## 题型定义

围绕 SRAM / DRAM / ROM 等存储器特性比较，以及按芯片规格和地址范围完成容量扩展、连线分析的题型。

## 常见问法

- 比较 SRAM、DRAM、ROM 的工作原理、是否掉电保持、是否需要刷新以及优缺点。
- 已知地址范围和芯片规格，求总容量、扩展方式与所需片数。
- 在 8086 / 8088 系统中，用 `8K×8`、`6264`、`256K×8` 等芯片构成给定容量或地址范围的内存。

## 主考点

- RAM / ROM / DRAM 的结构与特性边界。
- 位扩展、字扩展、地址范围换算与片数计算。
- 地址线、数据线、片选译码，以及高低字节分配的基本思路。

## 常用解题骨架
1. 先判断题目是“特性比较”还是“容量扩展 / 连线分析”。
2. 若是比较题，按是否可写、是否掉电保持、是否需要刷新、速度 / 功耗 / 集成度分点作答。
3. 若是扩展题，先把地址范围换成总容量，再根据芯片规格判断是位扩展、字扩展还是二者结合。
4. 最后给出片数、地址线 / 数据线连接和片选译码；若题目给出 8086 / 8088，还要检查高低字节或奇偶体分配。

## 期末高频证据

- `计组2022` 与 `2022 A卷` 都出现了“给定地址范围和芯片规格，判断扩展方式并计算片数”的稳定题型。
- 第 7 章教材、存储系统课件和随堂测验说明：这类题并不只考片数，更考你是否能区分“位扩展 / 字扩展 / 混合扩展”。
- 在六套混合卷里，卷 `3 / 5 / 6` 又分别出现了 `SRAM` 地址范围分析、`2732` 译码扩展、`6264` 双体存储器地址判断等变体。

## 建议作答模板

1. 先把地址范围换成总容量。
2. 再把目标内存写成“字数 × 位数”的形式。
3. 对照芯片规格，判断先做位扩展还是先做字扩展。
4. 最后写片数、地址线连接、数据线连接和片选译码。
5. 如果题目指定 8086 / 8088，单独说明总线宽度带来的差异。
6. 若题目明确要求“画出连接图”，则文字说明之后应补成图答案，不只停留在文字连线分析。
7. 若是 `8086 + 6264` 一类题，优先画出：
   - 左侧系统总线
   - 中间译码器
   - 右侧高低字节体芯片
   - `A0` 与 `\overline{BHE}` 的选通信号
   - 地址线、数据线、读写控制线、片选线的实际连线

## 易错点

- 地址范围首尾都算进来时少算一个边界，或十六进制容量换算错误。
- 只算总容量，不说明是位扩展、字扩展还是混合扩展。
- 忘记 DRAM 需要刷新，或把 ROM 写成掉电丢失。
- 把 8088 的 8 位数据总线和 8086 的 16 位数据总线混为一谈。
