# QT-C04-002 8086指令结果与汇编程序分析题

## 题型定义

围绕 8086 指令执行结果判断、寄存器/内存变化分析，以及整段汇编程序功能说明的题型。

## 常见问法

- 执行一条 MOV / ADD / PUSH / CMP / LOOP 后，寄存器或内存单元结果是什么。
- 阅读一段汇编程序，说明它完成的功能，并给出关键寄存器最终值。
- 执行串操作指令（如 REP MOVSB / LODSB / STOSB）后，内存区域或寄存器的变化。

## 主考点

- 指令语义、寻址规则、条件转移和循环控制。
- 程序中数据流和控制流的整体跟踪。

## 常用解题骨架

1. 先按顺序跟踪关键寄存器和关键内存单元。
2. 遇到循环时，先判断循环变量与终止条件。
3. 功能分析时，先找初始化、核心循环、输出结果三段。
4. 若涉及串操作指令（REP MOVSB 等），先确定源地址、目的地址和计数寄存器（CX），再按字节/字逐次传送。

## 期末高频证据

- `2020_final` 明确指出“读汇编，说明程序完成的功能”，并给出“统计缓冲区中偶数个数并求平均值”的典型功能。
- `2022_final` 与 `计组2022` 都保留了“读汇编代码，说明功能并给关键寄存器最终值”的大题形态。
- `计算机组成与结构1-5答案` 中保留了很多“先求地址、再跟踪寄存器、最后给功能”的书写口径。

## 建议作答模板

1. 先按程序分三段：初始化、循环主体、结束/输出。
2. 再写每一段做什么。
3. 如果题目要寄存器结果，单独列出 `AX / BX / CX / DX / SI` 的最终值。
4. 最后用一句完整的话总结“程序完成功能是……”

## 易错点

- 只盯一条指令，不跟踪前面语句对寄存器的准备。
- 忽略 `INC SI`、`LOOP` 这类控制流程变化。
- 只写“求最大值 / 求平均值”，不交代它比较了什么、统计了什么、结果存在哪里。
