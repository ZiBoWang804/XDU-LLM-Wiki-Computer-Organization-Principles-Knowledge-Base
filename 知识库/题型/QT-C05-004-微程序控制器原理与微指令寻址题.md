# QT-C05-004 微程序控制器原理与微指令寻址题

## 题型定义

围绕微程序控制器的基本工作原理、微操作层次关系、微指令中的地址域与控制域、下一条微指令地址的形成方式，以及水平型控制域编码等内容展开的题型。

## 常见问法

- 说明微操作、微命令、微指令、微程序之间的层次关系。
- 简述微程序控制器的工作原理。
- 微指令中地址域和控制域各起什么作用。
- 如何形成下一条微指令地址。
- 在哪些情况下需要微指令跳转，并举例说明。
- 水平型微指令控制域的编码方法是什么，有什么组织特点。
- 比较两地址格式、单地址格式、可变格式这几类微地址形成思路。

## 主考点

- 微操作是 CPU 中最基本的硬件动作；微命令是触发微操作的控制信号；微指令是一组微命令的编码；微程序是一组微指令序列，对应一条机器指令的执行过程。
- 微程序控制器把控制信号“程序化”并存入控制存储器，通过顺序取出微指令来产生控制命令。
- 微程序控制器的核心部件包括：控制存储器（CM）、微地址寄存器 `μAR`、微指令寄存器 `μIR`、微地址形成电路、时序逻辑。
- 微指令一般由地址域和控制域组成。地址域决定如何获得后继微指令地址，控制域负责发出控制信号。
- 下一条微指令地址通常有三类来源：当前地址顺序加 1、由指令寄存器译码得到微程序首地址、按条件或无条件分支跳转。
- 微指令跳转常出现在：一条新机器指令刚取到之后需要跳到对应微程序入口、条件转移类指令、测试状态标志后的分支、中断或异常处理入口等场景。
- 水平型微指令强调并行控制能力强，控制域较长；字段译码法是在字段内做垂直编码、字段间保持水平组织。

## 常用解题骨架

1. **先交代控制器任务**：根据指令操作码、时序和状态信息，产生一系列微命令，驱动各部件完成微操作。
2. **再写层次关系**：微操作 → 微命令 → 微指令 → 微程序 → 机器指令。
3. **若题目问工作原理**，按“`μAR` 取址 → 控存读出微指令到 `μIR` → 控制域发控制信号 → 地址形成电路给出下条微地址”这一顺序说明。
4. **若题目问地址域 / 控制域**，明确写：地址域负责后继微地址信息，控制域负责本条微指令的控制信号。
5. **若题目问微指令寻址**，固定按三类地址来源展开：顺序地址、微程序首地址、分支跳转地址。
6. **若题目问编码方法**，先写水平型 / 垂直型的基本差异，再写直接表示法和字段译码法的核心口径。

## 建议作答模板

1. **若问层次关系**，先给出一句标准链条：
   ```
   微操作是最基本的硬件动作；微命令是控制微操作的信号；
   微指令是若干微命令的编码；微程序是一组微指令序列，用来实现一条机器指令。
   ```
2. **若问微程序控制器原理**，按部件顺序作答：
   ```
   μAR 给出控存地址 → 控存读出微指令送入 μIR →
   μIR 的控制域产生控制信号 →
   地址形成电路根据地址域和状态信息形成下条微地址 →
   新微地址送回 μAR
   ```
3. **若问地址域与控制域**，固定写法：
   ```
   地址域：决定下条微指令如何取得
   控制域：给出本条微指令需要发出的控制信号
   ```
4. **若问微指令寻址**，固定分三类：
   - 顺序执行：`μPC + 1`
   - 入口转移：由指令寄存器译码得到微程序首地址
   - 分支转移：按条件或无条件跳转
5. **若问编码方式**，先写：
   - 水平型：并行控制能力强，控制域长
   - 垂直型：编码更紧凑，但并行性较弱
   - 字段译码法：字段内垂直编码，字段间水平并列
6. **若题目要求“举例说明跳转”**，应补一条场景，例如：条件转移指令检查标志位后选择不同微地址；取到新机器指令后跳转到该指令微程序入口。

## 易错点

- 把“微命令”和“微指令”混写。微命令是控制信号，微指令是这些控制信号的编码与组织形式。
- 把“微程序控制器原理题”答成“组合逻辑控制器 vs 微程序控制器对比题”。若题目不要求比较，就不要把篇幅浪费在优缺点对照上。
- 把地址域理解成“操作数地址”。这里的地址域指的是后继微指令地址信息，不是机器指令中的操作数地址码。
- 只写“下条微地址有三种来源”，却不点出“微程序首地址 / 顺序地址 / 分支地址”这三类具体来源。
- 把水平型和垂直型微指令的差别只写成“长 / 短”，忽略“并行控制能力强弱”这一核心原因。
- 题目要求“举例说明跳转”时，只写定义不写场景。
