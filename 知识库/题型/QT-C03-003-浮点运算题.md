# QT-C03-003 浮点运算题

## 题型定义

围绕浮点加减、乘除、对阶、规格化、舍入和结果编码的步骤计算题。与"规格化浮点与IEEE754编码题（QT-C02-002）"的区别在于：QT-C02-002 侧重浮点格式定义和表示范围，本题型侧重两个（或多个）浮点数之间的运算过程和中间步骤。

## 常见问法

- 给出两个浮点数 `[X]浮` 和 `[Y]浮`，按浮点运算规则计算 `[X±Y]浮` 或 `[X·Y]浮` 或 `[X÷Y]浮`，要求给出完整运算步骤。
- 尾数相乘采用 Booth 补码乘法，要求同时写出 Booth 表格过程。
- 结果需要规格化时，说明左规或右规的次数和理由。
- 判断浮点乘法结果"最多需要右规几位"并说明理由。

## 主考点

- **对阶**：小阶向大阶看齐，小阶的尾数右移，右移位数 = 大阶 − 小阶。
- **尾数运算**：加减题对阶后直接做补码加减；乘除题先处理符号和阶码，再做尾数乘除。
- **规格化**：运算后检查尾数是否满足规格化条件（补码规格化：符号位与最高数值位相异）。若不满足则左规（阶码减 1、尾数左移 1 位）或右规（阶码加 1、尾数右移 1 位）。
- **溢出判断**：规格化后阶码是否超出表示范围。阶码上溢 → 浮点数溢出；阶码下溢 → 置零。
- **舍入处理**：尾数右移后的舍入规则（0 舍 1 入、恒置 1 等），是否需要二次规格化。
- **结果编码**：把最终结果回写到题目要求的浮点格式。

## 常用解题骨架

1. **写出操作数的阶码和尾数**：明确位宽、编码方式（补码 / 移码）、小数点位置。
2. **加减题先对阶**：求阶差 ΔE = Ex − Ey，小阶的尾数右移 |ΔE| 位，阶码取大阶。
3. **乘除题先处理符号和阶码**：乘法阶码相加，除法阶码相减；乘法尾数直接相乘，除法尾数做除法。
4. **尾数运算**：按补码规则做加减（加减题）或 Booth 乘法（乘法题）。
5. **统一做规格化**：检查是否需要左规 / 右规，每次规格化同时调整阶码。
6. **溢出检查**：阶码超出上限 → 溢出；阶码低于下限 → 下溢置零。
7. **舍入与回写**：右移后的舍入处理，最后把阶码和尾数写回题目要求的浮点格式。

## 建议作答模板

1. **第一步写操作数的阶码和尾数**：
   ```
   已知：浮点数字长 N 位，阶码 n 位（含 1 位阶符），用补码/移码表示；
         尾数 m 位（含 1 位数符），用补码表示。基值为 2。
   [X]浮 = Ex Mx    [Y]浮 = Ey My
   其中 Ex = ..., Mx = ...; Ey = ..., My = ...
   ```

2. **加减题——对阶**：
   ```
   阶差 ΔE = Ex − Ey = ...
   因为 |ΔE| > 0，所以小阶（X 或 Y）的尾数右移 |ΔE| 位，阶码调整为大阶值。
   对阶后：Ex' = Ey' = ..., Mx' = ...（右移后补符号位）
   ```

3. **乘除题——处理符号和阶码**：
   ```
   结果符号 = X符号 ⊕ Y符号（乘法）或 X符号 ⊕ Y符号（除法）
   结果阶码 = Ex + Ey（乘法）或 Ex − Ey（除法）
   尾数运算：Mx × My（用 Booth 法）或 Mx ÷ My
   ```

4. **尾数运算**：
   - 加减题：直接做补码加减。
   - 乘法题：如要求 Booth 法，需单独写出完整 Booth 表格（列名：`符号 / D / Y / Y_0 / Y_{-1} / 操作说明`），每轮写清加 / 减 / 右移。

5. **规格化与溢出判断**：
   ```
   检查尾数是否满足规格化条件：
   - 补码规格化：符号位与最高数值位相异。
   - 若不满足，左规（阶码 −1，尾数左移 1 位）/ 右规（阶码 +1，尾数右移 1 位）。
   检查阶码是否溢出：阶码最大值 / 最小值与允许范围比较。
   ```

6. **舍入与回写**：
   ```
   若尾数右移后截断，按题目要求舍入（0 舍 1 入 / 恒置 1）。
   结果：[Z]浮 = Ez Mz，写回题目要求的浮点格式。
   ```

## 易错点

- **对阶方向搞反**：应该是小阶向大阶看齐（小阶的尾数右移），而不是大阶向小阶看齐。对阶后阶码取大阶值。
- **对阶后忘记同步说明"谁右移、右移几位"**：只写了一个结果数字，没有交代移位过程。
- **把尾数补码规格化条件写错**：补码规格化要求符号位与最高数值位相异（正数以 01 开头，负数以 10 开头），不是简单地看尾数是否"大于 0.5"。
- **只算出真值，没有回写到题目要求的浮点格式**：最终答案必须是阶码码值 + 尾数码值的形式。
- **溢出判断遗漏**：规格化后必须单独检查阶码是否超出表示范围，不能只看尾数规格化。
- **Booth 乘法过程和浮点乘法过程混在一起**：浮点乘法题如果要求用 Booth 法做尾数乘法，需要把 Booth 表格过程单独完整写出，不能跳步。
- **舍入后忘记检查是否需要二次规格化**：某些舍入操作可能导致尾数溢出，需要再做一次右规。
- **乘法阶码相加后不检查溢出**：两个合法阶码相加后可能超过阶码表示范围。
