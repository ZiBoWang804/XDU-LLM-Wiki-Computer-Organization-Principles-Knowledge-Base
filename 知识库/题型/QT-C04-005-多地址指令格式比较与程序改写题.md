# QT-C04-005 多地址指令格式比较与程序改写题

## 题型定义

围绕指令格式的基本组成（操作码 + 地址码），以及不同地址码数目（零地址 / 一地址 / 二地址 / 三地址）对程序改写方式、程序长度、执行效率和适用场景的影响展开的比较题。

## 常见问法

- 说明指令格式由哪两部分组成，各部分的作用。
- 比较零地址、一地址、二地址、三地址指令在程序长度和访存次数上的差异。
- 给定一个表达式，分别用三地址、二地址、一地址、零地址指令写出程序。
- 比较不同地址数指令在程序条数、临时变量需求和适用场景上的差异。
- 给定运算表达式（如 `Y = (A+B) × (C-D)`），分别用三地址、二地址、一地址、零地址指令写出汇编程序，并比较程序条数。
- 说明变长指令格式与定长指令格式的设计取舍。

## 主考点

- 指令 = 操作码（opcode）+ 地址码（operand / address code）。
- 操作码决定指令做什么操作，地址码指出操作数来源和结果去向。
- 地址码数目越多，单条指令表达能力越强，改写出的程序往往更短，但指令字也更长。
- 三地址指令：`OP A, B, C` 表示 `C = A OP B`，程序最短但指令字最长。
- 二地址指令：`OP A, B` 表示 `A = A OP B`，是常见的折中。
- 一地址指令：`OP A` 表示 `AC = AC OP A`，需要隐含累加器（AC），指令字短但程序条数多。
- 零地址指令：无地址码，操作数来自栈顶（如堆栈计算机），指令字最短但程序依赖栈结构。
- 指令字长固定时，地址码位数越多则操作码位数越少，可编码的指令种类越少；反之亦然。

## 常用解题骨架

1. **先写指令格式的基本组成**：操作码 + 地址码。
2. **若题目是比较题**，按地址码数目从多到少逐级说明：
   ```
   三地址：C = A OP B，程序条数最少，访存次数最少，指令字最长
   二地址：A = A OP B，折中方案
   一地址：AC = AC OP A，需隐含AC，程序条数多
   零地址：栈顶运算，指令字最短，程序依赖栈
   ```
3. **若题目要求写汇编程序**，对给定表达式分别用不同地址码格式改写：
   - 三地址：每条指令可同时指定两个源操作数和一个目标。
   - 二地址：其中一个源操作数同时也是目标，因此第一条指令结果留在某个地址中。
   - 一地址：所有运算都经过累加器 AC，中间结果暂存 AC。
   - 零地址：先用 PUSH 压栈，再用运算指令弹栈运算，结果留在栈顶。
4. **若题目顺带涉及位数分配**，再补充说明：操作码位数 = 指令字长 − 地址码字段数 × 每个地址字段位数。
5. **最后回到题型主旨**，比较哪一种地址数更适合该表达式、为什么。

## 建议作答模板

1. **写指令格式组成**：
   ```
   指令 = 操作码（opcode）+ 地址码（address code）
   操作码：指定操作类型
   地址码：指定操作数来源和结果去向
   ```

2. **比较不同地址码数目**：
   ```
   | 地址码数 | 格式示例    | 语义             | 程序条数 | 指令字长 | 访存次数 |
   |---------|------------|-----------------|---------|---------|---------|
   | 3       | OP A,B,C   | C = A OP B      | 最少    | 最长    | 较少    |
   | 2       | OP A,B     | A = A OP B      | 较少    | 较长    | 较多    |
   | 1       | OP A       | AC = AC OP A    | 较多    | 较短    | 较多    |
   | 0       | OP         | 栈顶运算         | 最多    | 最短    | 依实现  |
   ```

3. **若要求写程序**，对表达式逐级改写并数条数对比。

4. **若题目顺带问字段位数**：
   ```
   操作码位数 = 指令字长 − 地址码字段数 × 每字段位数
   可编码指令条数 = 2^(操作码位数)
   ```

## 易错点

- 把二地址指令的语义写成 `C = A OP B`——那是三地址指令的语义；二地址是 `A = A OP B`，其中一个操作数被结果覆盖。
- 一地址指令忘记说明隐含累加器（AC）——一地址指令的操作数来源和结果去向都依赖 AC，不写清楚 AC 会导致语义不完整。
- 零地址指令只写"栈顶运算"，不说明 PUSH / POP 的栈操作——零地址指令依赖栈结构，程序需要先压栈再运算。
- 把地址码数目和程序条数的关系搞反。地址码数多通常让单条指令表达能力更强，因此程序条数更少，但不是“所有指标都更好”。
- 写程序时不同地址码格式混用。每种格式有自己的约束，如一地址必须经过 AC，零地址必须通过栈。
