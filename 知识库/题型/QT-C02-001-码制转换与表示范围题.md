# QT-C02-001 码制转换与表示范围题

## 题型定义

围绕原码、反码、补码、移码、BCD 码之间转换，以及表示范围判断的题型。

## 常见问法

- 已知一个机器数，求其真值。
- 比较原码、补码、移码的表示范围或边界值。
- 给定十进制数，写出对应编码。

BCD 加法与校正的独立题型参见 [QT-C02-004](./QT-C02-004-BCD加法与校正题.md)。

## 主考点

- 各种编码规则与符号位处理方式。
- 边界数值，如最小负数和最大正数。

## 常用解题骨架

1. 先判定编码类型。
2. 再分"正数 / 负数"分别处理。
3. 最后单独检查边界值是否越界。

## 期末高频证据

- `2020_final` 直接点名：原码 / 反码 / 补码转换，以及真值乘 2、除 2 后的机器数。
- `2022_final` 与 `计组2022` 都出现了“已知 `[X]补`，求 `[2X]补 / [X/2]补 / [-X]补`”。
- 这类题通常出现在试卷前段，分值不算最高，但判分非常直接，属于典型送分题。

## 建议作答模板

1. 先写清题目给的是哪一种编码。
2. 若题目给的是补码，先判断符号，再还原真值或直接按补码规则变形。
3. 分别计算 `2X`、`X/2`、`-X`。
4. 每一步都回写成题目要求的机器数格式，不只写真值。
5. 最后单独检查是否越界或发生溢出。

## 易错点

- 把补码最小负数错误地当成可取绝对值的普通数。
- 混淆移码与补码在符号位上的差异。
- 对 `X/2` 直接做逻辑右移，忘记补码算术右移的符号扩展。
