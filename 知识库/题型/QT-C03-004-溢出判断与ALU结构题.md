# QT-C03-004 溢出判断与ALU结构题

## 题型定义

围绕定点加减溢出判断、ALU 功能和运算器结构分析的题型。

## 常见问法

- 判断补码加减运算是否溢出。
- 给出运算器或 ALU 简图，分析数据流或写出运算步骤。
- 用移码表示两个数并求其和或差。

## 主考点

- 溢出判别逻辑。
- ALU 和运算器中寄存器、数据通路的作用。

## 常用解题骨架

1. 先写符号位变化或判溢规则。
2. 再根据图中的寄存器和总线关系展开步骤。

## 复习补强

- 运算方法习题课反复强调了单符号位法、双符号位法和 `OF = CF xor SF` 的书写口径。
- 这类题虽然在回忆卷中不如 Booth 和浮点题稳定，但在平时题、习题课和运算器结构题里很容易作为基础步骤出现。

## 期末高频证据

- `部分作业题-习题课-运算方法-Spring-2020` 反复覆盖三种溢出判别方法：单符号位法、双符号位法（$OF = S_1 \oplus S_2$）和符号位与进位标志法（$OF = CF \oplus SF$），并给出正溢出和负溢出的完整算例。
- `卷3-试题` 第五/六/七大题（10 分）：给出含 `R0`~`R2`、`PC`、`IR`、`MAR`、`MDR`、`A`、`B`、`X`、`Y`、`ALU`、`C` 等部件的计算机系统框图，要求写出微操作流程、判断控制信号相容/互斥关系，并分析 ALU 数据通路。
- `卷2-试题` 第五大题（10 分）：给出含 `CPU`、`主存`、`外设`、`总线` 的计算机框图，题面涉及 ALU 的 `ADD`、`Mread`、`Mwrite` 等微命令能力，要求分析指令执行流程中的数据通路。
- `笔记-计算机组织与体系结构课程复习要点` 第 3 章明确列出"定点补码加减运算及溢出判断"和"行波进位和先行进位加减法器的特点"为复习要点。
- `笔记-summary` 第三章"运算方法与运算器"下列出"溢出判定"包含"双符号位判决、进位判决、运算前后符号位判决"三种方法。
- `笔记-计组上_复习笔记` 中 `OF` 标志的用法：当运算发生进位时 `CF` 置 1，溢出判断条件 $OF = CF \oplus SF$。
- 此类题在回忆卷中不如 Booth 乘法或浮点题稳定出大题，但溢出判断作为基础步骤经常出现在补码加减、浮点运算等综合题中；ALU / 运算器结构分析则在卷 2 和卷 3 的框图题里出现。

## 建议作答模板

1. 先说明当前采用哪一种判溢规则。
2. 若是补码加减，优先写“同号相加、异号相减才可能溢出”。
3. 若题目给了 `CF / SF / OF`，单独写出判定逻辑。
4. 若题目给的是 ALU 或运算器结构图，再按“寄存器 -> ALU -> 回写”顺序说明数据流。

## 易错点

- 只看结果符号，不按补码规则判断溢出。
- 把“单符号位法”和“双符号位法”混用，导致结论前后不一致。
- 图结构题只看 ALU，不看寄存器与总线约束。
