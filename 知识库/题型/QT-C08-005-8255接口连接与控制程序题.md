# QT-C08-005 8255接口连接与控制程序题

## 题型定义

围绕 `8255` 与按键、开关、发光二极管、温度值等外设的连接，以及根据外设状态编写控制程序的题型。

## 常见问法

- 给定接口地址范围，画出 `8255` 与外设接到 `8088 / 8086` 系统总线上的连接图。
- 说明 `PA / PB / PC` 各口分别承担什么输入输出角色。
- 根据按键或传感器状态，编写分支控制程序点亮 LED 或控制 `CTL` 信号。

## 主考点

- `8255` 的 `PA / PB / PC` 口方向分配。
- `RD / WR / CS / A0 / A1` 与系统总线的连接。
- 输入读取、条件判断、输出控制三段式程序骨架。
- 题目明示的“按下 / 抬起”或“温度大小”逻辑翻译成汇编分支。

## 常用解题骨架

1. 先说明外设各信号接到 `8255` 哪个口位。
2. 再说明地址线、数据线、片选信号如何接。
3. 程序部分固定按：
   - 读输入
   - 掩码 / 比较
   - 条件转移
   - 输出控制
   - 回跳
4. 若题目说明 `8255` 已初始化，可直接从读写程序开始。

## 期末高频证据

- 卷 `1 / 4 / 5 / 6` 都出现了 `8255` 或按钮/LED/控制端程序题。
- 题型形式稳定集中在两类：
  - 画出接口连接图
  - 写出按状态分支的控制程序
- 这类题的失分往往不是逻辑不会，而是“口线没说明白、程序没拆层”。

## 建议作答模板

1. 先写“哪一口输入、哪一口输出、哪一位接哪个外设”。
2. 再写系统总线侧的地址线、数据线、片选和读写控制。
3. 程序固定拆成：
   - `IN`
   - `AND / CMP`
   - `JZ / JNZ / JNC`
   - `OUT`
   - `JMP`
4. 题目要求“画图”时，优先给可照抄的成图答案，不只写抽象说明。

## 易错点

- 只写程序，不交代 `PA / PB / PC` 口的分配。
- 输入状态位没有先掩码就直接判断。
- 分支方向写反，导致“按下”和“抬起”的输出逻辑互换。
- 把“题目已说明不必初始化 8255”的前提忘掉，平白多写一段无关初始化。
