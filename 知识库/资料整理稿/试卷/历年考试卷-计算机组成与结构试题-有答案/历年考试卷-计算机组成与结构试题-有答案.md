### 卷 1：填空 + 简答 + Cache / 流水线 / 外设接口 + 参考答案

#### 试题主干

- 填空题
  - Cache 设置依据与一致性方法
  - 内存与接口编址方式
  - RAID2 含义
  - 磁盘接口总线
  - 2x2 互连开关连接方式
  - 8086/8088 响应中断请求条件
  - 串行通信的起始位/停止位
  - 8253 计数器数量、位数、最大计数值
  - 多核处理器属于 SMP / 对称多处理结构
- 简答题
  - 8088/8086 上 NMI 的响应过程
  - 8253 在 1MHz 下产生 1 秒周期对称方波
  - 对称多处理机系统结构和特点
- 综合题
  - Cache-MN 两级存储器地址变换与命中判断
  - 中断方式与 DMA 方式下 CPU 时间占比
  - 流水线时空图、加速比、效率
  - 8255 / 外设控制连接题

#### 答案主干

- Cache 设置依据：程序执行及数据访问的局部性原理
- 编址方式：统一编址、独立/隔离编址
- RAID2：位交叉海明编码阵列
- NMI 响应过程：硬件给出中断类型码、压栈 F/CS/IP、查中断向量表
- 8253 产生 1 秒方波：两个计数器串联，总计数值 `1000 x 1000`
- SMP 特点：多个处理器、共享主存和 I/O、统一操作系统管理
- 流水线示例结果：加速比约 `1.75`，效率约 `44%`
- 中断/DMA 示例结果：约 `2.5%` 与 `1%`

### 卷 4：2011 年 6 月《计算机组成与结构 II》试题

#### 试题主干

- 单项选择题

- 填空题
  - 8086 中断系统
  - 相联存储器按内容访问
  - 多核处理器结构
  - Cache 替换算法
  - 多体主存目的
  - 道密度与位密度定义
- 判断题
  - EEPROM / EPROM
  - 8255 按位控制
  - 8086 中断系统
- 简答题
  - Cache 一致性方法
  - 8253 方式 3 特点
  - PCI 特点
  - 磁盘容量与传输率
  - Cache 命中率与平均访问时间
- 综合题
  - 6264 / SRAM / 8086 总线连接
  - 直接映像 Cache
  - 8253 波形题
  - 按钮开关接口与程序题

#### 答案主干

- 8086 中断系统：`256`，`8` 位，中断类型码
- 多核处理器结构：SMP
- Cache 一致性：写回法 / 全写法
- PCI 特点：高传输性能、即插即用、多主控等
- 8253 方式 3：输出对称方波，GATE 低时强迫 OUT 为高
- 命中率示例：`24200 / 25000 = 0.968`
- 直接映像 Cache：
  - `8KB / 16B = 512` 块
  - 主存第 `513` 块映入 Cache 第 `1` 块
  - `04011H` 对应未命中
- 计数器波形题：`OUT2` 周期约 `800us`，`OUT1` 脉冲宽度约 `400ms`
