## 二、简答题参考答案

### 1. 8088 上外部中断 INTR 的响应过程

答案区可恢复的主干是：

1. 外设在 CPU 的 `INTR` 输入端加高电平，提出可屏蔽中断请求。  
2. CPU 在一条指令执行结束、且满足 `IF=1` 等条件后响应。  
3. CPU 从 `INTA` 送出两个负脉冲。  
4. 在第二个负脉冲期间，从数据线获得外设提供的中断类型码。  
5. CPU 将断点信息 `F`、`CS`、`IP` 压栈保护。  
6. 由中断类型码查中断向量表，取出中断服务程序入口地址。  
7. 将入口地址装入 `CS:IP` 后转入中断服务程序执行。  

### 2. 异步串行通信传送 ASCII `B` 的波形

答案区表明本题给出了波形图。  
当前可稳定确认的是：

- 数据格式：`7` 位数据位、`奇校验`、`1` 位停止位  
- 该题要求按给定串口格式画出波形  
- 若传送 ASCII 大写字母 `B`（`42H`），其 7 位数据可写作 `1000010`。
- 按异步串行通信低位先发规则，数据位发送顺序为：
  - `0 1 0 0 0 0 1`
- 该 7 位数据中 `1` 的个数为 `2`，为满足奇校验，校验位应为 `1`。
- 因而整个帧可概括为：
  - 起始位 `0`
  - 数据位 `0 1 0 0 0 0 1`
  - 奇校验位 `1`
  - 停止位 `1`
- 由于题中波形图依赖原页图，当前建议直接联读：
  - `../images/9402aa09fb13247e5bd988af7fea192ae5fa05eb0169203627946645b4cc26ce.jpg`

### 3. DMA 方式的一般过程

可恢复的答案主干如下：

1. 外设向 `DMAC` 提出 DMA 请求。  
2. `DMAC` 通过 `HOLD` 向 CPU 请求总线控制权。  
3. CPU 在当前总线周期结束时响应，请求获准后将三态信号置高阻，并送出 `HLDA`。  
4. `DMAC` 获得总线控制权，送出内存地址，控制内存读与接口写，将数据传送到外设。  
5. 传送过程中地址自动修改，计数自动减 1。  
6. 一批数据传送结束后，`DMAC` 使请求信号无效。  
7. CPU 重新获得总线控制权，继续执行原程序。  

### 4. 对称多处理机系统的三个特点

可稳定恢复的答案主干：

1. 由两个以上功能相同的处理器构成。  
2. 各处理器通过总线共享主存和 I/O。  
3. 所有处理器都可完成同样的功能。  
4. 系统由一个操作系统统一调度和管理。  

前三条或任意三条合理表述即可得分。

### 2. 只用 8253 产生 `1s` 周期对称方波

答案主干：

1. 外部计数时钟 `2MHz`，时钟周期为 `0.5us`。  
2. 若要求输出周期 `1s`，则总计数值应为：
   - `1000000us / 0.5us = 2000000`
3. 单个计数器为 16 位，单独使用最大计数时间不够，因此需要两个计数器串联。  
4. 可令两个计数器都工作在 `方式 3`。  
5. 取总计数值为 `2000 x 1000`，例如一个计数器取 `1000`，另一个取 `2000`。  
6. 将前一级 `OUT` 输出接到后一级 `CLK` 输入，即可得到周期为 `1s` 的方波。  

根据答案程序，可继续高置信恢复：

- 控制寄存器地址：`FF06H`
- 计数器 0 地址：`FF00H`
- 计数器 1 地址：`FF02H`

### 3. 初始化程序

答案区给出了示例程序，主干如下：

```asm
START:
MOV DX, 0FF06H
MOV AL, 00110111B
OUT DX, AL
MOV DX, 0FF00H
MOV AL, 00H
OUT DX, AL
MOV AL, 10H
OUT DX, AL
MOV DX, 0FF06H
MOV AL, 01110111B
OUT DX, AL
MOV DX, 0FF02H
MOV AL, 00H
OUT DX, AL
MOV AL, 20H
OUT DX, AL

```

## 六、静态双功能流水线题答案

题意：向量 `A`、`B` 各有 `4` 个元素，在静态双功能流水线上计算内积。

答案主干：

1. 时空图见：
   - `../images/67859f5f17e68773f1c4607ef0c6782fc4632637e9138049e268b24066ef80f8.jpg`
2. 顺序执行时间：
   - `4 x 3Δt + 3 x 4Δt = 24Δt`
3. 流水线执行时间：
   - `15Δt`
4. 加速比：
   - `Sp = 24Δt / 15Δt = 1.6`
5. 效率：
   - `η = (12 + 8 + 4) / (15 x 5) = 32%`
