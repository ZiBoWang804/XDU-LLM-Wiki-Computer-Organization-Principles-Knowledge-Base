## 四、简单回答题参考答案

### 1. 数据 Cache 中保证数据一致性的方法

答案区稳定保留下来的写策略有：

1. `写回法`
   - CPU 写 Cache 命中时，只写 Cache，不立即写主存
   - 只有当被修改块被替换出去时，才写回主存
2. `全写法`
   - CPU 写 Cache 命中时，同时修改 Cache 和主存
   - 更容易保持主存与 Cache 内容一致

### 2. `8253` 工作方式 `3` 的特点

答案区可稳定恢复出的主干：

- 方式 `3` 是 `方波发生器`
- 可以从 `OUT` 得到对称方波输出
- 当计数值 `N` 为偶数时：
  - 前 `N/2` 计数过程中 `OUT` 为高
  - 后 `N/2` 计数过程中 `OUT` 为低
- 当 `N` 为奇数时：
  - `(N+1)/2` 个计数期间 `OUT` 为高
  - `(N-1)/2` 个计数期间 `OUT` 为低
- 当 `GATE` 为低电平时，强迫 `OUT` 输出高电平
- 当 `GATE` 为高电平时，`OUT` 输出对称方波

### 3. `PCI` 总线的特点

答案区给出的可选要点包括：

1. 高传输性能
2. 总线设备工作与 CPU 相对独立
3. 即插即用
4. 支持设备多主控
5. 错误检测及报告
6. 两种电压环境
7. 两种兼容卡槽

任意写出其中三条即可。

### 4. 硬磁盘容量与传输率

答案区给出的近似结果为：

  - `8.16GB`
- 格式化容量：

  - `18.4MB/s`

### 5. Cache 命中率与平均存取时间

## 六、直接映像 Cache 题答案

答案区稳定保留下来的主干如下：

1. 地址划分：
   - `8KB / 16B = 512` 块
   - Cache 块号 `9` 位
   - 块内地址 `4` 位
   - 主存区号 `6` 位
   - 区内块号 `9` 位
   - 块内地址 `4` 位
2. 第 `513` 块：
   - `513 mod 512 = 1`

3. 主存地址 `04011H`：
