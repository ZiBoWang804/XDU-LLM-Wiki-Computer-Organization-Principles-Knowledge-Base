## 二、填空题参考答案

当前可稳定恢复或高置信补齐的内容如下：

1. 内存与接口地址编址方法：
   - `统一编址`
   - `隔离（独立）编址`
2. 8086 中断系统：
   - 最多 `256` 个中断源
   - 编码长度 `8` 位
   - 该编码称为 `中断类型码`
3. 多核处理器所属结构：
   - `SMP`
4. 题面所给磁盘参数计算结果：
   - 格式化容量约为 `6400000KB`
   - 数据传输率约为 `1920KB/s`
   - 若文件超出一个磁道容量，剩余部分应记录在 `同一柱面的另一磁道上`
   - 说明：这一小题答案区未完整保留，当前结果按题面参数直接计算补出
5. 道密度 / 位密度定义：
   - 道密度：磁盘沿半径方向上单位长度（毫米或英寸）上的磁道数
   - 位密度：磁盘最内磁道上单位长度（毫米或英寸）上记录的二进制位数
6. 动态存储器中的信息：
   - 存放在 `电容器` 上
   - 为防止信息丢失，需要定时 `刷新`
7. `EPROM / EEPROM`：
   - `EPROM` 需用 `紫外线` 擦除
   - `EEPROM` 只需用 `电信号` 擦除
8. 始终保持主存与 Cache 数据一致性的方法：
   - `全写法`
9. 查询 / DMA：
   - 查询方式不能保证数据的 `实时` 传输
   - 传输 `成批数据`
   - 速度最高的方式是 `DMA`

## 三、简答题参考答案

### 1. USB 的特点

答案区给出的可选要点包括：

1. 传输速率高
2. 支持即插即用
3. 支持热插拔
4. 良好的扩展性
5. 可靠性高
6. 统一标准
7. 总线供电
8. 传送距离适中
9. 成本低

写出其中任意三条即可。

### 2. DMA 方式的一般过程

按课程标准过程可恢复为：

1. 外设向 DMA 控制器提出请求。
2. DMA 控制器通过 `HOLD` 向 CPU 请求总线控制权。
3. CPU 在当前总线周期结束后响应，并通过 `HLDA` 让出总线。
4. DMA 控制器获得总线控制权，送出地址，控制内存与接口之间的数据传送。
5. 传送过程中地址自动修改、计数自动减 1。
6. 一批数据传送结束后，DMA 请求撤销，CPU 恢复对总线的控制。

说明：

- 这一题在本卷答案区没有像卷4那样完整保留逐步文字，因此这里采用与题意一致的课程标准表达。

### 3. 8253 在 `1MHz` 下产生 `1s` 周期对称方波

答案区稳定保留下来的主干为：

1. 单个 `16` 位计数器最大计数时间约 `65.5ms`，不足以直接得到 `1s` 周期。
2. 因此需要把 `8253` 的两个计数器串联起来使用。
3. 可将计数器 `0` 的输出接到计数器 `1` 的时钟输入。
4. 使两级总计数值为 `1000 × 1000`。
5. 例如：
   - 计数器 `0` 取 `1000`
   - 计数器 `1` 取 `1000`
6. 由此得到周期为 `1s` 的对称方波。

### 4. `8088 CPU` 执行 `INT 40H` 指令的过程

可恢复的主干为：

1. CPU 识别到这是一条软件中断指令，并得到中断类型码 `40H`。
2. 将断点信息压栈保护。
3. 计算中断向量表入口地址：
   - `40H × 4 = 100H`
4. 从中断向量表中取出对应的 `IP` 和 `CS`。
5. 转入该中断服务程序执行。

### 5. 电子时钟读数误差接近 `1` 小时的情况

答案区稳定保留下来的主干：

1. 当内存中的时间计数处于 `XX:59:59:49` 一类边界时，最容易出现问题。
2. 若主程序在读取“时、分、秒”过程中恰好发生中断，且中断处理程序把时间从 `59分59秒` 进到下一小时，则可能造成主程序先后读到不一致的时分秒组合。
3. 这样就会出现“读出的时间误差接近 1 小时”的情况。
4. 避免方法：
   - 读时先关中断
   - 或采用重复读取并校验一致性的办法

### 6. Cache 命中率与平均存取时间

当前可稳定恢复出的结果：

- 命中率：
  - `24200 / 25000 = 96.8%`
- 平均存取时间：
  - 按题面直接计算：
  - `(24200 × 30ns + 800 × 300ns) / 25000 = 38.64ns`

## 五、Cache-MN 两级存储器题答案

答案区当前可稳定恢复出的内容：

1. 地址划分：
   - 主存区号：`11` 位
   - 区内组号：`1` 位
   - 组内块号：`2` 位
   - 块内地址：`6` 位
   - 参与相联比较的位数：`13` 位
2. 命中判断：
   - 主存地址 `9118H` 命中
   - 对应 Cache 地址为 `1D8H`
   - 主存地址 `0DECBAH` 未命中
3. 若主存以 `64` 字节为一块顺序编号，则第 `515` 块应放在 Cache 的 `0` 组中
