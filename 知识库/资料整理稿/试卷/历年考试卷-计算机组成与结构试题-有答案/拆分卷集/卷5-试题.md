## 二、填空题

每空 `1` 分，本题共 `15` 分。当前可稳定恢复出的题干主干如下：

1. 计算机中，内存与接口地址编址方法有 `______` 和 `______`。
2. 8086 CPU 的中断系统最多可以容纳 `______` 个中断源；每个中断源用一个长度为 `______` 位的编码标识，该编码称为 `______`。
3. 市场上常见到的多核处理器属于 `______` 结构。
4. 设一个有 `2` 个盘片、共 `4` 个记录面的硬盘，转速 `7200` 转/分，盘面有效记录区域外直径 `30cm`、内直径 `10cm`，磁道密度为 `1000道/mm`，每磁道分 `16` 个扇区、每扇区 `1KB`，则该硬盘的格式化容量约为 `______`，数据传输率约为 `______`；若一个文件超出一个磁道容量，剩下部分应记录在 `______`。
5. 磁盘的道密度与位密度定义分别为 `______`。
6. 动态存储器中的信息存放在 `______` 上；为防止信息丢失，需要定时 `______`。
7. `EPROM` 中存储的信息需用 `______` 进行擦除；`EEPROM` 中的信息只需用 `______` 进行擦除。
8. 为始终保持主存与 Cache 的数据一致性，可采用 `______` 法。
9. 在计算机与外设的数据传输中，查询方式不能保证数据的 `______` 传输；而传输 `______` 的速度最高的方式是 `______`。

## 三、简答题

每小题 `4` 分，本题共 `24` 分。当前可稳定恢复出的题干如下：

1. 说明通用串行总线 `USB` 的诸多特点中的三个特点。
2. 叙述利用 `DMA` 方式，在外设需要时将内存中的一批数据连续传送到外设的一般过程。
3. 说明当 `8253` 的外部时钟为 `1MHz` 时，只用该 `8253` 如何产生一个周期为 `1` 秒的连续对称方波。
4. 试说明在 `8088 CPU` 执行 `INT 40H` 指令时的过程。
5. 在 `8088` 系统中，利用定时器每 `20ms` 产生一次中断，在内存中定义若干单元分别对 `1/50秒`、秒、分、小时进行计数来实现电子时钟。试分析在什么情况下，主程序读出的时间误差会接近 `1` 小时；如何避免这种误差。
6. CPU 执行一段程序时，对内存总存取 `25000` 次，其中对 Cache 存取 `24200` 次，对主存存取 `800` 次；已知 Cache 存取时间 `30ns`，主存存取时间 `300ns`，试求 Cache 的命中率及平均存取时间。

## 五、综合题：Cache-MN 两级存储器

本题共 `10` 分，三小题分别约为 `5` 分、`3` 分、`2` 分。题目主干可恢复为：

- `Cache-MN` 两级存储器采用组相联地址映像（组间直接、组内全相联）。
- Cache 容量为 `512B`，每块 `64` 字节，共分 `2` 组。
- 主存容量是 Cache 容量的 `2048` 倍。
- 要求：
  1. 写出主存区号、区内组号、组内块号、块内地址各需要多少位；每次地址变换时需要参与相联比较的位数是多少。
  2. 已知地址变换表，当 CPU 访问主存地址 `9118H` 和 `0DECBAH` 时，判断是否命中；若命中，写出相应的 Cache 地址。
  3. 若主存以 Cache 的 `64` 个字符为一块，从 `0` 块开始顺序分块并编号，试决定第 `515` 块应放在 Cache 的哪一组中。

- 要求利用基本门电路（与门、或门、非门、与非门等）完成：
  - 对 `3-8` 译码器使能端的控制
