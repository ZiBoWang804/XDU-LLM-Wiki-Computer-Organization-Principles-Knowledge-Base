## 二、填空题参考答案

根据答案区当前可稳定恢复出以下内容：

1. `80H` 分别表示整数原码、整数补码、整数反码和整数移码时，其十进制真值分别为：
   - `-0`
   - `-128`
   - `-127`
   - `0`
2. 规格化浮点数中：
   - 数值范围主要取决于 `阶码（指数）`
   - 精度主要取决于 `尾数`
3. 用 `2K×4bit` 芯片构成从 `0000H` 开始的 `8K×8bit` 存储器时，地址 `081FH` 所在芯片的最小地址：
   - 当前答案区未直接给出
   - 按题面可直接计算，应为 `0800H`
4. 存储系统中：
   - 采用高速缓冲存储器的目的是 `解决主存与 CPU 之间的速度匹配问题`
   - 采用虚拟存储器的目的是 `扩大内部存储器的地址空间`
5. `RAID` 的三种主要技术：
   - `条带化`
   - `镜像`
   - `校验`
6. 互连网络是由：
   - `高速开关元件`
   按照一定拓扑结构和控制方式构成的网络
7. 计算机流水线中的数据相关包括：
   - `写后读（RAW）`
   - `读后写（WAR）`
   - `写后写（WAW）`
8. Amdahl 定律题结果：
   - `1.5625`
   - 亦可写作 `25/16` 或 `1/0.64`
9. CPU 响应请求的时机：
   - 中断请求发生在 `指令周期` 结束时
   - DMA 请求发生在 `CPU 周期（或总线周期）` 结束时
10. 扩展操作码题结果：
   - 单地址指令最多 `256` 条

## 三、直接映像 Cache 题答案

答案区可恢复出的主干如下：

1. 地址划分：
   - 主存区号：`6` 位
   - 区内块号：`9` 位
   - 块内地址：`4` 位
   - 由题设可进一步推出 Cache 共 `512` 块
2. 主存中顺序排列的第 `1024` 块：
   - 是第 `02H` 区的第 `0` 块
   - 按直接映像应装入 Cache 的第 `0` 块
3. 主存地址 `02001H`：
   - 属于第 `01H` 区的第 `0` 块
   - 对应 Cache 的第 `0` 块
   - 但与上一步中的第 `1024` 块不属于同一区
   - 因而在“先装入第1024块”的前提下，此次访问 `不命中`

## 六、磁盘访问时间题答案

当前可稳定恢复出的答案主干：

1. 若文件数据连续分布：
   - 访问第 1 个磁道：
     - `平均寻道 + 平均旋转延迟 + 512 个扇区数据传输时间`
     - `4ms + 2ms + 4ms = 10ms`
   - 访问其余每个磁道：
     - `平均旋转延迟 + 512 个扇区数据传输时间`
     - `2ms + 4ms = 6ms`
   - 总时间：
     - `10ms + 6ms × 4 = 34ms = 0.034s`
2. 若文件数据随机分布：
   - 每个扇区访问时间：
     - `4ms + 2ms + 0.008ms = 6.008ms`
   - 文件共约 `2560` 个扇区
   - 总时间：
     - `6.008ms × 2560 = 15.38048s`
3. 结论：
   - `数据在磁盘扇区上的分布情况对 I/O 读取性能有很大影响`

### 2. 原流水线的加速比与效率

- 顺序执行时间：
  - `4 × 4Δt + 3 × 3Δt = 25Δt`
- 答案区对流水线总时间给出了两个近邻口径：
  - `T = 17Δt`
  - 或 `T = 16Δt`
- 对应可恢复为：
  - `Sp = 25Δt / 17Δt ≈ 1.47`
  - 或 `Sp = 25Δt / 16Δt ≈ 1.56`
  - `η = 25 / (17 × 4) ≈ 36.76%`
  - 或 `η = 25 / (16 × 4) ≈ 39.06%`

### 3. 细分瓶颈段后的加速比与效率

- 答案区给出的主结果为：
  - `Sp = 25Δt / 14Δt ≈ 1.78`
  - `η = 25 / (14 × 5) ≈ 35.7%`
- 另附一条备选口径：
  - 若按 `13Δt` 计算，则 `η ≈ 38.46%`
