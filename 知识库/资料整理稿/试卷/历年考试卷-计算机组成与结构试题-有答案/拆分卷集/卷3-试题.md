## 一、单项选择题

本题共 `5` 分，每小题 `1` 分。

当前可较稳定恢复出的题目如下：

1. 在计算机中，CPU 对其访问速度最快的是 `______`。
   - 选项：`主存` / `Cache` / `CPU中的通用寄存器` / `硬磁盘`
2. 第 2 题题干 OCR 缺失严重，但从选项看，是一道关于机器数 `80H` 真值判断的单项选择题。
   - 选项：`-1` / `-127` / `-0` / `-128`
3. 某浮点数字长 `16` 位，其中阶码与尾数分别采用给定编码方式时，该浮点数所能表示的数值范围为 `______`。
4. 若 Cache 的存取时间为 `10ns`，主存的存取时间为 `100ns`，系统平均存取时间为 `14.5ns`，则 Cache 的命中率为 `______`。
5. 程序计数器 `PC` 的位数决定了 `______`。

说明：

- 第 `2` 题题干未被完整保留，因此这里只把它记为“机器数 `80H` 真值判断题”。

## 二、典型题

每小题 `1` 分，本题共 `15` 分。当前可稳定恢复出的题干主干如下：

1. 计算机中设置 Cache 的依据是 `______`。
2. 若有效信息 `M(x)=1011010`，若要构成具有“纠正 1 位错”能力的校验码，则应增加 `______` 位校验码。
3. 采用多体交叉存储器的目的是为了 `______`。
4. `RAID` 的中文称为 `______`。
5. 多机系统互连网络中用到的 `2×2` 开关有 `______`、`______`、`______`、`______` 四种连接方式。
6. 在内存中若要设计一个存放引导程序的存储区，实现该存储区的存储器类型应连接为 `______`。
7. 在 `Cache-MM` 两段存储体系中，提高 Cache 的命中率，可以使该存储体系的 `______` 指标提高。
8. 一个慢速外设在满足一定条件时与计算机系统进行信息交换，如果希望 CPU 既有较高工作效率又能及时响应外设 I/O 要求，则 I/O 方法应选 `______`。
9. `EPROM` 芯片擦除干净的标志为 `______`。
10. 计算机流水线中，数据相关主要包括 `______`、`______` 和 `______` 三种情况。
11. 浮点数中，`n` 位（包括 `1` 位符号位）原码表示的规格化负尾数的数值范围是 `______`。
12. 若 `80H` 分别表示整数原码、整数补码和整数移码时，则其对应的十进制真值分别为 `______`、`______`、`______`。
13. 构成 `32K×8bit` 内容，选用容量分别为 `1K×4bit`、`4K×8bit` 的芯片，则分别需要 `______` 片、`______` 片。
14. 一个汉字的内码由 `______` 位二进制数表示。
15. `8` 位整数原码的取值范围是 `______`。

## 三、简答题

每小题 `5` 分，本题共 `30` 分。题目主干可恢复为：

1. 画出集中式独立请求总线仲裁方式示意图，并说明其工作原理。
2. 若某磁盘有 `2` 个记录面，外径 `10cm`，内径 `2cm`，道密度为 `100道/mm`，每磁道有 `32` 个扇区、每扇区 `512B`，求该磁盘的容量。
3. CPU 执行一段程序，共完成对内存的存取 `25000` 次，其中对 Cache 的存取为 `24200` 次，对主存的存取为 `800` 次；若 Cache 存取时间为 `30ns`，主存存取时间为 `300ns`，试求 Cache 命中率及平均存取时间。
4. 设浮点数 `X = 0.110101 × 2^-2`、`Y = -0.101010 × 2^-1`，字长 `12` 位，阶码 `4` 位，尾数 `8` 位；若阶码、尾数均用双符号补码表示，按浮点运算步骤计算 `X + Y`。
5. 说明高速 `RISC`（精简指令系统计算机）的主要特点。
6. 画一种对称多处理机框图，并说明其主要特点。

## 四、综合题：全相联 Cache 地址变换

本题 `10` 分。题目主干可恢复为：

- 高速缓存 Cache 与主存间采用 `全相联` 地址映像方式。
- Cache 容量为 `4KB`，分为 `4` 块，每块 `1KB`。
- 主存容量为 `1MB`。
- 给出地址变换表。
- 要求：
  1. 当主存地址为 `654E2H` 时，写出对应高速缓存地址。
  2. 当主存地址为 `D9D9DH` 时，写出对应高速缓存地址。
  3. 说明如何完善该地址变换表；该表应采用什么器件实现；容量多大。

## 五、综合题：SRAM 扩展存储器连接

本题 `10` 分。题目主干可恢复为：

- 给出某 `SRAM` 芯片引脚图，芯片可见信号包含：
  - `D0~D7`
  - `A0~A14`
  - `OE`
  - `WE`
  - `CS`

## 六、综合题：5 级指令流水线

本题 `10` 分。题目主干可恢复为：

- 某 `5` 级（段）指令流水线，各段运行时间均为 `1ns`。
- 要求：
  1. 若流水线连续执行 `100` 条无分支指令，求实际吞吐率、加速比与效率。
  2. 若执行的 `100` 条指令中有 `10%` 为分支指令，且流水线未采取解决控制相关的策略，求执行这 `100` 条指令的实际加速比。

## 七、综合题：微操作相容性与减法指令流程

本题 `10` 分。题目主干可恢复为：

- 给出某计算机系统框图，图中含 `R0`、`R1`、`R2`、`PC`、`IR`、`MAR`、`MDR`、`A`、`B`、`X`、`Y`、`ALU`、`C` 等部件。
- 题面说明：
  - 寄存器用 `XXin` 锁存数据，用 `XXout` 控制数据输出
  - ALU 具有 `ADD`、`AND`、`OR` 功能
  - 另有 `1→Σ`、左移、右移等控制信号
- 要求：
  1. 判断若干组控制信号之间是“相容”还是“互斥”。
  2. 写出减法指令 `SUB R1, mem_addr` 的微操作流程及相应微命令流程。

## 八、综合题：扩展操作码设计

本题 `10` 分。题目主干可恢复为：

- 某指令系统共有 `200` 条指令。
- 统计结果显示：
  - 传送类指令占 `5%`，使用频度 `50%`
  - 运算类指令占 `10%`，使用频度 `25%`
  - 分支类指令占 `20%`，使用频度 `15%`
  - 其余指令使用频度 `10%`
- 要求：
  1. 给出定长操作码的最短长度。
  2. 试用扩展操作码技术为各类指令设计操作码，并给出每类指令操作码的最短长度。
  3. 计算两种编码情况下的平均操作码长度。
