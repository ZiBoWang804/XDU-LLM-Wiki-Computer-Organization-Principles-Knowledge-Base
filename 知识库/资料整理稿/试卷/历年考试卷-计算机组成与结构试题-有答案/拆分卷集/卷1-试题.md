## 一、填空题

当前可稳定恢复出的题目主干如下：

1. 在主存和 CPU 之间增加 Cache 存储器的目的 / 依据是什么。
2. Cache 工作中，常用的数据一致性方法有哪两种。
3. 计算机中，内存与接口地址编址有哪两种方式。
4. 若要使多个中断源具有相同优先级，可采用什么方法实现。
5. RAID2 的含义是什么。
6. 磁盘中道密度、位密度的定义分别是什么。
7. 计算机系统中常见的磁盘接口总线有哪些。
8. 构成多机系统互连网络时，2×2 开关有哪四种连接状态。
9. 流水线中的数据相关主要包括哪些类型。
10. 内总线 / 系统总线中常见的标准有哪些。
11. 8086 CPU 响应 `INTR` 请求需要同时满足哪些条件。
12. 异步串行通信中，每传送一个字符时，总是先发送低电平的启动位，再发送数据位；数据位按“低位在前、高位在后”发送，最后发送高电平的停止位。
13. 8253 有几个独立计数器；每个计数器是多少位；最大计数值是多少。
14. 8255 有几种工作方式；C 口按位操作通过什么寄存器/控制字实现。
15. 接口与外设之间有哪几类信号。
16. 市场上常见的多核处理器属于什么结构。

## 三、综合题：Cache 与主存两级存储器地址映像

本题约 `10` 分。

题目主干：

- Cache 与主存之间采用组相联地址映像方式（组间直接、组内全相联）。
- 按当前 OCR 与答案区交叉恢复，题设高置信主干为：
  - Cache 容量约为 `512B`
  - 每块约为 `64B`
  - Cache 共分 `2` 组
  - 主存容量约为 Cache 容量的 `2048` 倍
- 题面给出了地址变换表。
- 要求：
  1. 写出主存区号、区内组号、组内块号、块内地址各占多少位。
  2. 判断给定主存地址是否命中，并给出相应 Cache 地址。
     - 第一组地址可稳定辨识为 `9118H`
     - 第二组地址串存在 OCR 污染，当前可见近似为 `OECDBAH / OEDCBAH`

## 四、综合题：中断方式 / DMA 方式时间占比

本题约 `10` 分。

题目主干：

- 某计算机 CPU 主频与平均 CPI 已知。
- 当前可高置信恢复到：`CPU 主频 500MHz`，平均每条指令约 `5` 个时钟周期。
- 某外设数据传输速率已知。
- 采用中断方式时：
  - 外设数据传输速率约 `0.5MB/s`
  - 以 `32` 位为传送单位
  - 中断服务程序含 `18` 条指令
  - 另有相当于 `2` 条指令的额外开销
- 采用 DMA 方式时：
  - 外设数据传输速率提高到约 `5MB/s`
  - 每次 DMA 传送数据块约 `5000B`
  - DMA 预处理与后处理总开销约 `500` 个时钟周期
- 要求分别计算：
  1. 中断方式下 CPU 用于该外设 I/O 的时间占比
  2. DMA 方式下 CPU 用于该外设 I/O 的时间占比
