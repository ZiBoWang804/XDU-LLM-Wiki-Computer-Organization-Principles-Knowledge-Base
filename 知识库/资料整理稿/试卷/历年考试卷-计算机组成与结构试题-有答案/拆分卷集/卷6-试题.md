## 一、单项选择题

每小题 `2` 分，本题共 `20` 分。当前可稳定恢复出的题目如下：

1. 若某中断的中断类型码为 `0AH`，则其中断向量表的首地址为多少。
2. `PSW` 中某标志位为 `0` 时，`8086` CPU 不响应的是哪类中断请求。
3. 内存从 `B8000H` 到 `DBFFFH`，共有多少容量。
4. 采用中断方式来实现输入输出是因为它具有什么特点。
5. 在主存与 CPU 之间增加高速缓存 Cache 的目的是什么。
6. `8086` CPU 构成内存时，内存需分为几个体。
7. 在计算机中，CPU 对其访问速度最快的是什么。
8. 掉电后，下面哪种说法正确。
9. 支持即插即用、热插拔的总线是哪一种。

说明：

- OCR 中单项选择题编号有轻微错位，但题干整体仍可恢复。

## 二、填空题

本题共 `10` 分。当前可稳定恢复出的题干主干如下：

1. `8086 CPU` 的中断系统最多可以容纳 `______` 个中断源；每个中断源用一个长度为 `______` 位的编码标识，该编码称为 `______`。
2. 相联存储器不按地址访问存储器，而是按 `______` 访问存储器。
3. 在市场上所见到的多核处理器是属于 `______` 结构。
4. Cache 工作中，替换算法有多种，其中有 `______` 算法和 `______` 算法。
5. 在主存采用多体存储器的目的是 `______`。
6. 磁盘的道密度定义为 `______`；位密度定义为 `______`。

## 三、判断题

每小题 `2` 分，本题共 `10` 分。当前可稳定恢复出的题干如下：

1. `EEPROM` 的内容可以利用紫外线照射擦除干净。
2. 在可编程并行接口 `8255` 中，利用将 `C` 口的按位操作控制字写入 `C` 口，可实现对 `C` 口的按位操作。
3. `8086 (88)` 某条与中断响应条件相关的说法。
4. 在 `8086` 微机系统中，可用多个主控中断控制器 `8259` 和多个从属中断控制器 `8259` 相连接，构成可管理多个外部中断源的中断系统。
5. `8086 CPU` 是 `16` 位微处理器，因此一个总线周期就一定能将一个 `16` 位字写入内存。

说明：

- 第 3 小题题面残缺，只能确认与 `8086/8088` 的中断响应条件有关。

## 四、简单回答题

每小题 `4` 分，本题共 `20` 分。当前可稳定恢复出的题干如下：

1. 说明在数据 Cache 中，保证数据一致性的方法。
2. 叙述可编程定时器 `8253` 工作方式 `3` 的特点。
3. 说明 `PCI` 总线诸多特点中的三个特点。
4. 某硬磁盘有 `5` 个记录面，有效记录区域内径 `2cm`、外径 `12cm`，位密度为 `2600B/mm`，道密度为 `1000 道/mm`，每磁道分 `64` 个扇区、每扇区记录 `2.4KB`，磁盘转速 `10000` 转/分。求其非格式化容量、格式化容量和数据传输率。
5. CPU 执行一段程序，共完成对内存的存取 `25000` 次，其中对 Cache 的存取为 `24200` 次，对主存的存取为 `800` 次；已知 Cache 存取时间 `30ns`，主存存取时间 `300ns`，试求 Cache 的命中率及平均存取时间。

## 六、综合题：直接映像 Cache

本题共 `10` 分，三小题分别约为 `5` 分、`3` 分、`2` 分。题目主干可恢复为：

- 设一直接映像方式的 Cache，容量为 `8KB`，以 `16B` 分块。
- 主存储器容量为 `512KB`。
- 要求：
  1. Cache 分为多少块；块号及块内地址各为多少位；主存地址应如何划分。
  2. 主存中顺序排列的第 `513` 块内容应调入 Cache 的哪一块。
  3. 在上一步基础上，若第 `513` 块内容已调入，试说明主存地址 `04011H` 时是否命中。
