# 2026 春计组 1 二进制数值计算习题课：题目版

# 统一约定

1. 定点乘法题中，“6位乘6位”指两个操作数的数值部分均为6位；原码乘法的符号位单独处理，补码乘法的机器字长为 6 位。  
2. 定点除法题中，“8位除4位”指被除数数值部分为8位、除数数值部分为4位，商取4位。  
3. 除法题可将 4 位除数左移 4 位后参与表格计算；最后把小数点放回去。  
4. 普通浮点格式题采用基值为 2 的浮点数，阶码和尾数位数按题目给定。  
5. 正式术语统一写作“原码”和“IEEE 754”。  
6. 要求写出完整、具体的运算过程，乘除法题尽量采用表格形式。

# 1. 原码一位乘法

设 $\ x = - 0 . 1 0 0 1 1 1$ ，y=+0.101011，用原码一位乘法求 x\*y。要求写出每一步部分积。

# 2. 原码两位乘法

设 $\mathsf { x } { = } { + } \mathsf { 0 } , \mathsf { 1 } 1 0 1 0 1$ ，y=-0.011011，用原码两位乘法求 x\*y。要求按两位乘数分组列出部分积。

# 3. 补码 Booth 小数乘法

设机器字长为 6 位，采用补码定点小数表示，其中最高位为符号位、后 5 位为小数位。已知 x=-0.10110，$y = + 0 . 0 1 1 0 1$ ，用 Booth 一位乘法求 x\*y。

# 4. 原码恢复余数法除法

设 x=-0.10110110，y=+0.1101，用原码恢复余数法求 x/y，商取 4 位。

# 5. 原码加减交替法除法

设 $\mathsf { x } = + \mathsf { 0 } . 1 0 0 1 1 1 0 1$ ，y=+0.1011，用原码加减交替法求 x/y，商取 4 位。

# 6. 补码加减交替法除法

设 $\mathsf { x } = + \boldsymbol { \mathsf { 0 } } . 0 1 1 1 0 1 1 0$ ，y=+0.1010，用补码加减交替法求 x/y，商取 4 位。

# 7. 普通浮点格式乘法

设浮点数字长 12 位，阶码 4 位（含 1 位阶符），尾数 8 位（含 1 位数符）。阶码和尾数均用补码表示，基值为2，尾数为规格化补码小数。已知：

$$
x = 2 ^ {\wedge} (+ 3) * (+ 0. 1 0 1 1 0 0 0)
$$

$$
y = 2 ^ {\wedge} (- 2) * (- 0. 1 1 0 0 0 0 0)
$$

求x\*y 的浮点表示。

# 8. 普通浮点格式除法

设浮点数字长 12 位，阶码 4 位（含 1 位阶符），尾数 8 位（含 1 位数符）。阶码和尾数均用补码表示，基值为 2，尾数为规格化补码小数。已知：

$$
x = 2 ^ {\wedge} (+ 1) * (- 0. 1 1 0 0 0 0 0)
$$

$$
y = 2 ^ {\wedge} (- 2) * (+ 0. 1 0 0 0 0 0 0)
$$

求x/y 的浮点表示。

# 9. IEEE 754 单精度浮点乘法

用 IEEE 754 单精度格式计算 (-13.5) \* (+0.75)，写出符号、阶码、尾数和最终 32 位机器数。

# 10. IEEE 754 单精度浮点除法

用 IEEE 754 单精度格式计算 (+10.5) / (-0.75)，写出符号、阶码、尾数和最终 32 位机器数。
