# 图7-30 直接映射方式示意图

## 图像类型
- 地址映射示意图

## 教材中的作用
- 说明直接映射方式下，主存要先分区，每个区中相同块号的主存块只能装入 cache 中相同块号的位置。

## 图中结构 / 读取要点
- 左侧是 cache，块号固定为 `000` 到 `111`。
- 右侧主存先分成许多区，从第 0 区到第 2047 区，每个区内再分成第 0 块到第 7 块。
- 图中连线强调：每个区的第 0 块只能装入 cache 第 0 块位，每个区的第 7 块只能装入 cache 第 7 块位，其余块也一一对应。
- 这张图体现的是“位置固定”的映射法则，而不是任意装入。

## 该图支撑的知识点
- 直接映射
- 主存分区
- 同号块固定装入同号 cache 块位
- 直接映射查找简单但会发生块位竞争
