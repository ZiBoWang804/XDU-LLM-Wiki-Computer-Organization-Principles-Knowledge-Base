# 图7-28 全相联地址映射

## 图像类型
- 地址映射示意图

## 教材中的作用
- 说明全相联方式下，主存任一块都可以装入 cache 任一块，映射关系最灵活。

## 图中结构 / 读取要点
- 左侧是 cache，共 8 块，块号为 `000` 到 `111`。
- 右侧是主存，示意为从第 0 块到第 16383 块。
- 连线表达的不是固定对位关系，而是“主存任一块都可装入 cache 任一块”。
- 因为没有固定位置，对应的主存块号必须通过相联方式记录和检索。

## 该图支撑的知识点
- 全相联地址映射
- 主存任意块到 cache 任意块
- 映射灵活但检索代价高

## 检索关键词
- 全相联地址映射
- 全相联映射
- 主存任意块到cache任意块
- cache块号000到111
- 主存16384块
