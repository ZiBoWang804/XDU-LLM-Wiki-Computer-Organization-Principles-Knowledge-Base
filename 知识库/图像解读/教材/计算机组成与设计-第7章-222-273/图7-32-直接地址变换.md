# 图7-32 直接地址变换

## 图像类型
- 地址变换流程图

## 教材中的作用
- 用具体例子说明直接映射方式下，主存地址如何分成区号、块号和块内地址，并据此完成命中判断和 cache 地址形成。

## 图中结构 / 读取要点
- 图中把主存地址分为三部分：主存区号 `11位`、块号 `3位`、块内地址 `12位`。
- 块号直接指出 cache 中的块位，例如图中的 `101` 直接对应 cache 第 `101` 号块位。
- 相联存储器中保存的是该块位当前对应的主存区号，例如图中的 `516H`。
- 访问时，先用块号选中 cache 对应块位，再把主存区号与该块位相联存储器中保存的区号比较；相等则命中，不等则未命中。
- 命中后，主存地址中的块号与块内地址可直接组成 cache 地址。

## 该图支撑的知识点
- 直接映射地址变换
- 主存区号、块号、块内地址的分工
- 块号定位、区号判别
- 相联存储器在直接映射中的作用
