# 图7-27 cache的组成

## 图像类型
- 结构图

## 教材中的作用
- 用图示把 cache 系统拆成替换管理模块、相联存储表和高速缓存体三部分，支撑 `cache 的构成` 与 `命中/未命中流程` 的讲解。

## 图中结构 / 读取要点
- 左侧是 CPU，右侧是主存，中间是 cache 系统。
- CPU 地址一方面送往主存，另一方面送往相联存储表，用于判断访问信息是否已经在 cache 中。
- 相联存储表上方连接替换管理，表示未命中时需要由替换管理决定换出哪一块。
- 中间下部是高速缓存 `cache`，它与主存之间进行块级信息交换，并通过数据总线向 CPU 提供命中数据。
- 这张图强调：cache 不是只有“缓存体”，而是“缓存体 + 标记/相联存储表 + 替换管理”共同构成的系统。

## 该图支撑的知识点
- cache 的基本组成
- 相联存储表的作用
- 命中与未命中的工作流程
- 主存块调入 cache 时需要替换管理
