# 图8-46 周期的挪用示意图

## 图像类型
- 时序分配示意图

## 教材中的作用
- 说明 DMA 常用方法中的“固定挪用周期”方案：在 CPU 的取指周期里预留一段时间给 DMA 传送。

## 图中结构 / 读取要点
- 教材说明该 CPU 的取指令操作码周期一共 4 个时钟周期。
- 其中一部分时间由 CPU 用来取指令，另一部分时间被专门留给 DMA。
- 这种方法的关键不是“强行暂停 CPU”，而是利用 CPU 设计时本就可挪出的总线空档。

## 该图支撑的知识点
- DMA 常用方法
- 固定挪用周期
- 取指周期中腾出 DMA 时间
