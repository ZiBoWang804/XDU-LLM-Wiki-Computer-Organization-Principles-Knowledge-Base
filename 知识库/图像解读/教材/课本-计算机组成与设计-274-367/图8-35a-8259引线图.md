# 图8-35(a) 8259引线图

## 图像类型
- 芯片引线图

## 教材中的作用
- 用于说明 8259 在硬件连接层面有哪些关键引线，以及这些引线如何参与数据交换、中断请求、级联和主从控制。

## 图中结构 / 读取要点
- 图中包含 8259 与系统总线、中断系统直接相关的核心引线。
- 教材在此图后重点解释：
  - `D0~D7` 为双向数据线
  - `WR/RD` 为读写控制
  - `CS` 为片选
  - `A0` 用于内部寄存器选择
  - `INT` 接 CPU 的 `INTR`
  - `INTA` 接收 CPU 的中断响应
  - `CAS0~CAS2` 与 `SP/EN` 用于级联和主从控制
  - `IR0~IR7` 为外部中断请求输入端

## 该图支撑的知识点
- 8259 外部引线功能
- 8259 与 CPU、中断源、系统总线的接口关系
- 级联和主从配置
