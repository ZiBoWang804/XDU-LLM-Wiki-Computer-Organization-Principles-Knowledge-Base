# 图8-48 CPU与DMA分时工作示意图

## 图像类型
- 分时示意图

## 教材中的作用
- 说明 CPU 与 DMA 交替分时工作这一类 DMA 方法，即把时间切成片，一片给 CPU，一片给 DMA。

## 图中结构 / 读取要点
- 图中强调总线时间被切分给两个控制者轮流使用，而不是谁长期独占。
- 教材评价这种方式实现较简单，但当 DMA 不需要工作时，某些分给 DMA 的时间片可能造成总线闲置。

## 该图支撑的知识点
- CPU 与 DMA 交替分时工作
- 分时让出总线
- 实现简单但可能降低总线利用率
