# CRC编码与接收端校验示例

## 页面类型

- 课件例题重排稿

## 来源作用

- 对应课件原页约第 `41` 到 `45` 页。
- 原课件在 OCR 后，模 2 除法表格和例题步骤容易粘连，这里把 CRC 示例按顺序重排成可直接检索和复用的 Markdown。

## 规则重排

- 发送端：
  - 被校验数据除以生成多项式
  - 用所得余数构造发送编码字
- 接收端：
  - 接收数据再除以生成多项式
  - 若可整除，则当前校验通过
  - 若不可整除，则说明接收数据存在差错
- 课件同时强调：
  - 采用模 2 算术运算
  - 通过模 2 减法实现模 2 除法
  - 以模 2 加法把余数拼接到被校验数据后面

## 课件例题重排

### 已知条件

- 信息字：`F = 1001010₂`
- 生成多项式：`G = 1011₂`
- 对应多项式形式：`G(X) = X^3 + X + 1`

### 发送端编码步骤

1. 因为 `G` 为 4 位，所以校验位长度为 `3` 位
2. 将 `F` 左移 `3` 位，得到：
   - `F' = 1001010000₂`
3. 用 `F'` 做被除数、`G` 做除数，进行模 2 除法
4. 忽略商，课件给出的余数为：
   - `R = 111₂`
5. 把余数加到 `F'` 中，得到发送信息：
   - `M = 1001010000₂ + 111₂ = 1001010111₂`

### 接收端校验

- 接收端对 `M` 再次用 `G` 做模 2 除法
- 正确情况下：
  - `M` 应该可以被 `G` 严格整除
- 若发生 1 位错误：
  - 课件通过对比“正确情况 / 1 位出错情况”说明校验结果会发生变化
  - 当前稳定可采用的结论是“不能整除则表示检测到差错”
