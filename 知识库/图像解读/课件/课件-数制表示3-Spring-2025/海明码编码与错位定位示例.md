## 例题重排

### 已知条件

- 原始 8 位 ASCII 字符：`M`
- 最高位取 `0`
- 因而数据位为：`01001101`
- 采用偶校验

### 发送端编码

1. 先假定 `H0 ~ H3 = 0`
2. 按课件中的校验关系计算：
   - `P0 = D6 ⊕ D4 ⊕ D3 ⊕ D1 ⊕ D0 ⊕ H0 = 1`
   - `P1 = D6 ⊕ D5 ⊕ D3 ⊕ D2 ⊕ D0 ⊕ H1 = 0`
   - `P2 = D7 ⊕ D3 ⊕ D2 ⊕ D1 ⊕ H2 = 0`
   - `P3 = D7 ⊕ D6 ⊕ D5 ⊕ D4 ⊕ H3 = 1`
3. 用 `Pi` 替代对应的 `Hi`，得到编码字：
   - `C = D7 D6 D5 D4 H3 D3 D2 D1 H2 D0 H1 H0`
   - `C = 010011100101`

### 接收端判断规则

- 若综合校验结果 `P` 全为 `0`：
  - 表示接收到的编码字没有错误。
- 若 `P` 中有多位为 `1`：
  - 表示某一数据位出错；
  - `P` 的二进制值就是错误位在编码字中的位置编号。
- 若 `P` 中有且仅有一位为 `1`：
  - 表示某一校验位出错；
  - 一般无需纠正数据位。

### 课件中的两个典型接收端例子

#### 情况 1：数据位出错

- 若接收到的编码字为：`011011100101`
- 课件计算结果：
  - `P = 1010`
- 结论：
  - 编码字第 `10` 位出错，对应数据位 `D5`
  - 将该位取反即可纠错

#### 情况 2：校验位出错

- 若接收到的编码字为：`010011101101`
- 课件计算结果：
  - `P = 0100`
- 结论：
  - 编码字第 `4` 位出错，对应校验位 `H2`
  - 这是校验位出错，不需要纠正数据位
