# CPU设计

> 覆盖 CPU 结构、功能、执行过程、控制器与部件设计，并连接到 EDA/VHDL 的实现层。

## 专题边界

本专题优先聚焦：

- CPU 由哪些核心部件组成
- CPU 如何执行指令
- 控制器如何设计
- CPU 的部件如何展开到实现层

## 易混点

- `CPU 的结构` 讲组成，`CPU 执行指令的过程` 讲动态行为，`CPU 的部件设计` 讲实现展开，三者不是同一层级。
- `组合逻辑控制器` 与 `微程序控制器` 是控制器设计的两条典型路线，需要并列比较。
