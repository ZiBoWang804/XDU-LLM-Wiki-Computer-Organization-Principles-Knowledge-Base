# 标准化答题模板

> 本页不是知识点正文，而是面向期末题的书写模板。目标是：老师看得懂、步骤不缺、分点明确、容易检查。

## 通用书写顺序

1. `题意重述`
2. `已知条件`
3. `分析 / 解题思路`
4. `分步计算或分步推导`
5. `结果写回`
6. `结论 / 功能说明`

## 推荐固定句式

- `已知：……`
- `由题意可得：……`
- `先……，再……，最后……`
- `因此：……`
- `所以最终结果为：……`
- `故该程序 / 该指令 / 该结构的功能是：……`

## 题型模板

### 1. 补码变形 / 码制题

- 先写编码类型：原码 / 反码 / 补码 / 移码
- 再写真值或符号判断
- 再做：`[-X]`、`[X/2]`、`[2X]`
- 最后回写机器数并检查是否溢出

### 2. 浮点表示范围题

- 先写清格式：基值、阶码位数与编码方式、尾数位数与编码方式
- 再分开求：尾数范围、阶码范围、最大 / 最小正负数
- 结果一定写成“规格化表达式”或题目要求的码值

### 3. Booth 乘法 / 交替除法

- 必写初值
- 必须把每一步按表格形式写出
- 表格列建议优先贴近课件口径：`D / Y / Y0 / Y-1 / 操作说明`
- 若一轮中既有“加 / 减”又有“右移”，建议拆成两行，先写本轮操作，再写右移后的新状态
- 必写每轮操作
- 必写商位或判别位依据
- 最后恢复小数点与符号

### 4. 寻址与汇编功能题

- 先判寻址方式名称
- 再求 `EA`
- 必要时再求 `PA`
- 程序功能题必须拆成：初始化 / 循环主体 / 输出结果

### 5. 微指令格式题

- 先逐字段算位数
- 明确是否预留全零空操作状态
- 再算条件控制字段
- 最后回推次地址位数和控存容量

### 6. 微操作流程题

- 一律分：取指 / 取操作数 / 执行 / 写回
- 若课程课件已采用英文阶段名，优先按 `Fetch / Fetch Operands / Execute / Store` 分段书写
- 段内步骤应尽量贴近课件数据通路展开方式，如：`PC->AR`、`AR->AB`、`AB->MAR`、`Read(MM->MDR)`、`MDR->DB`、`DB->DR`
- 若题目或老师更偏好时序节拍写法，再把各段步骤整理为 `T1/T2/T3/...`

### 7. Cache 映射题

- 先求位数划分
- 再判断命中
- 最后写 Cache 地址或平均访问时间

### 8. 磁盘容量 / 传输率题

- 先统一单位：`cm / mm / KB / MB / bit / Byte`
- 先分清是 `非格式化容量`、`格式化容量` 还是 `传输率`
- 若求非格式化容量，先求总磁道数与单磁道记录量
- 若求格式化容量，优先按“每磁道扇区数 × 每扇区容量 × 记录面数 × 磁道数”
- 若求传输率，再用“每转数据量 × 每秒转数”
- 若题目问“超过一个磁道后写到哪里”，单独写结论

### 9. 8253 定时 / 方波 / 波形题

- 先写输入时钟频率和时钟周期
- 再求目标总计数值
- 若单计数器不够，明确写出级联关系
- 必写工作方式
- 波形题必须标出周期、脉宽和高低电平区间
- 程序题要把控制字、端口地址、初值装入顺序写清

### 10. 8255 接口连接 / 控制程序题

- 先说明哪个口位接输入，哪个口位接输出
- 再说明地址线、数据线、片选线、读写控制线
- 若题目要求“画图”，优先画成可直接照抄的图答案
- 程序按 `读输入 -> 掩码/比较 -> 分支 -> 输出 -> 回跳` 写
- 若题目明确说 `8255` 已初始化，不要平白多写初始化

## 高频失分点

- 只写结果，不写步骤
- 公式会背，但不代数值
- 只写 `EA`，忘写 `PA`
- 程序功能题只写一句话，不拆初始化 / 循环 / 输出
- 微操作题只写执行阶段，不写取指
- Cache 题把主存块号和 Cache 块号混成一件事
