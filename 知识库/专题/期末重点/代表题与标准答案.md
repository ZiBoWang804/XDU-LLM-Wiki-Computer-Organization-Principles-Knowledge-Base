## 1. 8 位补码变换题

来源：
- [历年考试卷-计组2022](../../资料整理稿/试卷/历年考试卷-计组2022/历年考试卷-计组2022.md)

对应题型：
- [QT-C02-001 码制转换与表示范围题](../../题型/QT-C02-001-码制转换与表示范围题.md)

题目：
- 机器字长为 8 位，已知 `[X]补 = 11001010`，求 `[2X]补`、`[X/2]补` 和 `[-X]补`。

标准作答：
1. 先由补码求真值。`11001010_2 = CAH`，其真值为 `-54`。
2. `2X = -108`，仍在 8 位补码表示范围内，因此 `[2X]补 = 10010100_2`。
3. `X/2 = -27`。按补码算术右移或按真值回写，得 `[X/2]补 = 11100101_2`。
4. `-X = 54`，故 `[-X]补 = 00110110_2`。

结论：
- `[2X]补 = 10010100`
- `[X/2]补 = 11100101`
- `[-X]补 = 00110110`

易错点：
- 负数除以 2 时把补码右移做成逻辑右移。
- 不先还原真值，直接对位串机械“变形”。

## 2. 8088 寻址结果题

来源：
- [历年考试卷-计组2020](../../资料整理稿/试卷/历年考试卷-计组2020/历年考试卷-计组2020.md)

对应题型：
- [QT-C04-001 寻址方式判定与有效地址计算题](../../题型/QT-C04-001-寻址方式判定与有效地址计算题.md)

题目摘要：
- `(DS)=2000H`，`(BX)=0100H`，`(SI)=0002H`
- `(20100H)=12H`，`(20101H)=34H`，`(20102H)=56H`，`(20103H)=78H`
- `(21200H)=2AH`，`(21201H)=4CH`，`(21202H)=B7H`，`(21203H)=65H`
- 求下列指令执行后 `AX` 的内容：
- `MOV AX,1200H`
- `MOV AX,[1200H]`
- `MOV AX,[BX]`
- `MOV AX,1100H[BX]`
- `MOV AX,[BX][SI]`
- `MOV AX,1100H[BX][SI]`
- `LEA AX,1100H[BX][SI]`

标准作答：
1. 段基址为 `DS × 10H = 20000H`。
2. 8088 按小端方式取字：低地址单元放低字节，高地址单元放高字节。
3. 逐条计算有效地址和结果如下。

| 指令 | 有效地址 / 物理地址 | `AX` 最终值 |
| --- | --- | --- |
| `MOV AX,1200H` | 立即数，不访存 | `1200H` |
| `MOV AX,[1200H]` | `PA = 20000H + 1200H = 21200H` | `4C2AH` |
| `MOV AX,[BX]` | `PA = 20000H + 0100H = 20100H` | `3412H` |
| `MOV AX,1100H[BX]` | `PA = 20000H + 1200H = 21200H` | `4C2AH` |
| `MOV AX,[BX][SI]` | `PA = 20000H + 0102H = 20102H` | `7856H` |
| `MOV AX,1100H[BX][SI]` | `PA = 20000H + 1202H = 21202H` | `65B7H` |
| `LEA AX,1100H[BX][SI]` | 只取有效地址 `1202H` | `1202H` |

易错点：
- `LEA` 只取有效地址，不访问主存。
- 字数据读取时忘记按小端方式拼接高低字节。

## 3. 规格化浮点范围与码值题

来源：
- [历年考试卷-计组2022](../../资料整理稿/试卷/历年考试卷-计组2022/历年考试卷-计组2022.md)
- [部分作业题-计算机组成与结构1-5答案](../../资料整理稿/作业/部分作业题-计算机组成与结构1-5答案/部分作业题-计算机组成与结构1-5答案.md)

对应题型：
- [QT-C02-002 规格化浮点与IEEE754编码题](../../题型/QT-C02-002-规格化浮点与IEEE754编码题.md)

题目摘要：
- 规格化浮点数字长 16 位。
- 尾数 10 位（含 1 位符号位），用定点小数补码表示。
- 阶码 6 位（含 1 位符号位），用定点整数移码表示。
- 求尾数范围、阶码范围、四个极值，并把 `X = -0.001101 × 2^{-010}` 写成该格式的机器数。

标准作答：
1. 阶码 6 位、移码表示，故真值范围为 `-32 ~ +31`。
2. 尾数为规格化补码小数：
   - 正尾数范围：`0.100000000 ~ 0.111111111`
   - 负尾数范围：`1.000000000 ~ 1.011111111`
3. 因此四个极值为：

| 项目 | 结果 |
| --- | --- |
| 最大正数 | `(1 - 2^{-9}) × 2^{31}` |
| 最小正数 | `0.1 × 2^{-32} = 2^{-33}` |
| 最大负数 | `-(0.1 + 2^{-9}) × 2^{-32}` |
| 最小负数 | `-1.0 × 2^{31}` |

4. 对 `X = -0.001101 × 2^{-010}` 做规格化：
   - `-010_2 = -2`
   - `-0.001101 × 2^{-2} = -0.1101 × 2^{-4}`
5. 阶码为 `-4`，写成 6 位移码：
   - `-4 + 32 = 28 = 011100_2`
6. 尾数 `-0.1101` 写成 10 位补码小数：
   - `+0.110100000` 的机器数是 `0110100000`
   - 取补得 `1001100000`
7. 所以：
   - 阶码字段：`011100`
   - 尾数字段：`1001100000`

结论：
- `[X]浮 = 011100 1001100000`

易错点：
- “最大负数 / 最小负数”不说明口径，导致正负极值写反。
- 忽略补码规格化条件，误把 `11...` 开头的负尾数当作规格化尾数。

## 4. Booth 补码乘法题

来源：
- [历年考试卷-计组2022](../../资料整理稿/试卷/历年考试卷-计组2022/历年考试卷-计组2022.md)
- [QT-C03-001 原码与Booth乘法题](../../题型/QT-C03-001-原码与Booth乘法题.md)

题目：
- 已知 `X = 0.1011`，`Y = -0.1110`，用 Booth 法求 `[X×Y]补`。

标准作答：
1. 先写辅助量：
   - `[X]补 = 0.1011`
   - `[Y]补 = 1.0010`
   - `[-X]补 = 1.0101`
2. 按 Booth 一位乘法规则：
   - `Y0Y-1 = 10`：加 `[-X]补`
   - `Y0Y-1 = 01`：加 `[X]补`
   - `Y0Y-1 = 00 / 11`：跳过
   - 每轮操作后作一次算术右移
3. 计算过程如下表：

| 步骤 | `D` | `Y` | `Y0` | `Y-1` | 操作说明 |
| --- | --- | --- | --- | --- | --- |
| 初始化 | `0.0000` | `1.0010` | `0` | `0` | `D / Y` 初始化 |
| 1 | `0.0000` | `1.0010` | `0` | `0` | 尾数 `00`，跳过 |
| 右移后 | `0.0000` | `0.1001` | `1` | `0` | `D / Y` 算术右移 1 位 |
| 2 | `1.0101` | `0.1001` | `1` | `0` | 尾数 `10`，加 `[-X]补` |
| 右移后 | `1.1010` | `1.0100` | `0` | `1` | `D / Y` 算术右移 1 位 |
| 3 | `0.0101` | `1.0100` | `0` | `1` | 尾数 `01`，加 `[X]补` |
| 右移后 | `0.0010` | `1.1010` | `0` | `0` | `D / Y` 算术右移 1 位 |
| 4 | `0.0010` | `1.1010` | `0` | `0` | 尾数 `00`，跳过 |
| 右移后 | `0.0001` | `0.1101` | `1` | `0` | `D / Y` 算术右移 1 位 |
| 5 | `1.0110` | `0.1101` | `1` | `0` | 尾数 `10`，加 `[-X]补` |
| 右移后 | `1.1011` | `0.0110` | `0` | `1` | `D / Y` 算术右移 1 位 |

4. 计算结束后得到：
   - `D,Y = 1.101100110`
5. 因此：
   - `[X×Y]补 = 1.01100110`
   - 真值积 `X × Y = -0.10011010_2`

结论：
- 真值积：`X × Y = -0.10011010_2`
- 若按 `1 位符号 + 8 位小数` 补码格式书写：`[X×Y]补 = 1.01100110`

易错点：
- 不说明结果位宽，直接把 Booth 最后一行当“唯一答案”。
- 漏写 `[-X]补`，后面每一步都失去依据。

## 5. 微指令格式与控存容量题

来源：
- [部分作业题-CPU设计-练习](../../资料整理稿/作业/部分作业题-CPU设计-练习/部分作业题-CPU设计-练习.md)
- [历年考试卷-计组2020](../../资料整理稿/试卷/历年考试卷-计组2020/历年考试卷-计组2020.md)

对应题型：
- [QT-C05-001 微指令格式与控制存储器容量题](../../题型/QT-C05-001-微指令格式与控制存储器容量题.md)

题目：
- 微指令字长 24 位。
- 微命令生成部分分 4 个字段，互斥微命令数分别为 `5、8、14、3`。
- 后继地址条件有 `3` 种。
- 设计微指令格式，并求控制存储器最大容量。

标准作答：
1. 字段直接编码法必须给每个字段保留全零空操作状态，因此要满足 `2^n - 1 >= 微命令数`。
2. 逐字段求位数：

| 字段 | 微命令数 | 所需位数 |
| --- | --- | --- |
| 字段 1 | 5 | 3 |
| 字段 2 | 8 | 4 |
| 字段 3 | 14 | 4 |
| 字段 4 | 3 | 2 |

3. 控制字段共 `3 + 4 + 4 + 2 = 13` 位。
4. 后继地址条件有 3 种，需 `2` 位。
5. 次地址字段位数：
   - `24 - 13 - 2 = 9`
6. 控制存储器最大容量：
   - `2^9 = 512` 条微指令

结论：
- 微指令格式可写成：`3 位 + 4 位 + 4 位 + 2 位 + 2 位条件字段 + 9 位次地址字段`
- 控制存储器最大容量为 `512` 条微指令

易错点：
- 把“8 个微命令”误判为“3 位就够”，忘记 `111` 之外还必须给 `000` 留空操作。
- 只算完字段位数，不继续回推次地址字段和控存容量。

## 6. Cache 直接映像题

来源：
- [历年考试卷-计组2022](../../资料整理稿/试卷/历年考试卷-计组2022/历年考试卷-计组2022.md)
- [QT-C07-002 Cache地址映射命中判断与性能题](../../题型/QT-C07-002-Cache地址映射命中判断与性能题.md)

题目摘要：
- Cache 容量 `2KB`
- 直接映像
- 每块 `256B`
- 主存 `4MB`
- 地址 `238956H` 和 `312789H`

标准作答：
1. `4MB = 2^22B`，所以主存地址为 `22` 位。
2. `256B = 2^8B`，块内地址为 `8` 位。
3. Cache 共 `2KB / 256B = 8` 块，因此块号位数为 `3` 位。
4. 标记位数为 `22 - 3 - 8 = 11` 位。
5. 地址字段划分：
   - 主存地址：`标记 11 位 + Cache 块号 3 位 + 块内地址 8 位`
   - Cache 地址：`块号 3 位 + 块内地址 8 位`
6. 对 `238956H`：
   - 主存块号 `= 238956H >> 8 = 2389H`
   - Cache 块号 `= 2389H mod 8 = 1`
   - 标记 `= 2389H >> 3 = 471H`
   - 块内地址 `= 56H`
   - 按整理稿目录表，块 `1` 当前标记为 `471H`，故命中
   - Cache 地址 `= 156H`
7. 对 `312789H`：
   - 主存块号 `= 312789H >> 8 = 3127H`
   - Cache 块号 `= 3127H mod 8 = 7`
   - 标记 `= 3127H >> 3 = 624H`
   - 块内地址 `= 89H`
   - 按整理稿目录表，块 `7` 当前标记为 `312H`，与 `624H` 不同，故不命中

结论：
- 主存地址字段：`11 位标记 + 3 位块号 + 8 位块内地址`
- Cache 地址字段：`3 位块号 + 8 位块内地址`
- `238956H` 命中，变换后的 Cache 地址为 `156H`
- `312789H` 不命中

说明：
- 本题目录表的首行在整理稿中有轻微 OCR 错位，这里按块号 `0~7` 顺序对应标记值 `127H、471H、389H、624H、238H、895H、278H、312H` 进行判断；若后续回看原卷发现表格排布不同，应以原卷为准。

易错点：
- 不先求“主存块号”，直接把整个主存地址拿去和 Cache 标记比较。
- 命中后只写“命中”，不继续写变换后的 Cache 地址。

## 7. 汇编程序功能分析题

来源：
- [历年考试卷-计组2020](../../资料整理稿/试卷/历年考试卷-计组2020/历年考试卷-计组2020.md)

对应题型：
- [QT-C04-002 8086指令结果与汇编程序分析题](../../题型/QT-C04-002-8086指令结果与汇编程序分析题.md)

题目摘要：
- 程序逐字节扫描 `BUF` 中 100 个数据。
- 末尾执行 `DIV BL`，再把 `BL` 和 `AL` 分别写入 `RES1`、`RES2`。

标准作答：
1. 初始化阶段：
   - `DS` 指向 `BUF` 所在段
   - `SI` 指向 `BUF`
   - `BL = 0`，用于统计偶数个数
   - `AX = 0`，用于累计偶数和
   - `CX = 100`，循环 100 次
2. 循环阶段：
   - `DL <- [SI]`
   - `TEST DL, 01H` 检查最低位
   - 若最低位为 `1`，说明是奇数，直接跳过
   - 若最低位为 `0`，说明是偶数：
     - `DH <- 0`，把 `DL` 零扩展成 `DX`
     - `AX <- AX + DX`，累计偶数和
     - `BL <- BL + 1`，统计偶数个数
   - `SI <- SI + 1`，继续处理下一个字节
3. 结束阶段：
   - `DIV BL`，把累计和除以偶数个数
   - 商在 `AL`
   - `RES1 <- BL`
   - `RES2 <- AL`

结论：
- 程序功能是：统计缓冲区 `BUF` 中偶数的个数，并求这些偶数的平均值。
- `RES1` 保存偶数个数。
- `RES2` 保存偶数平均值的整除商。

易错点：
- 只看见 `DIV BL`，就说程序“求平均值”，却不先交代它平均的是哪一类数据。
- 忽略 `TEST DL,01H` 的筛选作用，看不出它只统计偶数。

说明：
- 以下默认按 Intel 记法解释指令，左操作数为目的操作数。
- 默认沿用课程里“`PC→AR`、`AR→AB`、`DB→DR`、`DR→IR`、`S→ALU`、`ALU→T`”这套简化 CPU 口径。
- 为了便于并排比较，以下统一按“取操作码 -> 取地址 / 取操作数 -> 执行 -> 写回”来写。

### 8.1 `ADD [SI], AX`

题意：
- `[SI]` 为寄存器间接寻址。
- 指令功能为 `((SI)) + (AX) -> ((SI))`。

标准作答：
1. 取指阶段：
   - `T1: PC→AR`
   - `T2: AR→AB, RD, PC+1`
   - `T3: DB→DR`
   - `T4: DR→IR`
2. 执行阶段：
   - `T5: SI→AR`
   - `T6: AR→AB, RD`
   - `T7: DB→DR`
   - `T8: DR→S`
   - `T9: AX→ALU`
   - `T10: ADD, ALU→T`
   - `T11: T→DB`
   - `T12: AR→AB, WR`

结果解释：
- `SI` 给出有效地址。
- 先从主存读出 `M[SI]` 到 `DR`。
- 再把 `AX` 与 `DR` 相加。
- 最后把结果回写到原主存单元 `M[SI]`。

易错点：
- 把它误写成 `(AX)+((SI))->AX`。
- 只写执行阶段，不补公共取指阶段。

### 8.2 `OR [1500H], AX`

题意：
- 指令功能为 `((1500H)) OR (AX) -> ((1500H))`。
- 题目已说明该指令为双字指令，第二个字为地址 `1500H`。

标准作答：
1. `Fetch`：
   - `PC→AR`
   - `AR→AB`
   - `AB→MAR`
   - `Read (MM→MDR)`
   - `MDR→DB`
   - `DB→DR`
   - `DR→IR`
   - `PC++`
2. `Fetch Operands`：
   - `PC→AR`
   - `AR→AB`
   - `AB→MAR`
   - `Read (MM→MDR)`
   - `MDR→DB`
   - `DB→DR`
   - `PC++`
   - `DR(1500H)→AR`
   - `AR→AB`
   - `AB→MAR`
   - `Read (MM→MDR)`
   - `MDR→DB`
   - `DB→DR`
   - `DR→S`
3. `Execute`：
   - `AX→ALU`
   - `OR, ALU→T`
4. `Store`：
   - `T→DR`
   - `DR→DB`
   - `AR→AB`
   - `AB→MAR`
   - `DB→MDR`
   - `Write`

结果解释：
- 第二字先提供有效地址 `1500H`。
- 再从 `M[1500H]` 取出目的操作数。
- 执行逻辑或后把结果写回原主存单元。

易错点：
- 忘记这是双字指令，漏掉“取第二字地址”的过程。
- 把结果误写回 `AX` 而不是写回主存。

### 8.3 `SUB [1500H], AX`

题意：
- 指令功能为 `((1500H)) - (AX) -> ((1500H))`。
- 该题同样是双字指令，第二个字给出直接地址 `1500H`。

标准作答：
1. 取第一字（操作码字）：
   - `T1: PC→AR`
   - `T2: AR→AB, RD, PC+1`
   - `T3: DB→DR`
   - `T4: DR→IR`
2. 取第二字（地址字）：
   - `T5: PC→AR`
   - `T6: AR→AB, RD, PC+1`
   - `T7: DB→DR`
3. 执行阶段：
   - `T8: DR→AR`
   - `T9: AR→AB, RD`
   - `T10: DB→DR`
   - `T11: DR→S`
   - `T12: AX→ALU`
   - `T13: SUB, ALU→T`
   - `T14: T→DB`
   - `T15: AR→AB, WR`

结果解释：
- 第二字先给出有效地址 `1500H`。
- 先从 `M[1500H]` 取出目的操作数。
- 再执行减法 `M[1500H] - AX`。
- 最后把差值写回原主存单元 `M[1500H]`。

易错点：
- 把 `SUB [1500H], AX` 看反，误写成 `(AX) - ((1500H))`。
- 只改运算符号，不同步保留双字指令的“取第二字地址”过程。

### 8.4 三题并排对照

| 指令 | 指令字长 / 寻址 | 有效地址怎么来 | 读出的主存操作数 | ALU 动作 | 写回位置 |
| --- | --- | --- | --- | --- | --- |
| `ADD [SI], AX` | 单字 / 寄存器间接 | `SI→AR` | `M[SI]` | `M[SI] + AX` | `M[SI]` |
| `OR [1500H], AX` | 双字 / 直接寻址 | 第二字给出 `1500H`，再 `DR→AR` | `M[1500H]` | `M[1500H] OR AX` | `M[1500H]` |
| `SUB [1500H], AX` | 双字 / 直接寻址 | 第二字给出 `1500H`，再 `DR→AR` | `M[1500H]` | `M[1500H] - AX` | `M[1500H]` |

一眼判断法：
- 看见 `[SI]` 这类寄存器间接寻址，执行阶段通常先由寄存器直接给出有效地址。
- 看见 `[1500H]` 且题目明确是双字指令，就必须多写一轮“取第二字地址”。
- `OR` 和 `SUB` 的取址、取数、写回框架基本相同，真正变化的核心只在 ALU 控制信号。

## 9. 8088 总线与 DRAM 扩展题

来源：
- [历年考试卷-计组2022](../../资料整理稿/试卷/历年考试卷-计组2022/历年考试卷-计组2022.md)
- [历年考试卷-计算机组成与结构Ⅰ-2022年试题A卷-顾新](../../资料整理稿/试卷/历年考试卷-计算机组成与结构Ⅰ-2022年试题A卷-顾新/历年考试卷-计算机组成与结构Ⅰ-2022年试题A卷-顾新.md)

对应题型：
- [QT-C08-001 总线与存储器扩展题](../../题型/QT-C08-001-总线与存储器扩展题.md)
- [QT-C07-001 存储器类型比较与容量扩展题](../../题型/QT-C07-001-存储器类型比较与容量扩展题.md)

题目：
- 8088CPU 系统总线上有地址信号 `A0-A19`、数据信号 `D0-D7`。
- 求内存 `40000H ~ 4FFFFH` 的容量。
- 若采用 `32K × 1bit` 的 DRAM 芯片构成该内存，应采用哪种扩展方式，共需要多少片。

标准作答：
1. 先算地址范围容量：
   - `4FFFFH - 40000H + 1 = 10000H`
   - `10000H = 65536B = 64KB`
2. 8088 的数据总线宽度为 `8` 位，因此目标内存应组织成 `64K × 8bit`。
3. 单片 DRAM 容量为 `32K × 1bit`。
4. 先做位扩展：
   - 8 片并联可得到 `32K × 8bit`
5. 再做字扩展 / 地址扩展：
   - 还需要把 `32K` 扩成 `64K`
   - 因此需要 2 组 `32K × 8bit`
6. 总片数：
   - `8 × 2 = 16` 片

结论：
- 内存区域 `40000H ~ 4FFFFH` 的容量为 `64KB`
- 扩展方式：`8 位位扩展 + 2 组地址扩展`
- 需要 `16` 片 `32K × 1bit` DRAM

连接思路：
- `A0 ~ A14` 接到每片 DRAM 的地址输入端。
- `D0 ~ D7` 分别对应一组中 8 片芯片的 8 个数据位。
- 用 `A15` 区分上下两个 `32KB` 块：
  - `40000H ~ 47FFFH`
  - `48000H ~ 4FFFFH`
- 再用高位地址 `A16 ~ A19 = 0100` 进行片选译码，保证只响应该段地址空间。

易错点：
- 只算出 `64KB`，却忘了把它写成 `64K × 8bit` 去和芯片规格比较。
- 把 `32K × 1bit` 误当成 `32KB` 芯片。
- 把 8088 错当成 8086，平白引入高低字节体。

## 10. 2022 回忆卷汇编程序题

来源：
- [历年考试卷-计组2022](../../资料整理稿/试卷/历年考试卷-计组2022/历年考试卷-计组2022.md)

对应题型：
- [QT-C04-002 8086指令结果与汇编程序分析题](../../题型/QT-C04-002-8086指令结果与汇编程序分析题.md)

题目摘要：
- 程序先把 `DS` 置为 `4000H`，`SI` 指向 `2000H`。
- `DX` 先取第一个数据，`BX` 初值为 `0`。
- 随后循环扫描后续 `99` 个字数据，并用 `CMP / JBE` 做比较。

标准作答：
1. 初始化阶段：
   - `DX <- M[4000:2000]`，即先把第一个字作为当前最大值候选。
   - `BX <- 0`，作为次大值候选。
   - `CX <- 99`，表示后面还要检查 99 个字。
2. 每轮循环读取一个新字到 `AX`。
3. 第一次比较：
   - `CMP AX, DX`
   - `JBE NEXT1`
   - 若不跳转，说明 `AX > DX`（按无符号数比较）
   - 此时先执行 `BX <- DX`，再执行 `DX <- AX`
4. 若 `AX <= DX`，转入 `NEXT1`：
   - `CMP AX, BX`
   - `JBE NEXT2`
   - 若不跳转，说明 `BX < AX <= DX`
   - 此时 `BX <- AX`

结论：
- `DX` 保存这 100 个字数据中的最大值。
- `BX` 保存这 100 个字数据中的次大值。
- 因为分支指令是 `JBE`，所以这里比较的是**无符号大小**，不是有符号大小。
- 若最大值在数据中重复出现，则 `BX` 也可能最终等于这个最大值。

易错点：
- 把 `JBE` 按有符号数“<=”理解。
- 只说“求最大值”，没看出 `BX` 同时维护的是次大值。

## 11. 第6章流水线代表题：4 段不等长线性流水线

来源：
- [计算机组成与设计-第6章-192-221](../../资料整理稿/教材/计算机组成与设计-第6章-192-221/计算机组成与设计-第6章-192-221.md)

对应题型：
- [QT-C06-001 流水线性能与相关分析题](../../题型/QT-C06-001-流水线性能与相关分析题.md)

题目：
- 一条 4 段流水线，各段执行时间分别为 `1ns、2ns、2ns、3ns`。
- 求连续完成 `100` 个任务时的总时间、吞吐率、加速比和效率。

标准作答：
1. 设各段时间分别为：
   - `t1 = 1ns`
   - `t2 = 2ns`
   - `t3 = 2ns`
   - `t4 = 3ns`
2. 最大段时间为：
   - `tmax = 3ns`
3. 顺序执行 `100` 个任务所需时间：
   - `Tseq = 100 × (1 + 2 + 2 + 3) = 800ns`
4. 流水线执行时间：
   - `Tp = (1 + 2 + 2 + 3) + (100 - 1) × 3`
   - `Tp = 8 + 297 = 305ns`

文本版时空图（前 5 个任务）：

```text
I1: S1[0,1)   -> S2[1,3)   -> S3[3,5)   -> S4[5,8)
I2: S1[1,2)   -> S2[3,5)   -> S3[5,7)   -> S4[8,11)
I3: S1[2,3)   -> S2[5,7)   -> S3[7,9)   -> S4[11,14)
I4: S1[3,4)   -> S2[7,9)   -> S3[9,11)  -> S4[14,17)
I5: S1[4,5)   -> S2[9,11)  -> S3[11,13) -> S4[17,20)
```

读图结论：
- `S4` 最慢，决定稳态输出间隔为 `3ns`。
- 前级更快，但会因为后级瓶颈而等待，因此不能按各自最快速度持续流出结果。

5. 吞吐率：
   - `TP = 100 / 305ns`
   - `TP ≈ 0.3279 × 10^9` 个任务 / 秒
   - 即约 `327.9 M` 任务 / 秒
6. 加速比：
   - `S = 800 / 305 ≈ 2.62`
7. 效率：
   - `E = [100 × (1 + 2 + 2 + 3)] / [4 × 305]`
   - `E = 800 / 1220 ≈ 65.6%`

结论：
- 总时间：`305ns`
- 吞吐率：约 `327.9 M` 任务 / 秒
- 加速比：约 `2.62`
- 效率：约 `65.6%`

易错点：
- 直接把 4 段流水线当成”每拍 1ns”来算。
- 只拿最大段时间 `3ns` 去乘 `100`，漏掉初始通过时间 `8ns`。

## 12. 第6章流水线代表题：条件跳转导致断流与重新填充

来源：
- [部分作业题-计组作业习题及答案-4](../../资料整理稿/作业/部分作业题-计组作业习题及答案-4/部分作业题-计组作业习题及答案-4.md)

对应题型：
- [QT-C06-001 流水线性能与相关分析题](../../题型/QT-C06-001-流水线性能与相关分析题.md)

题目：
- 某指令流水线由 `10` 级构成，每级处理时间均为 `100ps`。
- 现要执行一段程序，该程序由 `50` 个结构相同、顺序执行的小程序段组成。
- 每个小程序段有 `15` 条指令，其中第 `4` 条指令 `I4` 为条件跳转指令：
  - 条件为假：顺序执行完整 `15` 条指令。
  - 条件为真：跳转到 `I10`，故每段只实际执行 `10` 条指令。
- 求两种情况下的实际吞吐率、加速比和效率。

标准作答：
1. 先写基本参数：
   - 流水线段数 `m = 10`
   - 流水线周期 `τ = 100ps`
   - 顺序执行 1 条指令时间 `= mτ = 1000ps`
2. 当所有条件跳转都**未发生**时：
   - 实际执行指令数 `n1 = 50 × 15 = 750`
   - 顺序执行总时间：
     - `Tseq1 = 750 × 1000ps = 750000ps`
   - 流水线不断流，总时间：
     - `Tp1 = mτ + (n1 - 1)τ`
     - `Tp1 = 10 × 100ps + (750 - 1) × 100ps = 75900ps`
   - 吞吐率：
     - `TP1 = 750 / 75900ps ≈ 9.8814 × 10^9` 条 / 秒
   - 加速比：
     - `S1 = 750000 / 75900 ≈ 9.8814`
   - 效率：
     - `E1 = S1 / 10 ≈ 98.81%`
3. 当所有条件跳转都**发生**时：
   - 每个小程序段只执行 `10` 条指令，因此实际执行指令数：
     - `n2 = 50 × 10 = 500`
   - 顺序执行总时间：
     - `Tseq2 = 500 × 1000ps = 500000ps`
   - 若先不计断流，只按 `500` 条指令连续流过，则：
     - `Tp2(base) = mτ + (n2 - 1)τ`
     - `Tp2(base) = 10 × 100ps + (500 - 1) × 100ps = 50900ps`
   - 按本题整理稿口径，共出现 `50` 次断流；每次重新填充时间：
     - `Trefill = (m - 1)τ = 9 × 100ps = 900ps`
   - 总气泡时间：
     - `Tbubble = 50 × 900ps = 45000ps`
   - 所以流水线总时间：
     - `Tp2 = 50900ps + 45000ps = 95900ps`
   - 吞吐率：
     - `TP2 = 500 / 95900ps ≈ 5.2138 × 10^9` 条 / 秒
   - 加速比：
     - `S2 = 500000 / 95900 ≈ 5.2138`
   - 效率：
     - `E2 = S2 / 10 ≈ 52.14%`

结论：

| 情况 | 实际指令数 | 流水线总时间 | 吞吐率 | 加速比 | 效率 |
| --- | --- | --- | --- | --- | --- |
| 条件跳转未发生 | `750` | `75900ps` | 约 `9.8814 GIPS` | 约 `9.8814` | 约 `98.81%` |
| 条件跳转发生 | `500` | `95900ps` | 约 `5.2138 GIPS` | 约 `5.2138` | 约 `52.14%` |

一眼结论：
- 条件跳转不发生时，流水线基本不断流，性能接近理想值。
- 条件跳转一旦频繁发生，真正拖慢系统的不是少执行了几条指令，而是**反复断流后必须重新填充流水线**。

易错点：
- 跳转发生后，仍按每段 `15` 条指令去算指令总数。
- 只算 `500` 条指令的连续流水时间，漏掉 `50` 次重新填充的气泡时间。
- 看见”条件跳转”只会说”有控制相关”，却没有把它落实到 `(m - 1)τ` 的断流开销上。

## 14. 扩展操作码设计题

来源：
- [历年考试卷-计组2020](../../资料整理稿/试卷/历年考试卷-计组2020/历年考试卷-计组2020.md)
- [部分作业题-CPU设计-练习](../../资料整理稿/作业/部分作业题-CPU设计-练习/部分作业题-CPU设计-练习.md)

对应题型：
- [QT-C04-004 扩展操作码与指令设计题](../../题型/QT-C04-004-扩展操作码与指令设计题.md)

题目：
- 指令字长 24 位。
- 指令类型有双操作数、单操作数和无操作数三类。
- 每个操作数地址字段均为 8 位。
- 已有 `M` 条双操作数指令、`N` 条无操作数指令。
- 求最多还能设计多少条单操作数指令。

标准作答：
1. 双操作数指令需要两个地址字段：
   - 地址字段共 `8 + 8 = 16` 位
   - 因此双操作数指令的操作码只有 `24 - 16 = 8` 位
   - 共可编码 `2^8` 条
2. 已有 `M` 条双操作数指令后，还剩：
   - `2^8 - M` 个 8 位扩展入口
3. 对于单操作数指令：
   - 只需要 1 个 8 位地址字段
   - 因而操作码可以扩展到 `24 - 8 = 16` 位
   - 每个剩余的 8 位扩展入口，下面可再细分出 `2^8` 条 16 位编码
4. 因此，剩余可分配的 16 位操作码总数为：
   - `(2^8 - M) × 2^8`
5. 其中无操作数指令不需要地址字段，也要占用这批 16 位编码中的 `N` 条
6. 所以单操作数指令最多条数为：

```text
(2^8 - M) × 2^8 - N
```

结论：
- 最多还能设计的单操作数指令条数为：
- `[(2^8 - M) × 2^8 - N]`

易错点：
- 把双操作数剩余的“8 位扩展入口”直接当成单操作数条数。
- 忘记无操作数指令也要占用扩展后的 16 位编码空间。

## 15. RISC 特点简答题

来源：
- [历年考试卷-2020_final](../../资料整理稿/试卷/历年考试卷-2020_final/历年考试卷-2020_final.md)
- [历年考试卷-计组2020](../../资料整理稿/试卷/历年考试卷-计组2020/历年考试卷-计组2020.md)

对应题型：
- [QT-C04-003 CISC与RISC对比题](../../题型/QT-C04-003-CISC与RISC对比题.md)

标准作答模板：
1. 指令系统精简，指令种类较少。
2. 指令长度通常规整，便于译码和流水线实现。
3. 寻址方式较少，访存操作尽量通过专门的装入 / 存储指令完成。
4. 通用寄存器较多，尽量减少对主存的频繁访问。
5. 大多数指令可在较少甚至单个时钟周期内完成，便于提高吞吐率。
6. 控制器多采用硬布线或更适合流水线的实现方式。

一句话结论：
- `RISC` 的核心不是“功能弱”，而是通过精简指令、增加寄存器和优化流水线友好性来提高执行效率。

易错点：
- 把“RISC 指令少”理解成“功能差”。
- 把 “RISC 寻址方式多” 错写成特点；这恰好更接近 `CISC`。

## 16. 8253 产生 1 秒周期对称方波题

来源：
- [卷1-答案](../../资料整理稿/试卷/历年考试卷-计算机组成与结构试题-有答案/拆分卷集/卷1-答案.md)
- [卷5-答案](../../资料整理稿/试卷/历年考试卷-计算机组成与结构试题-有答案/拆分卷集/卷5-答案.md)

对应题型：
- [QT-C08-004 8253定时方波与波形题](../../题型/QT-C08-004-8253定时方波与波形题.md)

题目摘要：
- 外部计数时钟为 `1MHz`。
- 只用一片 `8253`，产生周期为 `1s` 的对称方波。

标准作答：
1. 先求输入时钟周期：
   - `Tclk = 1 / 1MHz = 1μs`
2. 若直接产生 `1s` 周期方波，则总计数值应为：
   - `1s / 1μs = 10^6`
3. 单个 `8253` 计数器为 `16` 位，最大计数时间约 `65.5ms`，因此单个计数器不够。
4. 需将两个计数器级联：
   - 例如把 `CLK0` 接外部时钟
   - 使 `OUT0 -> CLK1`
   - `GATE0`、`GATE1` 置有效
5. 可令：
   - 计数器 `0` 工作在方式 `2` 或方式 `3`
   - 计数器 `1` 工作在方式 `3`
6. 取两级总计数值为：
   - `1000 × 1000`
7. 例如：
   - 计数器 `0` 计数值 `1000`
   - 计数器 `1` 计数值 `1000`
8. 则：
   - `OUT0` 可形成周期为 `1ms` 的脉冲或方波
   - `OUT1` 可形成周期为 `1s` 的对称方波

结论：
- 单个计数器不够，必须级联。
- 一组标准答案是：`计数器0 = 1000，计数器1 = 1000`，最终得到 `1s` 周期对称方波。

易错点：
- 只算出 `10^6`，却不检查 `16` 位计数器能否单独实现。
- 不写 `OUT0 -> CLK1` 的级联关系。

## 17. 按钮 K 与双色发光二极管接口程序题

来源：
- [卷5-答案](../../资料整理稿/试卷/历年考试卷-计算机组成与结构试题-有答案/拆分卷集/卷5-答案.md)

对应题型：
- [QT-C08-005 8255接口连接与控制程序题](../../题型/QT-C08-005-8255接口连接与控制程序题.md)

题目摘要：
- 接口地址定为 `0000H`
- 检测按钮 `K` 的状态
- 根据状态控制红、绿发光二极管显示

标准作答：
1. 连接思路：
   - 按钮 `K` 作为输入
   - 红、绿发光二极管作为输出
   - 题目允许自选锁存器或 `8255`，答案稿采用了锁存输出接口思路
2. 程序骨架如下：

```asm
START:  MOV DX, 0000H
        IN  AL, DX
        AND AL, 80H
        JZ  NEXT
        MOV AL, 80H
        OUT DX, AL
        JMP START

NEXT:   MOV AL, 01H
        OUT DX, AL
        JMP START
```

3. 程序逻辑解释：
   - `IN AL,DX`：读取按钮状态
   - `AND AL,80H`：取出对应状态位
   - `JZ NEXT`：若该位为 `0`，跳到另一种显示方案
   - 两个 `OUT` 分别对应按钮两种状态下的 LED 显示

结论：
- 这类题的标准答案不是“只给程序”，而是“先说明输入/输出对象，再给程序骨架”。

易错点：
- 没有先掩码就直接判断。
- `JZ / JNZ` 方向写反，导致“按下 / 抬起”的显示逻辑互换。

## 18. 8253 波形题

来源：
- [卷6-答案](../../资料整理稿/试卷/历年考试卷-计算机组成与结构试题-有答案/拆分卷集/卷6-答案.md)

对应题型：
- [QT-C08-004 8253定时方波与波形题](../../题型/QT-C08-004-8253定时方波与波形题.md)

题目摘要：
- `8253` 中：
  - 计数器 `1` 初始化为方式 `1`，计数值 `500`
  - 计数器 `2` 初始化为方式 `3`，计数值 `2000`
  - `CLK2 = 2.5MHz`
  - `OUT2` 反相后作为计数器 `1` 的外部计数时钟
- 开关 `K` 断开后，画 `OUT2` 和 `OUT1` 反相后的波形，并标宽度

标准作答：
1. 先求计数器 `2` 的输入时钟周期：
   - `Tclk = 1 / 2.5MHz = 0.4μs`
2. 计数器 `2` 工作在方式 `3`，计数值为 `2000`，因此：
   - `OUT2` 为连续对称方波
   - 周期为 `2000 × 0.4μs = 800μs`
3. `OUT2` 反相后送到计数器 `1` 作外部计数时钟。
4. 计数器 `1` 计数值为 `500`，因此其输出相关脉冲宽度为：
   - `800μs × 500 = 400ms`
5. 所以最终应标出：
   - `OUT2`：周期 `800μs`
   - `OUT1` 反相后：单个正脉冲，脉宽 `400ms`

结论：
- `OUT2` 为连续对称方波，周期 `800μs`
- `OUT1` 反相后为单个正脉冲，脉宽 `400ms`

易错点：
- 先把 `2.5MHz` 的时钟周期算错。
- 波形画出来了，但没有把周期和脉宽标在图旁。
