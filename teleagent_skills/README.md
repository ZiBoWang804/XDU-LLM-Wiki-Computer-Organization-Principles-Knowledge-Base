# TeleAgent Skill 专家包（可上架）

四条核心教学链路的**平台侧能力封装**：讲题出题、变式训练、错因诊断、复习计划。
每张卡片 = 系统提示词 + 输入参数 + 输出规范 + 工具依赖 + 留痕模板 + API 接入方式，
可直接粘贴到 TeleAgent 智能体平台配置，也可作为"专家包"素材上架。

| 卡片 | 链路 | 核心能力 | 调用入口 |
|------|------|----------|----------|
| [01-讲题出题专家](01-讲题出题专家.md) | 讲题/出题 | 自主查库+学情命题、答案解析折叠 | `skill=question` |
| [02-变式训练生成器](02-变式训练生成器.md) | 变式 | 同源变式、换情境设问、答案可验证 | `skill=variant` |
| [03-错因诊断专家](03-错因诊断专家.md) | 错因 | 四分类归因+薄弱诊断+对症训练 | `skill=diagnosis` |
| [04-复习计划规划师](04-复习计划规划师.md) | 计划 | 个性化逐天规划、缺信息二次询问 | `skill=plan` |

## 设计原则（与参赛验收对齐）

- **全 LLM 驱动**：无规则引擎/模板兜底；坏输出直接报错
- **只做输出格式校验**：格式由提示词 + 示例约定
- **错因四分类口径统一**：概念不清／计算失误／审题偏差／知识迁移不足（命题枚举）
- **留痕**：所有产出写入知识库 `智能体记录/`，题面/答案/解析/模型思考全程可追溯
- **个性化**：注入学生档案（掌握度/错因分布/能力轨迹/学习路径）+ 考点分布（难度/题型/内容量）+ 教师侧信息

## TeleAgent 平台上架/配置步骤

1. **创建智能体应用**（agent.teleai.com.cn 控制台）：名称"编译原理考点地图"，简介按 README.md
2. **系统提示词**：将各卡"系统提示词"合并（或按技能拆成多个子技能/专家）
3. **挂载知识库**：绑定 `编译原理知识库`（dataset key 对应知识库，RAG 素材层）
4. **API 插件/工具**：指向在线后端 `POST /api/skills/run`（鉴权 X-Token），按卡片"平台接入"配置参数；或直接调用后端 `/api/ask`（问答）、`/api/quiz/submit`（错因自动归类）
5. **发布上线**：拿到**在线交互地址**（比赛核心交互载体），测试四条链路后写入作品文档

## 与自建网页的关系

- **TeleAgent 在线交互地址** = 核心业务交互载体（对话式交付，比赛演示主入口）
- 自建双端网页（Obsidian 风格）= 功能拓展展示（考点地图可视化、题库/变式 UI、Smart Lookup/Connections、多会话等）
- 后端能力（DeepSeek LLM、双层检索、学情库）为两者共用——符合"可借助外部 API，入口在 TeleAgent"的规则

## 提示词同步约定

卡片内提示词与仓库代码同源：
`app/backend/services.py`（PLAN_SYSTEM / VARIANT_SYSTEM / QUIZ_SYSTEM / classify_error）、
`app/backend/skills.py`（QuestionSkill / DiagnosisSkill）。
修改提示词时两边同步更新，卡内版本以仓库代码为准。
