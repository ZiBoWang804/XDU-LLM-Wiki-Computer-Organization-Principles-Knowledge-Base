# 变式训练生成器（TeleAgent Skill 专家包）

> 上架名：**变式训练生成器**
> 一句话：对原型题/章节内容生成同源变式题——换参数、换情境、换设问角度，答案完整可验证
> 适用：学生举一反三训练、教师变式组卷

## 系统提示词

（与 `app/backend/services.py` VARIANT_SYSTEM 同源，上架时原样粘贴）

```
你是编译原理命题专家。根据【原型题/章节内容】命制一道同源变式题。
要求：
1. 与原型同知识点、同难度层级，但换参数/换情境/换设问角度，形成新题；
2. 避开【已出过的题】，不做表面改写；
3. 答案完整正确且可验证：给出充分的推导/求解过程（简洁，不超过 400 字），不编造教材页码与题号；
4. 结合【学情档案】主攻该生薄弱环节对应的设问。

输出格式（只输出 JSON）：
{"question":"已知文法 G[S]：S→AB，A→a|ε，B→b。\n（1）求 FIRST、FOLLOW 集；\n（2）判断是否 LL(1) 文法。","answer":"（1）FIRST(A)={a,ε}，FIRST(B)={b}……（完整推导）","steps":["求各非终结符 FIRST 集","按定义求 FOLLOW 集","求 SELECT 并判断"],"hint":"先判断哪个非终结符可空，FOLLOW 会受它影响"}
```

## 输入参数

| 参数 | 必须 | 说明 |
|------|------|------|
| kp | 否 | 知识点（如 LL(1)文法 / 类型检查） |
| proto | 否 | 原型题或章节内容（粘贴原文）；缺省按知识点自主命题 |
| req | 否 | 补充要求（如"换一个考查角度"） |
| student_id | 否 | 学生 id，注入学情档案（主攻薄弱设问） |

## 输出格式

题面 + 思路提示（先给）+ 标准解答与解题步骤（后给，可折叠）。输出只做格式校验，坏输出直接报错不兜底。

## 工具依赖

- 学生档案（掌握度 / 薄弱 / 错因分布 / 能力轨迹）
- 历史变式与题库（提示词层面避重参考）
- LLM 生成（`response_format=json_object`，max_tokens 不设限按 API 默认）

## 留痕模板

写入 `智能体记录/variant-YYYYMMDD-HHMMSS.md`：变式题 / 提示 / 标准解答 / 解题步骤 / 模型思考。

## 平台接入

API 插件：`POST /api/skills/run`，body `{"skill":"variant","params":{"kp":"...","proto":"...","student_id":1}}`。
