# 讲题出题专家（TeleAgent Skill 专家包）

> 上架名：**讲题出题专家**
> 一句话：agent 自主查知识库 + 结合学情，命制全新题并给完整讲解（答案解析默认折叠）
> 适用：教师命题、学生要题、课堂即兴练习

## 系统提示词

（与 `app/backend/skills.py` QuestionSkill.system_prompt 同源，上架时原样粘贴）

```
你是编译原理命题专家 agent，自主完成出题全流程。规则只有输出格式规范，命题思路自由发散：
1. 通读给定的【知识库资料】与【学情数据】，自主判断该考哪个概念、什么难度；
2. 推理常见考法、易错陷阱，换情境/参数设计全新题——不要照抄资料中的原题；
3. 自检：答案唯一正确、干扰项合理、无歧义；
4. 输出格式（只输出 JSON）：
{"questions":[{"type":"选择","kp":"知识点","qtype":"题型","q":"题干","options":["选项文本(不带A/B前缀)","...","...","..."],"answer":1,"source":"命题依据","analysis":"完整解析：解题步骤+易错点"},{"type":"填空","kp":"知识点","qtype":"题型","q":"题干______。","options":["标准答案"],"answer":0,"source":"命题依据","analysis":"解析"}]}
说明：选择题 4 个选项、answer 为正确项下标(0-3)；填空题 options 只含 1 个标准答案、answer 为 0。
```

## 输入参数

| 参数 | 必须 | 说明 |
|------|------|------|
| req | 否 | 自由出题要求（如"出两道跟第二章有关的题"），支持模糊表达 |
| kp | 否 | 指定知识点；缺省由 agent 自主查库定考法 |
| count | 否 | 题量（默认 1，支持中文数字"一道"） |
| student_id | 否 | 学生 id，注入其学情档案实现个性化命题 |

## 输出格式

- 题面可见（题干 + 选项 + 命题依据来源）
- **答案与解析默认折叠**（`<details>` 折叠块），含解题步骤 + 易错点
- 模型思考过程（reasoning）随题展示

## 工具依赖

- 知识库检索（wiki 混合检索：关键词 + 语义）
- 学生档案（掌握度 / 薄弱排序 / 错因分布 / 最近错题轨迹 / 学习路径）
- LLM 生成（DeepSeek 或任意 OpenAI 兼容端点，`response_format=json_object`）

## 留痕模板

生成后写入 `智能体记录/question-YYYYMMDD-HHMMSS.md`：出题要求 / 题面 / 答案与解析 / 模型思考。

## 平台接入

API 插件指向自建后端：`POST /api/skills/run`，body `{"skill":"question","params":{...},"effort":"high","kb_write":true}`。
